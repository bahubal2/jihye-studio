# 제작 전 점검표 — 영상마다 장면을 짜기 전에 반드시 본다
처음 작성: 2026-11-03. 근거: 같은 주제 상위 5편(125만·89만·84만·57만·19만 회)과 레퍼런스 9개 채널의 **본편 5:00~9:00 구간** 레이더 분석 (brand/radar/2026-11-03/*_본편.md).
담당자 말: "우리가 지금 꼴찌다. 수단과 방법을 총동원해 처음부터 끝까지 보고 싶게 만들어야 한다."

## 0. 시작 순서 (대본·오디오를 받으면)
1. 레이더 두 번 돌리기 (약 $0.3):
   `python3 tools/radar.py --per 1 --yes` (인트로 3분)
   `python3 tools/radar.py --body --from 300 --sec 240 --per 1 --days 30 --yes` (본편)
   같은 주제 상위 영상이 있으면 `--ids 영상ID,…` 로 그 영상들의 본편도 본다.
2. 새로 보인 기법 중 키트에 없는 것 → 바로 만들고(무료면 즉시), 이번 영상에 최소 2개 시험.
3. 아래 대본 점검 → 고칠 곳을 담당자에게 보고(한국어, 짧게) → 장면 계획.

## 1. 대본 — 중간에 나가지 않게 (상위 영상 공통)
- [ ] 순위마다 **시작 방식이 다르다**: 사건·스캔들 / 모순("역대 최대 이익인데 신입은 덜 뽑았다") / 시청자 소지품 지목("서랍 속에 있을 그 자격증") / 퀴즈 먼저 내고 직업 공개 / "이번엔 이유가 다릅니다"(원인 전환)
- [ ] 순위 **길이가 다르다** (70~130초). 같은 길이·같은 순서 반복 금지 (우리 사라지는직업: 7개 모두 151~163초 → 지루함의 원인)
- [ ] **직업 이름을 바로 말하지 않는다**: 힌트·퀴즈 → 공개
- [ ] 순위 끝에 **다리 질문**(다음 순위로 넘기는 궁금증) 하나
- [ ] **복선**: "이 숫자, 1위에서 다시 나옵니다. 기억해 두세요" 1~2회 (화면: foreshadow 카드가 구석에 붙어 남음)
- [ ] 1위 예고를 중간에 2~3번 되살린다
- [ ] **내 가족 환산**: 퍼센트는 즉시 "5명 중 1명", "그 1명이 우리 아이일 수도"
- [ ] 소리로 나오는 숫자는 1분에 4~6개, 나머지는 화면으로만
- [ ] "생각하시죠? → 아닙니다"는 영상 전체 3번까지. 대신 뒤집기 카드·모순 대비·퀴즈로 바꿔 가며
- [ ] 심리 용어를 대놓고 말하지 않는다 (채널 규칙 2026-11-03). 마음은 장면·대사에 녹인다
- [ ] 영상 한가운데 쉼표: 짧은 중간 정리 + 1위 복선 (경제탐사단 06:49)
- [ ] 결론 문장 직전 반 박자 쉼 (대본에 "…" 또는 문장 끊기)

## 2. 화면 — 계속 보고 싶게
- [ ] **1분에 컷·상태 변화 7~9번** (6~9초마다 배경 교체 또는 큰 움직임). 장면 안에서도 bg 리스트로 바꿔 끼운다
- [ ] 장면마다 최소 하나: 카메라(crash/push/pull/shake) 또는 긋기(arrow/circ/uline) 또는 액자 축소(shrink)
- [ ] 정지 그림과 **움직이는 클립을 번갈아** (상위 영상은 일러스트:실사 = 1:1). 순위마다 클립 2개 이상
- [ ] 과거 회상은 **세피아 톤**(PAST) — 시대가 바뀐다는 신호
- [ ] 통념→현실은 **뒤집기 카드**(flipcard), 잘못된 숫자는 빨간 줄(swapnum·tag strike)
- [ ] 서류·기사 위에 **빨간 펜 동그라미·밑줄**(circ·uline, 사각사각 소리)
- [ ] 휴대폰 장면은 화면 터치(tap 소리)
- [ ] 1인칭 시점 컷 (서랍을 여는 내 손, 내 휴대폰 화면) — 그림 프롬프트에 "first-person POV"

## 3. 소리
- [ ] **배경음악**을 깐다 (TTS 경로는 지금 배경음악이 없다 → 가장 큰 빈칸). 순위가 바뀔 때 음악을 바꾸거나 잠깐 빼서 '새 장' 신호
- [ ] 핵심 문장 직전 배경음악을 0.3초 줄인다 (덕킹)
- [ ] 효과음은 15~20초에 1번, 그림의 행동과 맞춘다 (펜 = 사각, 서류 = 바스락, 폰 = 톡, 전환 = 휙). 뾱 남발 금지
