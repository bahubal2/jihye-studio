### 3. 30초 이후 1분당 컷 수와 그래픽 등장 수 (추정)
* **1분당 컷 수**: 약 **14~18회** (평균 3.5~4.5초마다 화면 전환 또는 레이아웃 변경).
* **1분당 그래픽/텍스트 등장 수**: 약 **18~25회** (내레이션의 핵심 키워드, 숫자, 인포그래픽 박스, 화살표 등이 2~3초 간격으로 쉴 새 없이 움직임). 40대 이상 타깃층의 지루함을 방지하기 위해 정적인 구간 없이 지속적인 미세 모션이 유지됩니다.

### 4. 화면 레이어 구성
* **바닥(배경)**: 
  * 은은한 모눈종이 패턴(그리드 라인)이 들어간 깔끔한 화이트/연그레이 배경 또는 블러(가우시안 흐림) 처리된 실사 오피스 영상.
* **중간(미디어 및 데이터)**: 
  * 실사 뉴스/다큐멘터리 B-roll 영상, 스톡 영상, 모서리가 둥근 카드형 사진 프레임.
  * 3D 느낌의 렌더링 아이콘(밥솥, 경찰차, 도장 등) 및 2D 플랫 벡터 일러스트(공무원 실루엣, 타임라인, 순찰선 등).
* **앞(텍스트 및 강조 그래픽)**:
  * 굵은 고딕 폰트의 볼드 텍스트, '합격/불합격' 배지, 스탬프 그래픽, 순위 표시 배지('7위', '6위' 등), 하단 자막 바.

### 5. 글자 연출
* **크기**: 
  * 화면 높이 대비 메인 키워드/숫자는 **약 8~12%**, 중간 인포그래픽 설명 텍스트는 **약 4~6%**, 하단 내레이션 자막은 **약 4.5%**.
* **색상**: 
  * 주요 색상은 화이트 배경 기준 **다크 네이비/차콜(#1A202C)** 본문, 핵심 강조색으로 **블루(#185ADB)**, 위기/경고/감소에는 **선명한 레드/버건디(#E53E3E)** 사용.
* **등장 및 강조 방식**:
  * 글자가 아래에서 위로 부드럽게 튀어 오르는(Slide-up with Bounce) 방식.
  * 둥근 라운드 박스(Pill shape), 붉은색 스탬프 찍힘 효과, 굵은 테두리(Stroke), 네온/글로우 효과.

### 6. 전환과 카메라 워크
* **전환(Transition)**: 컷 간 전환은 깔끔한 하드 컷(Hard Cut)과 좌우 가로 슬라이드 컷(Wipe)을 메인으로 사용.
* **카메라 워크**: 
  * 정지 이미지를 쓸 때 켄 번스(Ken Burns) 효과로 미세하게 지속적인 Slow Zoom-in/Zoom-out 적용.
  * 핵심 텍스트가 찍힐 때 미세한 화면 떨림(Camera Shake)을 주어 임팩트 부여.

### 7. 사운드 연출
* **배경음악(BGM)**:
  * 초반(0~42초): 긴장감과 의문점을 고조시키는 미스터리/뉴스 풍의 차분하면서도 묵직한 신디사이저 비트.
  * 랭킹 시작(42초 이후): 템포가 약간 빨라지며 정보 전달에 집중하게 만드는 테크/다큐멘터리 스타일의 리드미컬한 BGM.
* **효과음(SFX)**:
  * 컷 전환: 가벼운 '휙' (Whoosh) 사운드.
  * 그래픽 등장/텍스트 팝업: '뽁', '퐁' (Pop/UI 클릭음).
  * 수치/충격 단어 강조: 묵직한 베이스 쿵(Thud), 스탬프 쾅(Stamp impact), 종이 넘기는 소리 등 초당 0.5~1회 꼴로 빈번하게 배치.

### 8. 특히 강력한 추천 연출 기법 3가지 (HTML/CSS 구현 가이드)

#### ① 충격 스탬프 타격 연출 ('감소 판정' 도장)
* **무엇인가**: 텍스트나 일러스트 위에 사선으로 기울어진 붉은색 도장이 쾅 찍히는 애니메이션.
* **언제 쓰나**: 기존 통념(정년 보장, 안정적 직장 등)이 무너졌음을 시각적으로 선고할 때.
* **구현 방법**:
```html
<div class="stamp">감소 판정</div>
```
```css
.stamp {
  display: inline-block;
  padding: 8px 16px;
  border: 4px solid #e53e3e;
  color: #e53e3e;
  font-weight: 900;
  border-radius: 8px;
  opacity: 0;
  transform: scale(3) rotate(-15deg);
  animation: stamp-slam 0.4s cubic-bezier(0.1, 0.9, 0.2, 1) forwards;
}

@keyframes stamp-slam {
  0% { opacity: 0; transform: scale(3) rotate(-15deg); }
  70% { opacity: 1; transform: scale(0.9) rotate(-15deg); }
  100% { opacity: 1; transform: scale(1) rotate(-12deg); }
}
```

#### ② 카드 분할 UI (미디어 + 데이터 배지 결합)
* **무엇인가**: 한 화면에 실사 영상/사진 카드와 우측에 대형 숫자/상태 배지(뱃지)를 모던하게 배치하는 그리드 레이아웃.
* **언제 쓰나**: 사례(현장)와 데이터(수치)를 동시에 대비하여 신뢰도를 극대화할 때.
* **구현 방법**:
```html
<div class="split-card-container">
  <div class="media-card"><video src="..." autoplay loop muted></video></div>
  <div class="data-card">
    <span class="sub-label">경쟁률</span>
    <h1 class="big-number">100 대 1</h1>
    <div class="status-badge">✔ 합격</div>
  </div>
</div>
```
```css
.split-card-container {
  display: flex; gap: 24px; align-items: center;
  background: #f8fafc; padding: 30px; border-radius: 20px;
}
.media-card {
  width: 55%; border-radius: 16px; overflow: hidden;
  box-shadow: 0 10px 25px rgba(0,0,0,0.1);
}
.big-number {
  font-size: 64px; font-weight: 900; color: #185adb; margin: 0;
}
.status-badge {
  display: inline-block; background: #e6fffa; color: #319795;
  padding: 6px 14px; border-radius: 20px; font-weight: bold;
}
```

#### ③ 책상/의자가 페이드아웃되는 인력 감축 그래픽
* **무엇인가**: 나열되어 있던 책상(또는 사람 실루엣) 아이콘이 붉은색 점선 테두리만 남긴 채 사라지는(Evaporate) 모션.
* **언제 쓰나**: 인원 감축, 일자리 증발 등 '존재하던 것이 사라지는' 경제적 현상을 직관적으로 체감시킬 때.
* **구현 방법**:
```html
<div class="desk-slot active">🪑</div>
<div class="desk-slot vanishing">🪑</div>
```
```css
.desk-slot {
  width: 80px; height: 80px; display: flex; align-items: center; justify-content: center;
  border-radius: 12px; font-size: 32px;
}
.vanishing {
  border: 2px dashed #e53e3e;
  animation: vanish-seat 1.2s ease forwards;
}
@keyframes vanish-seat {
  0% { opacity: 1; transform: scale(1); background: rgba(229, 62, 62, 0.1); }
  100% { opacity: 0.3; transform: scale(0.8); background: transparent; }
}
```
