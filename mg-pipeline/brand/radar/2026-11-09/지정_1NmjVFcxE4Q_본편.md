### 7. 55세 이상 남성 경제 채널(HTML/CSS 기반) 적용 기법 5가지

50대 이상 남성은 **'나와 내 가족의 생존'**, **'직관적이고 큰 그래픽'**, **'과거 대비 현실의 격차'**에 가장 민감합니다. 복잡한 툴 없이 HTML/CSS 모션으로 구현 가능한 전략 5가지입니다.

#### ① 시청자 지목형 '거울 효과' (Targeting Anchor)
*   **무엇을:** 중반 이탈 방지를 위해 제3자 이야기를 "바로 당신(또는 자녀)의 일"로 끌어옴.
*   **대본:** "솔직히 말씀드리겠습니다. 지금 은퇴하셨거나 퇴직을 앞둔 5060 선배님들, 남의 자식 이야기 아닙니다."
*   **화면(CSS):** 화면 전체가 약간 어두워지며 중앙에 타겟 텍스트 카드만 밝아지는 스포트라이트 박스.
```html
<div class="target-box">
  <span class="badge">경고</span>
  <p>지금 영상을 보시는 <strong>5060 가장</strong>의 일자리 이야기입니다</p>
</div>
<style>
.target-box {
  background: rgba(20, 20, 20, 0.95);
  border-left: 8px solid #d32f2f;
  padding: 24px;
  font-size: 28px;
  animation: pulseGlow 2s infinite alternate;
}
@keyframes pulseGlow {
  0% { box-shadow: 0 0 10px rgba(211, 47, 47, 0.2); }
  100% { box-shadow: 0 0 30px rgba(211, 47, 47, 0.6); }
}
</style>
```

#### ② '역설 질문' 인터랙티브 토글 (Paradox Toggle)
*   **무엇을:** 직관에 반하는 데이터(예: "연금 가입자는 늘었는데 받는 돈은 왜 줄었을까?")를 던져 답을 기다리게 만듦.
*   **대본:** "상식적으로 이해가 안 되시죠? 일자리는 줄어드는데 자격증 등록자는 역대 최대입니다. 왜일까요? 반전이 있습니다."
*   **화면(CSS):** 두 개의 탭이 교차되며 물음표가 느낌표로 바뀌는 CSS 전환.
```html
<div class="toggle-container">
  <div class="tab">사라지는 직업</div>
  <div class="arrow">➔</div>
  <div class="tab highlight">사람은 폭증?</div>
</div>
<style>
.toggle-container { display: flex; gap: 15px; font-size: 26px; align-items: center; }
.tab { padding: 12px 24px; background: #333; border-radius: 8px; color: #fff; }
.tab.highlight {
  background: #ff9800;
  animation: slideBounce 1s ease-in-out infinite alternate;
}
@keyframes slideBounce {
  from { transform: translateY(0); }
  to { transform: translateY(-6px); }
}
</style>
```

*   **무엇을:** 이번 순위를 맺으면서 다음 순위를 안 볼 수 없게 만드는 하단 티저 자막 바.
*   **대본:** "은행원도 충격이지만, 다음 순위에 비하면 아무것도 아닙니다. 2위는 우리 중 절반이 하고 있는 일입니다."
*   **화면(CSS):** 화면 하단에서 스멀스멀 올라오며 깜빡이는 티저 바.
```html
<div class="bottom-bridge">
  <span class="next-label">다음 순위 예고</span>
  <span class="next-title">2위 : 대한민국 사무직 70%가 직면한 현실 ➔</span>
</div>
<style>
.bottom-bridge {
  position: absolute; bottom: 30px; width: 90%;
  background: linear-gradient(90deg, #b71c1c, #000);
  color: white; padding: 15px 30px; font-size: 24px;
  border-radius: 4px; display: flex; justify-content: space-between;
  animation: slideUp 0.8s ease-out;
}
@keyframes slideUp {
  from { transform: translateY(100%); opacity: 0; }
  to { transform: translateY(0); opacity: 1; }
}
</style>
```
