영상 앞부분 180초를 바탕으로 40대 이상 타깃 경제·심리 해설 채널 및 HTML/CSS 모션그래픽 자동화에 적용할 수 있는 연출 분석 보고서입니다.

### 1. 후킹 대본 구조 (0~30초)

*   **문장 1 (0:00~0:05):** "요즘에 음식 배달하는 분들 얘기 들어보면 일감이 없어가지고 엄청나게 힘들다는 말을 많이 하죠. 콜이 말랐다고 합니다."
    *   **사용 장치:** **현실 공감 및 위기감 조성** (최근 체감되는 경기 침체 상황 제시).
*   **문장 2 (0:06~0:10):** "달에 700~800 벌었다고 수익 인증하는 걸 올라오던 게 불과 몇 년 전인데..."
    *   **사용 장치:** **과거 vs 현재의 극단적 대조 & 숫자 충격** ('월 700~800만 원'이라는 자극적 수치로 인지 부조화 유도).
*   **문장 3 (0:10~0:15):** "관련해가지고 마운자로 얘기를 많이 하시더라고요. 마운자로 맞고 배달 음식을 안 먹는 사람이 는 것 같다는 거예요."
    *   **사용 장치:** **트렌드 키워드(비만약) 결합 & 그럴듯한 가설 제시** (시청자의 통념 자극).
*   **문장 4 (0:15~0:22):** "맞으면 먹는 양도 확실히 줄고... 해서 진짜로 요즘에 배달 음식을 잘 안 먹나 하고 찾아보니까..."
    *   **사용 장치:** **오픈 루프(Open Loop)** (연구 자료 인용으로 신빙성을 높인 뒤 "과연 그럴까?" 의문 증폭).
*   **문장 5 (0:22~0:28):** "전혀 아니었습니다. 여전히 잘 먹고 있어요. 배달 플랫폼 결제액이 역대 최고치를 찍었더라고요."
    *   **사용 장치:** **통념 격파(반전) & 팩트 제시** (가설을 단칼에 부정하며 '그렇다면 진짜 원인은 무엇인가?'로 자연스럽게 본론 유입).

### 3. 30초 이후 컷 수 및 그래픽 빈도 (추정)

*   **1분당 컷 전환 수:** **약 15~18회** (평균 3.5~4초당 1컷). 정보 밀도가 높은 지식 채널답게 오디오 호흡에 맞춰 컷이 매우 빠르고 리드미컬하게 전환됨.
*   **1분당 그래픽/자료 등장 수:** **약 10~12회** (신문 기사 발췌문, 카드형 통계, 막대그래프, 원형 차트, 화살표 인덱스 등이 5~6초마다 교체되며 시각적 지루함 차단).

    *   화이트/연회색 톤의 미니멀 모션그래픽 배경 (종이 질감 또는 연한 그라데이션).
*   **중간 레이어 (시각 자료):**

    *   간단한 3D 캐릭터 오브젝트 (배달 스쿠터 주행 애니메이션 등).
*   **앞 레이어 (텍스트/UI):**
    *   화면 좌상단 채널 로고('지식한입') 및 코너명 뱃지.

    *   하단 중앙 고정 자막 (검정 배경 + 노란색/흰색 폰트).

### 5. 글자 연출

*   **자막 크기:** 화면 세로 높이 기준 약 4.5~5.5% (40대 이상도 모바일에서 읽기 편한 볼드 고딕 계열 폰트).
*   **색상 체계:**
    *   기본 자막: **흰색(#FFFFFF)**
    *   핵심 키워드/숫자: **형광 노란색(#FFEB3B)** 또는 주황색
    *   배경: 텍스트 가독성을 위한 어두운 반투명 바(Bar) 또는 드롭 섀도우
*   **등장 및 강조 방식:**
    *   단어 단위로 툭툭 튀어나오는 스케일 팝업(Pop-up) 효과.
    *   기사 인용 시 중요 문장에 **노란색/하늘색 형광펜 하이라이트(Stroke draw)** 처리.
    *   충격적인 수치 등장 시 글리치(지직거림) 및 일시적 폰트 확대.

### 6. 전환과 카메라

*   **화면 전환:** 화려한 3D 트랜지션 대신 **하드 컷(Hard Cut)** 위주로 빠르고 담백하게 전환. 챕터가 바뀌거나 인포그래픽이 나올 때만 부드러운 페이드(Dip to Black)나 좌우 슬라이드 활용.
*   **카메라 무빙:** 정적인 이미지를 보여줄 때 반드시 **켄 번스(Ken Burns) 효과** 적용 (0.5~1초 단위의 미세한 슬로 줌인 또는 서서히 패닝)하여 영상의 템포 유지.
*   **시각 효과:** 강조가 필요한 순간 카메라 셰이크(흔들림)나 펄스(Pulse) 줌인으로 임팩트 부여.

### 7. 소리 연출

*   **배경음악(BGM):**
    *   초반 후킹~가설 반박: 호기심과 긴장감을 자아내는 미스터리/시사 톤의 로우파이 비트.
    *   원인 분석 본론: 경쾌하고 담백한 템포감의 핑거스냅/어쿠스틱 계열 경제 해설 BGM.
*   **효과음(SFX):**
    *   **등장 타이밍:** 그래프 막대가 차오를 때(`Whoosh`), 통계 수치가 바뀔 때(`Tick/Click`), 핵심 단어가 팝업될 때(`Pop`), 기사 인용문이 뜰 때(`카메라 셔터` 또는 `종이 넘기는 소리`).
    *   **빈도:** 평균 3~5초에 1회꼴로 매우 빈번하게 사용되어 청각적 주의를 계속 환기함.

### 8. 추천 기법 3가지 및 HTML/CSS 모션그래픽 구현법

#### ① 비교 막대그래프 카운트업 & 슬라이드 인 (0:26 구간)
*   **무엇을:** 연도별/항목별 통계 데이터를 비교할 때, 바(Bar)가 왼쪽에서 오른쪽으로 부드럽게 늘어나며 수치가 카운트업되는 인포그래픽.
*   **언제 쓰나:** 40대 이상 시청자에게 "배달 시장이 죽지 않고 오히려 결제액이 늘었다"와 같은 경제적 통계를 직관적으로 설득할 때.
*   **HTML·CSS 모션그래픽 구현:**
    ```html
    <div class="bar-chart-container">
      <div class="bar-row">
        <span class="label">2026년 7월</span>
        <div class="bar-track">
          <div class="bar-fill"></div>
        </div>
        <span class="value">약 3조 2,800억 원</span>
      </div>
    </div>
    ```
    ```css
    .bar-fill {
      width: 0%;
      height: 24px;
      background: #2563eb;
      border-radius: 4px;
      animation: growBar 1.2s cubic-bezier(0.16, 1, 0.3, 1) forwards;
    }
    @keyframes growBar {
      to { width: 85%; } /* 목표 수치 비율 */
    }
    ```

#### ② 신문 헤드라인 형광펜 하이라이트 박스 (0:17, 0:31 구간)
*   **무엇을:** 깔끔한 흰색 카드 UI 위에 기사 원문을 띄우고, 핵심 문장에 왼쪽에서 오른쪽으로 형광펜이 그어지듯 배경색이 채워지는 효과.
*   **언제 쓰나:** 공신력 있는 언론 보도, 논문 인용으로 팩트 체크를 진행할 때 시선 집중용.
*   **HTML·CSS 모션그래픽 구현:**
    ```html
    <div class="news-card">
      <p>연합뉴스에 따르면, <span class="highlight">결제 추정액은 전년 동월 대비 18% 늘었다.</span></p>
    </div>
    ```
    ```css
    .highlight {
      background: linear-gradient(to right, rgba(254, 240, 138, 0.9) 50%, transparent 50%);
      background-size: 200% 100%;
      background-position: 100% 0;
      animation: highlightDraw 0.8s 0.3s ease-in-out forwards;
    }
    @keyframes highlightDraw {
      to { background-position: 0 0; }
    }
    ```

#### ③ 미니멀 2분할 뱃지 비교 카드 (1:31 '배달료 개편' 구간)
*   **무엇을:** 지역별(서울 vs 경기·인천 vs 비수도권) 단가 인하를 둥근 박스와 원화 심볼 기호(`₩`)로 정갈하게 배치하여 한눈에 보이게 하는 레이아웃.
*   **언제 쓰나:** 복잡한 정책 변경, 가격 변동, 심리적 전후 차이를 비교하여 설명할 때.
*   **HTML·CSS 모션그래픽 구현:**
    ```html
    <div class="card-grid">
      <div class="fee-card">
        <div class="region-pill">서울</div>
        <div class="amount-badge">₩</div>
        <div class="price">2,500원</div>
      </div>
    </div>
    ```
    ```css
    .fee-card {
      background: #f8fafc;
      border: 1px solid #e2e8f0;
      border-radius: 16px;
      padding: 24px;
      text-align: center;
      transform: translateY(20px);
      opacity: 0;
      animation: cardFadeUp 0.6s cubic-bezier(0.2, 0.8, 0.2, 1) forwards;
    }
    @keyframes cardFadeUp {
      to { transform: translateY(0); opacity: 1; }
    }
    ```
