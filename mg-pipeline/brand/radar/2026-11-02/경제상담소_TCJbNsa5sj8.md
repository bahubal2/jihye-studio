### 1. 후킹 대본 구조 (0~43초 분석)

* **0:00~0:09** | *"중고차 매매단지에서 요즘 이런 말이 나옵니다. 8천만 원, 9천만 원 하던 대형 캠핑카가 3천만 원을 깎아 줘도 사겠다는 사람이 잘 안 나온다고요."*
  * **연출 장치**: **결과/현실 먼저 보여주기 + 숫자 충격**. 시작하자마자 구체적인 액수(8~9천만 원 → -3,000만 원 할인)를 제시하여 즉각적인 가격 파괴 충격을 줌.
* **0:10~0:17** | *"불과 5년 전엔 1억짜리 캠핑카도 없어서 못 판다는 기사가 나오던 차입니다. 주문하면 아홉 달을 기다려야 했죠."*
  * **연출 장치**: **극적 반전(과거 호황 대조) + 희소성 환기**. 5년 전 '1억 캠핑카 완판', '9개월 대기'라는 과거의 열풍을 소환해 현재의 하락세와 극단적인 대비를 형성.
* **0:18~0:26** | *"그 사이 새로 등록되는 캠핑카는 다섯 대 중 한 대도 안 남았고, 캠핑카를 만들어 팔던 회사는 1년 만에 넷 중 하나가 손을 놓았습니다."*
  * **연출 장치**: **통계적 위기감 조성**. 분수 표현("5대 중 1대", "4곳 중 1곳 폐업")으로 직관적인 산업 붕괴의 심각성을 전달.
* **0:27~0:34** | *"오늘은 캠핑카를 산 사람에게 산 그날부터 팔려고 내놓는 날까지 무슨 일이 벌어지는지 따라가 보겠습니다."*
  * **연출 장치**: **스토리텔링 여정 예고(타임라인 구조)**. 구매부터 처분까지의 과정을 다큐멘터리식 서사로 풀겠다고 선언하여 호기심 유발.
* **0:35~0:43** | *"끝까지 보시면 왜 이 차가 값을 내려도 안 팔리는지, 그리고 지금 캠핑카를 사도 될지 판단할 기준이 생기실 겁니다."*
  * **연출 장치**: **오픈 루프(Open Loop) + 실용적 가치 제안**. 시청자가 끝까지 시청해야 하는 명확한 보상(구매 판단 기준)을 제시하여 이탈 방지.

### 3. 30초 이후 컷 수 및 그래픽 빈도 (추정)

* **분당 컷 수**: 약 **10 ~ 13컷** (컷당 평균 4.5 ~ 6초 유지).
  * 40대 이상 타깃 채널에 맞춰 장면이 지나치게 어지럽지 않고, 비주얼과 자막을 충분히 음미할 수 있는 안정적인 호흡.
* **분당 그래픽 등장 수**: 약 **6 ~ 9회** 등장.
  * 가격 변동 카드, 전후 비교 막대 바, 차량 종류별 팝업 카드, 수치 카운트 뱃지 등이 핵심 문장마다 등장.

### 4. 화면 레이어 구조

* **바닥 (배경 레이어)**: 
  * 클레이 토이/스톱모션 디오라마 질감의 AI 생성 이미지(또는 3D 렌더링).
  * 후반부 실사 고속도로 주행 스톡 푸티지 및 정비소 영상 혼합.
* **중간 (콘텐츠/인포 레이어)**:
  * 스마트폰 중고 거래 UI(가격 인하 내역), 뉴스 기사 원문 캡처, 차종별 인셋 사진 카드(레이, 포터 등), 전후 비교 그래프 바.
* **앞 (자막/텍스트 레이어)**:
  * 최하단 전체 내레이션 자막.
  * 상단 좌측 '주제/상황 요약 태그' (예: [2021년 가을 · 서울], [그날 주문하면 언제 받을까?]).
  * 중앙 핵심 데이터 배너 (예: 1억 3,400만 원, 7,300대, 20대꼴).

---

### 5. 글자 연출

* **크기**: 하단 자막은 화면 높이의 약 **4~5%**, 중앙 핵심 수치는 화면 높이의 약 **10~15%**로 큼직하게 배치.
* **색상**: 
  * 본문 자막: 순백색(#FFFFFF) + 소프트 블랙 그림자(가독성 확보).
  * 강조/숫자: 노란색(#FFD700), 주황색(#FF7A00).
  * 위기/인하/취소선: 빨간색(#FF3B30).
* **등장 및 강조 방식**:
  * 숫자가 커지며 튀어나오는 `Scale Pop-in` 기법.
  * 이전 가격 위에 빨간색 가로 취소선이 그어지는 모션.
  * 라운드 박스 형태의 태그 뱃지(Badge) 디자인 다수 활용.

---

### 6. 전환과 카메라

* **전환**: 컷과 컷 사이는 군더더기 없는 하드 컷(Hard Cut) 또는 자연스러운 크로스 디졸브(Cross Dissolve) 위주로 사용하여 피로도를 낮춤.
* **카메라 모션**: 정지된 AI/3D 이미지임에도 불구하고 **미세한 슬로우 줌인/줌아웃(Slow Push-in / Pull-back)**을 100% 적용하여 화면이 멈춰있다는 느낌을 배제.
* **특수 효과**: 영상 전반에 은은한 먼지 입자(Dust Particles)와 빛망울 오버레이를 얹어 아날로그 스톱모션 필름 감성을 부여.

---

### 7. 소리 연출

* **배경음악 (BGM)**: 잔잔한 어쿠스틱 기타와 서정적인 피아노 기반의 인스트루멘탈. 나레이션의 명료성을 방해하지 않도록 중저음역대가 비워진 믹싱.
* **효과음 (SFX)**:
  * 텍스트·뱃지 팝업 시: 가볍고 둔탁하지 않은 미니멀한 '툭(Pop)', '틱(Click)' 사운드.
  * 파격적인 수치 강조 시: 깊은 저음의 묵직한 타격음(Sub Whoosh / Low Thud).
  * 빈도: 문장마다 남발하지 않고 분당 4~6회 수준으로 절제하여 신뢰감 유지.

### 8. 우리 채널에 즉시 도입할 핵심 기법 3가지 (HTML/CSS 모션그래픽 구현법)

#### ① 가격 폭락/취소선 인터랙션 카드 (스마트폰 매물창 연출 - 00:35)
* **언제 쓰나**: 기존 자산 가격의 하락세, 중고가 폭락, 할인 폭을 극적으로 대비할 때.
* **HTML/CSS 구현법**:
```html
<div class="price-card">
  <div class="old-price">8,500만 원</div>
  <div class="old-price">7,000만 원</div>
  <div class="new-price">5,500만 원</div>
</div>
```
```css
/* 취소선이 왼쪽에서 오른쪽으로 그어지는 모션 */
.old-price {
  position: relative;
  color: #888;
  font-size: 1.5rem;
}
.old-price::after {
  content: '';
  position: absolute;
  left: 0; top: 50%;
  width: 100%; height: 3px;
  background-color: #ff3b30;
  transform: scaleX(0);
  transform-origin: left;
  animation: strikeThrough 0.6s ease-out forwards;
}
@keyframes strikeThrough {
  to { transform: scaleX(1); }
}
/* 최종 가격 팝업 */
.new-price {
  color: #ff3b30;
  font-size: 2.2rem;
  font-weight: 800;
  animation: popIn 0.5s 0.7s cubic-bezier(0.175, 0.885, 0.32, 1.275) both;
}
@keyframes popIn {
  from { opacity: 0; transform: scale(0.7); }
  to { opacity: 1; transform: scale(1); }
}
```

#### ② 전후 비교 게이지 트랜지션 (보험료/비용 절감 연출 - 02:14)
* **언제 쓰나**: 정책 변화, 세금/보험료 절감, 소비 격차 등 수치 감소 효과를 체감시킬 때.
* **HTML/CSS 구현법**:
```html
<div class="bar-container">
  <div class="bar before" style="--target-width: 100%;">
    <span>109만 원</span>
  </div>
  <div class="bar after" style="--target-width: 58%;">
    <span>63만 원</span>
  </div>
</div>
```
```css
.bar {
  height: 40px;
  border-radius: 6px;
  margin-bottom: 8px;
  width: 0;
  display: flex;
  align-items: center;
  justify-content: flex-end;
  padding-right: 12px;
  color: #fff;
  font-weight: bold;
  animation: fillBar 1.2s cubic-bezier(0.25, 1, 0.5, 1) forwards;
}
.before { background: #3b82f6; } /* 파란색: 기준 */
.after { background: #ef4444; animation-delay: 0.4s; } /* 빨간색: 변화 */

@keyframes fillBar {
  to { width: var(--target-width); }
}
```

#### ③ 법/규제 완화에 따른 '다중 품목 확장 카드' (차량 종류 팝업 - 01:57)
* **언제 쓰나**: "이것뿐만 아니라 A도, B도, C도 가능해졌다" 식의 조건 확대 및 범위 확장을 설명할 때.

```html

```
