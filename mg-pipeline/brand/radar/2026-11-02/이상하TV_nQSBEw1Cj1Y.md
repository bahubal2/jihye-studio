### 1. 후킹 대본 구조 (0~30초)

* **00:00~00:04**

  * *장치:* **상황·공간 제시 + 호기심 유발** (한국인에게 친숙한 시골 풍경 속 '진풍경'이라는 단어로 시각적 기대감 형성).
* **00:05~00:11**  
  * *대본 요약:* 굽은 허리의 할머니들이 마늘 줄기 끝을 툭툭 꺾어낸다.  
  * *장치:* **시각적 디테일 묘사 + 상식과의 충돌** (애써 키운 농작물의 줄기를 꺾는 기이한 행동 묘사).
* **00:12~00:17**  
  * *대본 요약:* 도시에서 온 외국인 유튜버가 다급하게 이유를 묻는다.  
  * *장치:* **제3자(외국인)의 시선 개입** (시청자가 가질 법한 의문을 대변하며 몰입도 급상승).
* **00:17~00:24**  
  * *대본 요약:* "마늘이 자라는데 왜 꺾나요? 농사 망하는 것 아닙니까?"  
  * *장치:* **위기감 조성 + 직설적 질문(상식적 반론)** (농사를 망친다는 극단적 의문으로 긴장감 부여).
* **00:25~00:30**  
  * *대본 요약:* 김복순 할머니가 땀을 훔치며 혀를 차고 설명을 준비한다.  
  * *장치:* **오픈 루프(Open Loop) + 세대·경험의 반전 암시** ("뭘 모르네"라는 답변을 예고하며 뒤 내용을 무조건 보게 만듦).

### 3. 30초 이후 컷 수 및 그래픽 빈도 (추정)

* **1분당 컷 수 (추정):** 약 **12~15회** (평균 4~5초당 1회 전환). 실사 요리 B-roll, AI 이미지, 통계 기사 캡처, 식당 현장 컷이 매우 리드미컬하게 교체됨.
* **1분당 그래픽/텍스트 배지 등장 수 (추정):** 약 **12~16회**. 컷이 바뀔 때마다 장소 배지, 인물 배지, 키워드 칩, 아이콘, 통계 박스 등이 3초 단위로 갱신됨.

---

### 4. 화면 레이어 구조

* **바닥 레이어 (배경):** 완전한 블랙이 아닌 은은한 비네팅이 들어간 다크 그레이/네이비 그라데이션 배경, 또는 강하게 블러(Blur) 처리된 실사 텍스처.
* **중간 레이어 (비주얼):** 
  * 둥근 모서리(border-radius 16~24px)가 들어간 카드 형태의 실사 사진/영상 (유튜브 클립, 조리 과정 B-roll).
  * 고품질 실사풍 **AI 인물 이미지** (할머니, 외국인 셰프 등).
  * 뉴스 기사 캡처 카드(농림축산식품부 통계), 고기 굽는 실사 스톡 영상.
* **앞 레이어 (정보/텍스트):**
  * 하단 캡슐형 자막 바 (둥근 반투명 박스).
  * 모바일 앱 UI 스타일의 **Pill(알약) 형태 뱃지** (아이콘 + 텍스트).
  * 원형/다각형 경고 스티커, 말풍선, 그래픽 다이어그램 (위장 일러스트, 알리신 화학 구조 등).

### 5. 글자 연출 스타일

* **크기:** 
  * 하단 내레이션 기본 자막: 화면 높이 대비 약 **5~6%** (40대 이상 타깃답게 볼드하고 큼직함).
  * 핵심 강조 키워드/숫자: 화면 대비 **8~12%**.
  * 씬 전환용 타이틀('제때'): 화면 대비 **25~30%**의 압도적 크기.
* **색상:** 화이트(`#FFFFFF`) 기본, 핵심 강조어는 **옐로우(`#FCD34D`)**, **민트/그린**, 경고/의문은 **레드/코랄**.
* **등장 및 강조 방식:**
  * 통통 튀는 탄성 팝업(Scale Bounce).
  * 반투명 블랙 캡슐 박스 안에 텍스트를 배치하여 가독성 100% 확보.
  * 중요한 단어는 형광펜 긋기 효과, 박스 테두리 깜빡임, 단어별 색상 차별화.

---

### 6. 전환과 카메라 워크

* **전환:** 빠른 컷 편집이 기본이며, 챕터가 나뉠 때는 굵은 텍스트 내부로 영상이 비쳐 보이는 **텍스트 마스크 트랜지션** 사용.
* **카메라 워크:** 정지 이미지에 생명력을 주기 위해 모든 스틸 컷에 **미세한 슬로우 줌인/줌아웃(Ken Burns 효과)** 적용.
* **포커스 연출:** 설명 대상 외의 배경을 순식간에 어둡게 누르는 **선택적 딤(Selective Dimming)** 기법 활용.

---

### 7. 소리 (효과음 & BGM)

* **효과음 (SFX):** 
  * 빈도: **3~4초당 1회꼴**로 매우 잦음.
  * 종류: 뱃지/텍스트 팝업 시 경쾌한 '뽁(Pop)'/'뾱', 질문/경고 시 '띵(Alert Bell)', 카드 전환 시 '쉭(Whoosh)', 망치/타격감 있는 '쿵(Sub Bass Thud)'.
* **배경음악 (BGM):**
  * 초기 호기심 유발 구간에서는 미스터리하고 서정적인 어쿠스틱/피아노 선율, 이후 고기 굽는 장면과 외국인 반응에서는 약간의 비트감이 있는 경쾌한 인포메이션 트랙으로 자연스럽게 크로스페이드.

### 8. 우리 채널(40대+ 경제/심리 모션그래픽)에 도입할 강력한 기법 3가지

#### ① 스포트라이트 딤 & 포인터 뱃지 (Spotlight Dim & Pin)
* **무엇인가:** 화면 전체를 어둡게 가라앉히고, 시선을 모아야 하는 특정 인물이나 차트의 특정 지점만 원형으로 밝힌 뒤 옆에 화살표와 뱃지를 띄우는 기법 (00:05 구간).
* **언제 쓰나:** 복잡한 경제 그래프에서 "특정 폭락 시점"을 짚거나, 심리 분석에서 "특정 행동 단서"를 지목할 때.
* **HTML/CSS 구현법:**
  ```html
  <div class="spotlight-container">
    <img src="chart.jpg" class="base-img">
    <div class="dim-mask"></div>
    <div class="pin-badge">폭락 지점 (-40%)</div>
  </div>
  ```
  ```css
  /* box-shadow를 크게 주어 스포트라이트 구멍을 뚫는 기법 */
  .dim-mask {
    position: absolute;
    top: 40%; left: 30%; width: 120px; height: 120px;
    border-radius: 50%;
    box-shadow: 0 0 0 9999px rgba(0, 0, 0, 0.75);
    animation: pulseSpot 1.5s infinite alternate ease-in-out;
  }
  .pin-badge {
    position: absolute;
    top: 35%; left: 45%;
    background: #FCD34D; color: #111;
    padding: 6px 14px; border-radius: 20px; font-weight: 800;
    animation: popBounce 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275);
  }
  ```

#### ② 텍스트 클리핑 마스크 전환 (Text Clipping Mask Transition)
* **무엇인가:** 화면 가득 굵은 키워드(예: '제때', '공포', '금리')가 나타나고 글자 내부로 다음 씬의 영상이 재생되다가, 글자가 급격히 확대되면서 화면 전체가 다음 씬으로 바뀌는 연출 (00:24 구간).
* **언제 쓰나:** "그런데 문제는 '인플레이션'이었습니다"처럼 핵심 경제 용어 하나로 화제를 전환할 때.
* **HTML/CSS 구현법:**
  ```html
  <div class="text-mask-wrapper">
    <h1 class="masked-title">폭 락</h1>
  </div>
  ```
  ```css
  .masked-title {
    font-size: 14vw;
    font-weight: 900;
    background-image: url('next-scene-video-or-img.jpg');
    background-size: cover;
    background-position: center;
    -webkit-background-clip: text;
    -webkit-text-fill-color: transparent;
    animation: zoomThrough 1.2s forwards ease-in-out;
  }
  @keyframes zoomThrough {
    0% { transform: scale(0.8); opacity: 0; }
    50% { transform: scale(1); opacity: 1; }
    100% { transform: scale(15); opacity: 0; } /* 글자 안으로 빨려 들어가며 퇴장 */
  }
  ```

#### ③ 앱 UI형 캡슐 칩 & 대비 데이터 시각화 (Pill Badge & Split Data Card)
* **무엇인가:** 위치, 화자(김복순, 박 과장), 수치 비교(한국 6.2kg vs 서양 0.8kg)를 지도 앱이나 노션 UI처럼 깔끔한 '알약(Pill) 태그'로 띄워 신뢰도를 주는 방식 (01:21, 02:49 구간).
* **언제 쓰나:** 경제 통계 비교(한국인 저축률 vs 미국인 저축률), 논문 출처 표기, 심리학자/인물 소개 시.
* **HTML/CSS 구현법:**
  ```html
  <div class="pill-badge">
    <span class="icon">📊</span>
    <span class="label">1인당 연간 소비량</span>
    <span class="value">6.2kg</span>
  </div>
  ```
  ```css
  .pill-badge {
    display: inline-flex;
    align-items: center;
    gap: 8px;
    background: rgba(20, 20, 24, 0.85);
    backdrop-filter: blur(12px);
    border: 1px solid rgba(255, 255, 255, 0.15);
    padding: 8px 18px;
    border-radius: 9999px;
    color: #fff;
    font-size: 1.1rem;
    box-shadow: 0 8px 20px rgba(0,0,0,0.4);
    animation: slideUpFade 0.5s ease-out;
  }
  .pill-badge .value {
    color: #FCD34D;
    font-weight: 800;
  }
  ```
