### 1. 후킹 대본 구조 (0~30초)

* **[00:00~00:06] "고기를 마음껏 먹는 명륜진사갈비 1인당 가격이, 이제 고깃집 삼겹살 1인분보다 비쌉니다."**
  * **사용 장치:** **상식 뒤집기(역설) + 직관적 비교**. 무한리필 브랜드가 일반 식당 1인분보다 비싸졌다는 충격적인 사실로 즉각적인 주의 집중 유도.
* **[00:07~00:15] "지난해 2만 1,900원까지 올랐는데, 올여름 서울 식당 삼겹살은 평균 2만 1,300원 남짓이었습니다."**
  * **사용 장치:** **구체적 숫자 제시(데이터 증명)**. 앞선 역설적 주장에 실제 가격 통계를 덧붙여 신뢰도와 체감 물가 충격을 강화.
* **[00:16~00:21] "한때는 비슷한 돈이면 실컷 먹는 무한리필로 가는 게 남는 장사였습니다."**
  * **사용 장치:** **공감대 형성(과거 회상)**. 시청자가 겪었던 보편적 경험을 상기시켜 몰입 유도.
* **[00:22~00:27] "그렇게 퍼 주다 보니 가게는 남는 게 없어 가격을 올렸겠거니 싶으실 거예요."**
  * **사용 장치:** **시청자 심리 예측(통념 유도)**. 시청자가 머릿속으로 떠올릴 뻔한 변명/상식을 미리 짚어주며 반전의 밑밥을 깖.
* **[00:28~00:37] "실제로 줄 서서 먹던 무한리필, 뷔페 다섯 곳은, 한창때보다 매장이 많게는 열 곳 가운데 아홉 곳 넘게 사라졌습니다."**
  * **사용 장치:** **위기감 고조 + 숫자 충격(90% 폐업)**.
* **[00:38~00:45] "그런데 그 가게들이 문을 닫은 건, 많이 먹는 손님 때문이 아니었습니다. 진짜 이유는 따로 있었습니다."**
  * **사용 장치:** **반전 + 오픈 루프(Open Loop)**. 손님 때문이 아니라는 통념 파괴 후 '진짜 이유'를 뒤에 밝히겠다며 이탈을 원천 차단.

### 3. 30초 이후 컷 수 및 그래픽 등장 수 (추정)

* **1분당 컷 수 (추정):** 약 **8~10회** (컷당 5~8초 유지).
  * 자극적인 숏폼처럼 1~2초마다 자르지 않고, 40대 이상 타깃에 맞춰 서정적 2D 일러스트를 진득하게 감상하며 내레이션에 집중할 수 있는 템포 유지.
* **1분당 그래픽(배지·수치 박스) 등장 수 (추정):** 약 **3~4회**.
  * 핵심 통계(폐업률, 가격, 매장 수 변동, 고금리 18% 등)가 나올 때마다 상단 중앙 또는 측면에 볼드한 라운드 박스로 시각화.

### 4. 화면 레이어 구조

1. **바닥 레이어 (배경/주제 이미지):**
   * 고품질 **AI 생성 2D 웹툰·애니메이션풍 일러스트** (지브리/신카이 마코토 감성의 따뜻하면서도 서정적인 채색).
   * 실사 사진이나 삭막한 기사 캡처 대신, 감정을 자극하는 극화된 일러스트를 배경으로 전면 배치.
2. **중간 레이어 (핵심 시각 보조 요소):**
   * 핵심 키워드 및 수치를 담은 **입체 배지 박스** (노란색/다크그레이 투톤 라운드 사각 박스, 화살표 `→`, 픽토그램 등).
   * 구독/좋아요 안내용 오버레이 캐릭터 및 UI.
3. **앞 레이어 (자막 및 UI):**
   * 하단 중앙 고정 기본 내레이션 자막 (화이트 텍스트 + 두꺼운 블랙 외곽선).
   * 좌측 상단 코너: `5위 | 명륜진사갈비 · 매장은 버텼다`와 같은 챕터 안내 고정 바.

### 5. 글자(타이포그래피) 연출

* **기본 자막 (하단):**
  * **크기:** 화면 높이의 약 4.5~5%.
  * **폰트/색상:** 둥근 고딕 계열(Sandoll 네모고딕 또는 카페24 아네모네 스타일 추정), 순백색(#FFFFFF) 본문에 진한 블랙 외곽선(Stroke)으로 가독성 극대화.
* **강조 그래픽 박스 (상단/중앙):**
  * **크기:** 화면 높이의 약 8~12%.
  * **색상 조합:** 시인성이 가장 높은 **노란색(#FFD200 계열)** + **진회색/남색(#2B2F3A 계열)** 투톤 조합.
  * **강조 방식:** 텍스트를 단순 노출하지 않고 모서리가 둥근 알약형 박스(Pill shape) 안에 가두어 '숫자'와 '핵심 명사'를 극대화. 등장 시 약간 튀어 오르는 바운스(Scale Pop) 모션 적용.

### 6. 전환과 카메라 워크

* **전환 (Transition):**
  * 컷과 컷 사이는 90% 이상 **디졸브(Cross Dissolve)** 또는 **하드 컷(Cut)** 사용. 복잡한 3D 회전이나 글리치는 배제하여 중장년층의 시각적 피로도를 낮춤.
* **카메라 워크:**
  * 정적인 2D 일러스트에 생명력을 주기 위해 모든 컷에 **미세한 켄 번스(Ken Burns) 효과** 적용 (0.5%~2% 비율로 천천히 줌인되거나 좌우로 천천히 패닝).

---

### 7. 소리 연출

* **배경음악 (BGM):**
  * 어쿠스틱 피아노와 잔잔한 현악기 위주의 서정적이고 감성적인 BGM.
  * 내레이션을 덮지 않도록 볼륨을 -22~-24 LUFS 수준으로 낮게 깔아 편안하고 다큐멘터리 같은 톤 유지.
* **효과음 (SFX):**
  * 남발하지 않고 **핵심 수치 그래픽이 뜰 때만 절제하여 사용**.
  * 귀를 찌르는 '띵' 소리 대신 부드러운 '퐁(Pop)', 종이를 넘기는 소리, 낮게 울리는 '두웅(Impact)' 등 둔탁하고 부드러운 톤 사용 (빈도: 분당 3~5회 내외).

### 8. 벤치마킹할 강력한 연출 기법 3가지 (자동화 모션그래픽 구현법)

#### 기법 1. [숫자 대비 알약형 정보 카드 (Comparison Pill Card)]
* **무엇인가:** 양쪽의 가격이나 수치를 좌우로 대비시키며 시각적으로 즉각 체감하게 만드는 2분할/순차 팝업 카드. (예: `명륜 21,900원` vs `삼겹살 21,300원`)
* **언제 쓰나:** 경제 해설에서 두 지표의 역전 현상이나 극단적 비교를 설명할 때.
* **HTML/CSS 구현법:**
  ```html
  <div class="stat-card">
    <div class="stat-badge">2만 1,900원</div>
    <div class="stat-label">명륜진사갈비 1인당</div>
  </div>
  ```
  ```css
  .stat-card {
    display: flex; flex-direction: column; align-items: center;
    background: #ffffff; border-radius: 12px; padding: 8px 16px;
    box-shadow: 0 8px 20px rgba(0,0,0,0.25);
    animation: popBounce 0.5s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
  }
  .stat-badge {
    background: #ffcc00; color: #111; font-weight: 800; font-size: 22px;
    padding: 4px 12px; border-radius: 20px;
  }
  @keyframes popBounce {
    0% { transform: scale(0.6); opacity: 0; }
    100% { transform: scale(1); opacity: 1; }
  }
  ```

#### 기법 2. [오토 켄 번스(Ken Burns) 배경 엔진]
* **무엇인가:** 고정된 AI 이미지가 멈춰있지 않고, 살아있는 영상처럼 미세하게 전진/후진/이동하는 배경 모션.
* **언제 쓰나:** 2D 일러스트나 자료 화면을 4~7초 이상 정지 상태로 보여줄 때 지루함을 없애기 위해 상시 적용.
* **HTML/CSS 구현법:**
  ```css
  .bg-canvas {
    width: 100vw; height: 100vh; overflow: hidden; position: relative;
  }
  .bg-image {
    width: 100%; height: 100%; object-fit: cover;
    animation: slowKenBurns 8s ease-out forwards;
    transform-origin: center center;
  }
  @keyframes slowKenBurns {
    0% { transform: scale(1); }
    100% { transform: scale(1.06) translate(-1%, -0.5%); }
  }
  ```

#### 기법 3. [상단 고정 챕터 인디케이터 (Persistent Chapter Header)]
* **무엇인가:** 현재 영상의 진행 위치(순위)와 핵심 논점을 시청자가 놓치지 않도록 화면 좌측 상단에 고정해 두는 인포 태그. (예: `5위 | 명륜진사갈비 · 매장은 버텼다`)
* **언제 쓰나:** 랭킹형 콘텐츠나 복잡한 단계별 경제 인과관계를 설명할 때 이탈 방지용 맥락 유지 장치로 활용.
* **HTML/CSS 구현법:**
  ```html
  <div class="chapter-tag">
    <span class="rank-badge">5위</span>
    <span class="rank-title">명륜진사갈비 · 매장은 버텼다</span>
  </div>
  ```
  ```css
  .chapter-tag {
    position: absolute; top: 30px; left: 30px;
    display: inline-flex; align-items: center;
    background: rgba(17, 24, 39, 0.85); backdrop-filter: blur(8px);
    border: 2px solid #ffcc00; border-radius: 8px; overflow: hidden;
  }
  .rank-badge {
    background: #ffcc00; color: #000; font-weight: 900;
    padding: 6px 12px; font-size: 16px;
  }
  .rank-title {
    color: #fff; font-weight: 700; padding: 6px 14px; font-size: 16px;
  }
  ```
