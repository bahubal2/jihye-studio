* **00:04~00:08** *"그 화장품 회사, 청개구리 광고로 온 나라에 이름을 알린 바로 그 참존입니다."*
  * **사용 장치:** **향수 자극 & 브랜드 특정** (4070 타깃이 즉각 떠올릴 수 있는 대표 기억 코드인 '청개구리 참존' 제시).
* **00:09~00:17** *"여러분, 1988년에 국내에서 처음으로 클렌징 워터를 내놓았고, 1990년대엔 업계 매출 3위까지 올랐습니다."*
  * **사용 장치:** **시청자 지목('여러분') & 과거 전성기 숫자 제시** (화려했던 성공 실적 강조).
* **00:18~00:25** *"그런데 참 이상한 일이 벌어졌습니다. 크림은 40년 넘게 팔렸는데 회사에 쌓인 손실은 무려 1,015억 원입니다."*

  * **사용 장치:** **구체적 실패 사건 & 손실 구체화** (억 단위 손실 사건을 연달아 던지며 몰입 극대화).

### 3. 30초 이후 컷 수 및 그래픽 빈도 (추정치)

* **1분당 컷 전환 수:** **약 14~18회** (평균 3~4.5초에 1회 전환)
  * 설명이 이어질 때는 실사 B-roll(스톡 영상)을 길게(4~5초) 보여주며 시청 피로도를 낮추고, 위기/수치 설명 구간에서는 2~3초 간격으로 빠르게 컷을 넘김.
* **1분당 그래픽/자막 모션 등장 수:** **약 8~11회**
  * 대형 숫자 인포그래픽, 타임라인 바(1984~2025), 좌측 상단 코너 그래픽, 기사 헤드라인 캡처 등이 5~7초 간격으로 연속 배치됨.

### 4. 화면 레이어 구조

* **바닥 레이어 (배경):**
  * 톤 다운된 4K 실사 스톡 영상 (물류창고, 빌딩 숲, 자연/사자, 동전·지폐 매크로 샷).
  * 챕터 전환 구간(예: 02:46): 차콜 그레이/블랙의 깔끔한 단색 솔리드 배경.
* **중간 레이어 (보조 자료 & 오버레이):**
  * 다크 딤(Dark Dim, 30~60% 검은색 반투명 오버레이)을 깔아 배경 명도를 낮춤.
  * 신문 기사/방송 캡처, 가로형 연표/타임라인 그래픽, 영문 뉴스 자료.
* **앞 레이어 (핵심 정보 & 자막):**
  * **상단 고정 UI:** 좌측 상단 채널 타이틀 배너, 중앙 상단 화두 질문 배너 ("참치 회사 동원은 왜...").
  * **중앙 텍스트/숫자:** 고대비 굵은 고딕 폰트의 초대형 숫자("1,015억 원", "-352억 원").
  * **하단 자막:** 흰색 고딕 볼드체 + 얇은 블랙 스트로크(가독성 중심).

### 5. 글자 연출 기법

* **크기:**
  * 충격 숫자/헤드라인: 화면 높이의 **약 20~30%**를 차지하는 극대형 볼드체.
  * 요약 카드 및 챕터 타이틀: 화면 높이의 **약 6~10%**.
  * 일반 내레이션 자막: 화면 높이의 **약 3.5~4.5%**.
* **색상 팔레트:**
  * 배경: 다크 차콜 (`#1A1A1A`), 딥 네이비.
  * 기본 텍스트: 화이트 (`#FFFFFF`).
  * 포인트 강조색: **딥 시안 블루 (`#007ACC` / `#1E88E5`)** 및 **경고 옐로우 (`#F5A623`)**.
* **등장 및 강조 방식:**
  * 핵심 키워드가 언급될 때 단어 단위로 0.2초간 튀어나오는 스케일 업(Scale-up, 1.05배 확대 후 복귀).
  * 수치 뒤에 반투명 박스 라벨링 처리, 텍스트 하단에 가로 바(Bar) 라인이 좌에서 우로 그어지는 애니메이션.

### 6. 전환 및 카메라 워크

* **트랜지션 (화면 전환):**
  * 기본 서사 전개 시: **하드 컷(Hard Cut)**과 0.3초 내외의 부드러운 **디졸브(Cross Dissolve)** 혼용.
  * 챕터 변경/주제 전환 시: 스와이프(Wipe) 또는 굵은 챕터 카드(02:46)로 완전히 리셋.
* **카메라 모션:**
  * 스톡 영상 및 정지 이미지에 끊임없이 서서히 다가가는 **슬로우 줌인(Slow Zoom-in / Ken Burns 효과)**을 적용하여 정적인 느낌을 완전히 배제.

### 7. 소리 연출 (SFX & BGM)

* **BGM (배경음악):**
  * 초반(0~45초): 묵직하고 미스터리한 저음 기반의 다큐멘터리/스릴러 신디사이저 사운드.
  * 중반 서사: 피아노와 현악기 중심의 차분하면서도 몰입감 있는 경제 탐사보도 톤.
* **SFX (효과음):**
  * 큰 숫자 팝업 시: 묵직한 타격음(**Deep Thud / Whoosh Boom**).
  * 텍스트 라벨 등장 시: 짧고 둔탁한 팝음(**Pop / Click**).
  * 신문 기사 등장 시: 종이 넘기는 소리(**Paper Rustle**).
  * 빈도: 문맥상 중요한 반전이나 수치가 등장하는 지점마다 **약 5~8초에 1회** 정밀 타격.

### 8. 우리 채널에 도입할 3가지 핵심 기법 (HTML/CSS 모션그래픽 구현 가이드)

#### ① 극대형 수치 충격 카드 (Impact Big Number Counter)
* **언제 쓰나:** 40대 이상 시청자의 뇌리에 적자 규모, 빚, 손실액 등 충격적인 통계를 한눈에 각인시킬 때 (예: 1,015억 원 손실).
* **HTML/CSS 구현 방법:**
  ```html
  <div class="impact-container">
    <div class="label">쌓인 손실</div>
    <div class="big-number">1,015<span class="unit">억원</span></div>
  </div>
  <style>
  .impact-container {
    display: flex; flex-direction: column; align-items: flex-start;
    font-family: 'Pretendard', sans-serif; font-weight: 900;
  }
  .label {
    font-size: 2.2rem; color: #fff; background: rgba(0,0,0,0.6);
    padding: 4px 12px; margin-bottom: 8px; border-left: 4px solid #0084ff;
  }
  .big-number {
    font-size: 6.5rem; color: #0084ff; line-height: 1;
    animation: impactPop 0.45s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
  }
  .unit { font-size: 3.5rem; color: #fff; margin-left: 8px; }
  @keyframes impactPop {
    0% { transform: scale(0.7); opacity: 0; }
    70% { transform: scale(1.06); }
    100% { transform: scale(1); opacity: 1; }
  }
  </style>
  ```

#### ② 가로 타임라인 히스토리 바 (Linear Timeline Infographic)
* **언제 쓰나:** 기업이나 사건의 흥망성쇠(설립 → 전성기 → 위기)를 시간순으로 정리해 시청자가 맥락을 단숨에 이해하게 할 때 (01:31 구간).
* **HTML/CSS 구현 방법:**
  ```html
  <div class="timeline-bar">
    <div class="progress-line"></div>
    <div class="node active" style="left: 10%;">
      <span class="year">1984</span>
      <span class="desc">회사 설립</span>
    </div>
    <div class="node" style="left: 50%;">
      <span class="year">1990년대</span>
      <span class="desc">매출 3위</span>
    </div>
  </div>
  <style>
  .timeline-bar { position: relative; width: 80%; height: 60px; margin: auto; }
  .progress-line {
    position: absolute; top: 15px; width: 0%; height: 3px; background: #fff;
    animation: lineFill 1.5s ease-out forwards;
  }
  .node {
    position: absolute; top: 5px; opacity: 0; transform: translateY(10px);
    animation: nodeFadeUp 0.5s ease forwards 0.8s;
  }
  .year { display: block; font-size: 1.2rem; color: #aaa; }
  .desc { font-size: 1.5rem; font-weight: bold; color: #fff; }
  @keyframes lineFill { to { width: 100%; } }
  @keyframes nodeFadeUp { to { opacity: 1; transform: translateY(0); } }
  </style>
  ```

#### ③ 미니멀 챕터 분기 디바이더 (Clean Chapter Slate)
* **언제 쓰나:** 3~5분 이상의 긴 호흡에서 시청자의 집중력이 흐려질 때, 다음 주제로 완전히 환기시키는 정적(Pause) 구간 (02:46 구간).
* **HTML/CSS 구현 방법:**
  ```html
  <div class="chapter-card">
    <div class="left-box">
      <span class="badge">Chapter. 1</span>
      <h2 class="title">참존의<br>지금 숫자</h2>
      <div class="accent-bar"></div>
    </div>
    <div class="right-num">01</div>
  </div>
  <style>
  .chapter-card {
    display: flex; justify-content: space-between; align-items: center;
    width: 100vw; height: 100vh; background: #161616; padding: 0 15%;
    box-sizing: border-box; font-family: 'Pretendard', sans-serif;
  }
  .badge { color: #f5a623; font-weight: bold; font-size: 1.3rem; }
  .title { font-size: 3.5rem; color: #fff; margin: 15px 0; line-height: 1.2; }
  .accent-bar { width: 60px; height: 4px; background: #f5a623; }
  .right-num {
    font-size: 14rem; font-weight: 900; color: #252525;
    animation: fadeInNum 0.8s ease-out forwards;
  }
  @keyframes fadeInNum { from { opacity: 0; transform: scale(0.9); } to { opacity: 1; transform: scale(1); } }
  </style>
  ```
