### 1. 후킹 대본 구조 (0~30초)

* **[0:10~0:14]** *"가스도 기름도 한 방울 안 태우는데 방바닥은 뜨끈뜨끈합니다."*

### 5. 글자(타이포그래피) 연출

* **크기:**
  * 기본 나레이션 자막: 화면 높이의 약 **5~6%** (중장년층 타깃에 맞춰 모바일에서도 또렷하게 읽힘).
  * 키워드/숫자 인포그래픽: 화면 높이의 **15~25%** 수준으로 대형 배치.
* **색상 전략:**
  * **부정/위험/비용:** 선명한 레드 (#FF2E2E) $\rightarrow$ *23만원, 가스비 폭탄, 120만원*
  * **절감/이득/안정:** 딥 그린 (#00A859) $\rightarrow$ *5만원, 80% 비용 절감*
  * **키워드/라벨:** 형광 옐로우 (#FFE600) 바탕에 검정 글씨 $\rightarrow$ *히트펌프, 훈훈하게, 1년 데이터*
* **등장/강조 방식:**
  * 단어 단위로 쪼개어 통통 튀며 등장하거나, 쿵 찍히는 '도장(스탬프)' 스케일 애니메이션 사용.

### 6. 전환과 카메라 워크

* **전환(Transition):** 대부분 군더더기 없는 **하드 컷(Hard Cut)**과 부드러운 **디졸브(Crossfade)** 중심. 그래픽 설명 구간에서는 장면 전체를 좌우로 슬라이드하지 않고 요소들만 빠르게 교체.
* **카메라 워크:** 정지된 일러스트에 생동감을 주기 위해 **미세한 켄 번스 효과(Slow Zoom-in / Zoom-out)**를 100% 적용. 인물의 감정이 고조될 때(예: 난방비 보고 놀람) 살짝 빠른 줌인 적용.

### 7. 소리 연출

* **내레이션:** 또렷한 발음의 신뢰감 있는 남성 톤 (AI 보이스 또는 정갈한 성우 톤).
* **배경음(BGM):** 
  * 도입부: 호기심과 긴장감을 자극하는 밝고 리드미컬한 퓨전 어쿠스틱/재즈풍 BGM.
  * 중반부: 실제 고민/비용 부담 구간에서는 베이스 위주의 차분한 톤으로 전환.
* **효과음(SFX):**
  * 숫자 80% 뜰 때: 묵직한 '쿵/퍽' 임팩트 사운드.
  * 계산기/돈 관련: 경쾌한 '동전/찰칵' 소리.
  * 돋보기/손 이동: 부드러운 '슉(Whoosh)' 사운드.
  * 평균 3~5초에 한 번씩 시각 요소 등장에 맞춰 SFX를 넣어 시청각 싱크 일치.

### 8. 우리 채널이 즉시 벤치마킹할 핵심 기법 3가지 (HTML/CSS 구현법 포함)

#### ① [전/후 비용 대비 카드 + 절감 스탬프]
* **언제 쓰나:** 경제적 손익, 전후 비교, 정책 변화에 따른 혜택을 3초 안에 각인시킬 때.
* **HTML/CSS 구현 원리:**
```html
<div class="compare-card">
  <div class="row old">기존: <span class="num red">23만 원</span></div>
  <div class="row new">개선 후: <span class="num green">5만 원</span></div>
  <div class="stamp-badge">80% 절감</div>
</div>

<style>
.stamp-badge {
  position: absolute;
  top: 10%; left: -20px;
  background: #00A859; color: #fff;
  font-size: 2.2rem; font-weight: 900;
  padding: 10px 20px; border-radius: 8px;
  transform: scale(3) rotate(-15deg);
  opacity: 0;
  /* 스탬프 쾅 찍히는 바운스 효과 */
  animation: stampDown 0.4s 0.6s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
}
@keyframes stampDown {
  to { transform: scale(1) rotate(-8deg); opacity: 1; }
}
</style>
```

#### ② [주택 단면도 기반 에너지/열 순환 다이어그램]
* **언제 쓰나:** 복잡한 경제 메커니즘(돈의 흐름, 세금 환급 구조, 심리 회로)을 직관적으로 보여줄 때.
* **HTML/CSS 구현 원리:**
  * 집 단면 일러스트 위에 SVG `<path>`를 깔고 `stroke-dashoffset` 애니메이션으로 열(화살표/파티클)이 실외기에서 온수 탱크로 흐르는 모습을 자동 렌더링.
```html
<svg width="400" height="200">
  <!-- 파이프 경로 -->
  <path d="M 50 150 L 200 150 L 200 50" fill="none" stroke="#ff4500" stroke-width="6" 
        stroke-dasharray="10 6" class="flowing-heat" />
</svg>
<style>
.flowing-heat {
  animation: heatFlow 1s linear infinite;
}
@keyframes heatFlow {
  from { stroke-dashoffset: 32; }
  to { stroke-dashoffset: 0; }
}
</style>
```

#### ③ [포스트잇/네임택 형태의 직관적 라벨링]
* **언제 쓰나:** 화면 내 특정 오브젝트(인물, 물건, 통장, 서류)에 즉시 시선을 집중시키고 텍스트 설명을 달 때.
* **HTML/CSS 구현 원리:**
```html
<div class="label-tag">기름값 120만원</div>

<style>
.label-tag {
  display: inline-block;
  background: #FFE600;
  color: #111;
  font-weight: 800;
  font-size: 1.1rem;
  padding: 4px 10px;
  border-radius: 4px;
  box-shadow: 2px 3px 6px rgba(0,0,0,0.25);
  transform: rotate(-2deg);
  animation: popIn 0.3s cubic-bezier(0.34, 1.56, 0.64, 1) both;
}
@keyframes popIn {
  0% { transform: scale(0.4) rotate(10deg); opacity: 0; }
  100% { transform: scale(1) rotate(-2deg); opacity: 1; }
}
</style>
```
