### 1. 후킹 대본 구조 (0~30초)

*   **문장 1 (0:00~0:04):** *"야, 한국 사람들 안 와도 돼! 어차피 중국 손님들이 줄 서서 온다고!"*
    *   **장치:** **직접 인용/도발적 대사(어그로) + 갈등 유발**. 시청자의 감정(분노·호기심)을 즉각 자극하는 극단적인 발언으로 시작.
*   **문장 2 (0:04~0:10):** *불과 몇 년 전만 해도 제주도 상인들이 콧방귀를 뀌며 내뱉던 말입니다.*
    *   **장치:** **상황 규정 + 비판적 프레이밍**. 발언의 주체를 명확히 밝히며 대중적 공분 서사 형성.
*   **문장 3 (0:10~0:16):** *비계 덩어리 삼겹살에 10만 원짜리 갈치조림을 팔아치우며 배짱을 부렸죠.*
    *   **장치:** **구체적 실물 사례(비계 삼겹살) + 숫자 충격(10만 원)**. 뉴스 이슈로 검증된 시각적·금전적 피해 사실 소환.
*   **문장 4 (0:16~0:19):** *근데 지금 그 거리, 어떻게 됐는지 아세요?*
    *   **장치:** **질문(호기심 유발) + 오픈 루프(Open Loop)**. "현재 어떤 파국을 맞았는가?"에 대한 결말 유예.
*   **문장 5 (0:19~0:24):** *한국인은 싹 사라지고 온 거리가 붉은 중국어 간판으로 도배됐습니다.*
    *   **장치:** **반전/결과 선공개(시각적 충격)**. 자업자득의 1단계 결과 노출.
*   **문장 6 (0:24~0:30):** *심지어 그 중국인들조차 편의점 앞에서 컵라면만 먹고 쓰레기만 버리고 간대요.*
    *   **장치:** **2차 반전 + 카타르시스/자업자득 강조**. 기대했던 중국 특수마저 허상이었음을 폭로하여 본론 시청 유도.

### 3. 30초 이후 분당 컷 수 및 그래픽 등장 빈도 (추정)

*   **분당 컷(화면 전환) 수:** 약 **18~22회** (평균 2.5~3.5초당 1회 컷 전환 또는 주요 레이어 교체).
*   **분당 그래픽/인포그래픽 등장 수:** 분당 약 **25~35개** (인포그래픽 아이콘, 화살표, 숫자 카운터, 기사 박스, 텍스트 라벨 등이 1~2초 간격으로 누적·교체됨). 정적 이미지를 그대로 두지 않고 화살표나 라벨을 계속 추가해 동적 느낌 유지.

### 4. 화면 레이어 구성

*   **바닥 레이어 (배경):**
    *   완전한 검은색보다는 명도를 낮추고 블러(가우시안 블러)를 먹인 **관련 실사 영상/사진** 또는 깔끔한 라이트 그레이/베이지 톤의 텍스처 배경.
*   **중간 레이어 (시각 자료):**
    *   실제 뉴스 보도 사진, 현장 캡처 사진(고깃집, 거리, 공항 등).
    *   신문/방송 뉴스 기사 헤드라인 캡처(메모지 핀 형태 연출).
    *   원형/도넛 그래프 및 수치 인포그래픽, 픽토그램 아이콘(손님, 돼지, 렌터카, 비행기 등).
*   **앞 레이어 (텍스트/모션 UI):**
    *   화면 중앙/상단 핵심 키워드 강조 타이포그래피.
    *   메뉴판 UI, 수치 비교 박스, 붉은 경고창/도장 효과.
    *   화면 최하단: 2줄 이하의 나레이션 싱크 자막(검은 반투명 바 또는 드롭섀도우 폰트).

### 5. 글자(타이포그래피) 연출

*   **크기:** 
    *   핵심 키워드/헤드라인: 화면 높이 대비 약 **10~15%** (크고 굵은 산세리프).
    *   하단 대본 자막: 화면 높이 대비 약 **4~5%**.
*   **색상:**
    *   기본 텍스트: 흰색(`#FFFFFF`), 짙은 차콜/블랙(`#222222`).
    *   강조 컬러: 붉은색(`#E53935` - 경고/중국/분노), 노란색/주황색(`#FFA000` - 수치/경고).
*   **등장 및 강조 방식:**
    *   글자 박스가 아래에서 위로 살짝 튀어 오르는 바운스(Bounce) 팝업.
    *   중요 키워드 뒤에 형광펜/네모 박스 테두리가 쳐지거나 빨간색 스탬프(`콧방귀`, `안방까지 털렸다`) 쾅 찍히는 연출.

### 6. 전환과 카메라 워크

*   **화면 전환:** 단순 컷 편집(하드 컷) 비율이 높으나, 레이어 내부 요소는 **빠른 페이드 인(Fade-in) + 슬라이드(Slide up/down)** 활용.
*   **카메라(모션):** 
    *   정지 사진에 미세한 켄 번스 효과(Ken Burns - 천천히 줌인 또는 줌아웃).
    *   충격적인 대목에서 순간적인 **스냅 줌인(Snap Zoom)** 또는 미세한 **화면 흔들림(Camera Shake)**으로 분노·충격 감정 동조.

### 7. 소리(사운드 디자인)

*   **효과음 (SFX):**
    *   등장 빈도: 약 2~4초마다 1회 발생.
    *   종류: UI 팝업음('뽁', '띡'), 스탬프 찍히는 둔탁한 '쿵(Thud)', 종이 넘어가는 소리(기사 인용 시 '스윽'), 돈 계산음('칭'), 경고음('삐-').
*   **배경음악 (BGM):**
    *   초반부: 낮고 긴장감 넘치는 텐션의 베이스/신스 비트(시사 고발 프로 특유의 긴박한 분위기).
    *   설명 구간: 일정한 리듬을 유지하며 내레이션 전달력을 해치지 않는 절제된 다운템포 비트.

### 8. 강력한 연출 기법 3가지 (HTML/CSS 모션그래픽 구현법)

#### ① UI 카드 순차 빌드업 (메뉴판/영수증 인포그래픽)
*   **무엇을:** 가격 폭리나 영수증 내역을 실제 스마트폰 화면이나 식당 메뉴판 UI 카드 형태로 한 줄씩 차례대로 띄워 객관적 근거를 보여줌 (0:10 삼겹살 10만원 연출).
*   **언제 쓰나:** 경제적 불합리함, 비용 폭증, 수치 비교를 시각화할 때.
*   **HTML·CSS 구현법:**
```html
<div class="menu-card">
  <div class="row item-1">삼겹살 <span>비계 덩어리</span></div>
  <div class="row item-2">갈치조림 <span>100,000원</span></div>
  <div class="row alert-badge">배짱 장사</div>
</div>
```
```css
.row {
  opacity: 0;
  transform: translateY(15px);
  animation: slideUp 0.4s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
.item-1 { animation-delay: 0.2s; }
.item-2 { animation-delay: 0.6s; }
.alert-badge { 
  animation-delay: 1.0s;
  background: #ff4d4f; color: white;
}
@keyframes slideUp {
  to { opacity: 1; transform: translateY(0); }
}
```

#### ② '간판 도배' 그리드 오버레이 애니메이션 (0:21)
*   **무엇을:** 한국 거리 사진 위로 빨간색 중국어 간판 박스들이 격자 그리드를 1개씩 덮어버리며 '잠식당한 상권'을 비유적으로 표현.
*   **언제 쓰나:** 시장 독점, 특정 세력/외국 자본의 유입으로 기존 생태계가 잠식되는 현상을 설명할 때.
*   **HTML·CSS 구현법:**
```html
<div class="street-container">
  <img src="street.jpg" class="bg-img" />
  <div class="grid-overlay">
    <div class="sign-box" style="--delay: 0.1s;">간판 1</div>
    <div class="sign-box" style="--delay: 0.2s;">간판 2</div>
    <div class="sign-box" style="--delay: 0.3s;">간판 3</div>
    <div class="sign-box" style="--delay: 0.4s;">간판 4</div>
  </div>
</div>
```
```css
.grid-overlay {
  display: grid; grid-template-columns: repeat(4, 1fr);
  position: absolute; inset: 0;
}
.sign-box {
  background: rgba(200, 20, 20, 0.85);
  border: 1px solid #ffd700;
  transform: scale(0.7); opacity: 0;
  animation: popIn 0.3s ease-out forwards;
  animation-delay: var(--delay);
}
@keyframes popIn {
  to { transform: scale(1); opacity: 1; }
}
```

#### ③ 원형 프로그레스 카운터 + 픽토그램 비교 (02:46)
*   **무엇을:** 원형 그래프가 0%에서 70%까지 빠르게 차오르며 옆에 최종 인원수(`159만 명`)가 굵게 박히는 통계 그래픽.
*   **언제 쓰나:** 40대 이상 타깃에게 통계의 심각성(압도적 비중)을 직관적으로 각인시킬 때.
*   **HTML·CSS 구현법:**
```html
<div class="stat-container">
  <svg class="progress-ring" width="120" height="120">
    <circle class="ring-bg" stroke="#eee" stroke-width="12" fill="transparent" r="50" cx="60" cy="60"/>
    <circle class="ring-fill" stroke="#e53935" stroke-width="12" fill="transparent" r="50" cx="60" cy="60"/>
  </svg>
  <div class="number">70%</div>
</div>
```
```css
.ring-fill {
  stroke-dasharray: 314;
  stroke-dashoffset: 314; /* 2 * PI * r */
  transform: rotate(-90deg); transform-origin: 50% 50%;
  animation: fillAnim 1.2s cubic-bezier(0.2, 0.8, 0.2, 1) forwards;
}
@keyframes fillAnim {
  to { stroke-dashoffset: 94.2; } /* 70% 지점: 314 * (1 - 0.70) */
}
```
