### 1. 후킹 대본 구조 (0~30초)

* **문장 1**: "전쟁 때문에 러시아 경제가 갈려나가고 있습니다. 여기저기서 문제가 터지고 있는데..."
  * **장치**: **충격적 상황 제시(결과 먼저 보여주기)**. 강력하고 직관적인 어휘("갈려나가다", "터지다")로 위기감 조성.
* **문장 2**: "제일 눈에 띄는 문제가 기름이 없어요. 기름 받으러 주유소를 가면은 줄을 선대요. 몇 시간을 선대요."
  * **장치**: **일상적 불편/반전 유도**. '전쟁'이라는 거대 담론을 '주유소 줄서기'라는 피부에 와닿는 체감형 결핍으로 치환.
* **문장 3**: "구매량 제한이 걸린 지역도 있어 가지고 얼마 넣지도 못한다고 합니다."
  * **장치**: **구체적 사례/오픈 루프 시작**. 제한 조치 사실을 던져 의아함 유발.
* **문장 4**: "근데 생각해보면 러시아는 산유국이잖아요. 그냥 산유국도 아니에요. 생산량이 전 세계 2등이야."
  * **장치**: **강력한 인지적 반전(Paradox) 및 숫자 충격**. "세계 2위 산유국에 왜 기름이 없는가?"라는 핵심 의문을 심어 이탈을 방지함.

### 3. 30초 이후 컷 수 및 그래픽 빈도 (추정)

* **1분당 컷 수**: 약 **18~22컷** (평균 2.5~3.5초당 1컷 전환). 40대 이상 타깃 채널에 맞게 눈이 피로하지 않으면서도 지루할 틈을 주지 않는 빠른 호흡 유지.
* **그래픽 등장 수**: 1분당 **10~14개** (데이터 차트, 지도, 뉴스 기사 캡처, AI 생성 일러스트, 자막 박스 등이 매 컷 단위로 등장).

### 5. 글자(타이포그래피) 연출

* **크기**: 메인 자막은 화면 높이 대비 약 **4~5%**, 그래프/차트의 핵심 수치는 **8~12%**로 시원하게 배치하여 중장년층 가독성 극대화.
* **색상**: 
  * 본문 자막: 순백색(`#FFFFFF`) 굵은 고딕(산세리프).
  * 강조 텍스트: 채도 높은 옐로우(`#FFDD00`) 또는 시안/블루(`#3894FF`).
* **등장 및 강조 방식**:
  * 자막 뒤에 반투명한 블랙/다크그레이 라운드 박스를 깔아 배경 영상과 완벽히 분리.
  * 뉴스 기사 인용 시 핵심 문장에 형광펜이 그어지는 듯한 라인 애니메이션.
  * 주요 통계치(예: "67.3%", "2배")는 숫자가 카운트업되거나 크기가 일시적으로 커졌다가 제자리로 돌아오는 펄스(Pulse) 모션 사용.

### 6. 전환과 카메라 워크

* **전환(Transition)**:
  * 인포그래픽 및 자료 전환 시 깔끔한 하드 컷(Hard Cut) 위주이며, 문맥이 바뀔 때 부드러운 디졸브(Fade/Cross Dissolve) 혼용.
* **카메라 연출 (2.5D / 3D Ken Burns Effect)**:
  * 정지된 스톡 이미지나 표에도 105~115% 서서히 줌인(Slow Zoom-in) 또는 대각선 팬(Pan)을 적용하여 정적인 느낌을 완전히 배제.
  * 정유시설 드론 피격 등 위기 상황 자료화면에서는 미세한 흔들림(Handheld Camera Shake) 효과로 현장감과 불안감 전달.

### 7. 음향 (사운드 디자인)

* **배경음(BGM)**:
  * 인트로~본론 전반: 긴장감 있는 앰비언트 신스 베이스 + 일정한 템포의 틱톡(Ticking) 비트가 깔려 진지하고 지적인 탐사보도 톤 유지.
* **효과음(SFX)**:
  * **Whoosh/스위시**: 화면 컷 전환, 그래프 막대가 솟아오를 때.
  * **디지털 클릭/팝**: 데이터 수치 라벨 등장, 차트 포인트 찍힐 때.
  * **저음 쿵(Boom/Hit)**: 심각한 지표(적자 비율, 공장 폐쇄 등)를 선고하듯 던질 때 사용.
  * 평균 4~6초에 1회꼴로 배치되어 시각적 정보 변화와 정확히 싱크됨.

### 8. HTML/CSS 기반 모션그래픽 추천 기법 3가지

우리 채널의 자동화 렌더링(Node.js + Puppeteer 등 HTML Canvas/DOM 캡처 파이프라인)에 바로 적용할 수 있는 기법들입니다.

#### ① 동적 가로 막대 차트 하이라이트 (00:13 산유국 순위 연출)
* **어디에 쓰나**: 국가별/항목별 통계 순위를 보여주며 특정 대상(러시아/한국 등)을 시각적으로 집중시킬 때.
* **HTML/CSS 구현 방법**:
  * 막대 요소의 `width`를 0에서 목표치(`%`)로 애니메이션(`transition: width 1s cubic-bezier(0.2, 0.8, 0.2, 1)`).
  * 1위~10위 중 주목할 대상(러시아) 행에만 별도 CSS 클래스(`.highlight`)를 부여해 색상을 진한 블루(`#0052CC`)로 지정하고, CSS `filter: drop-shadow(...)` 및 우측 끝 수치 태그가 0.2초 뒤 `scale(1) -> 1.15 -> 1`로 바운스되도록 키프레임 설정.

#### ② 텍스트 형광펜 하이라이트 오버레이 (01:27, 02:38 기사 인용 연출)
* **어디에 쓰나**: 공식 언론사 기사나 보고서 원문을 띄우고 신뢰도를 부여하면서 핵심 문장을 읽어줄 때.
* **HTML/CSS 구현 방법**:
  * 배경은 어두운 종이/카드 형태(`background: rgba(20,20,20,0.85); backdrop-filter: blur(4px)`).
  * 기사 텍스트 중 강조할 문장을 `<mark class="highlight">`로 감쌈.
  * `linear-gradient`와 `background-size`를 활용해 밑줄/형광펜이 좌에서 우로 차오르는 효과 구현:
    ```css
    mark.highlight {
      background: linear-gradient(to right, rgba(255, 215, 0, 0.4), rgba(255, 215, 0, 0.4)) no-repeat;
      background-size: 0% 100%;
      animation: drawMarker 0.8s ease-out forwards 0.3s;
    }
    @keyframes drawMarker {
      to { background-size: 100% 100%; }
    }
    ```

#### ③ 원유/에너지 배럴 그리드 & 줌인 뷰 (00:17 드럼통 연출의 웹식 재해석)
* **어디에 쓰나**: 특정 자원/비용의 막대한 양이나 공급 과잉/결핍을 시각적으로 압도감 있게 보여줄 때.
* **HTML/CSS 구현 방법**:
  * CSS Grid(`grid-template-columns: repeat(6, 1fr)`)로 아이콘/오브젝트 컨테이너를 가득 채움.
  * 전체 래퍼(`.grid-wrapper`)에 3D 원근감 부여:
    ```css
    .grid-container {
      perspective: 800px;
      overflow: hidden;
    }
    .grid-wrapper {
      transform: rotateX(20deg) scale(1);
      animation: slowDrift 6s infinite alternate ease-in-out;
    }
    @keyframes slowDrift {
      to { transform: rotateX(15deg) scale(1.08) translateY(-10px); }
    }
    ```
  * 3D 소프트웨어 없이도 CSS 3D Transform만으로 역동적인 공간감을 자동 생성할 수 있습니다.
