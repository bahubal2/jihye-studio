### 1. 후킹 대본 구조 (0~30초)

*   **문장 1 (0:00~0:05):** "경북 경산의 한 대추밭, 지금 한창 수확철이어야 할 과수원에 대추를 따는 사람이 없습니다."
    *   **사용 장치:** **상황적 반전/결핍 제시** (수확철 풍경 vs 일손이 전무한 텅 빈 과수원).
*   **문장 2 (0:06~0:14):** "탁구공만 한 열매가 가지를 잔뜩 휘어감기고 있는데, 정작 농부는 트랙터를 몰고 와서 그 나무들을 통째로 갈아엎고 있습니다."
    *   **사용 장치:** **시각적 충격 및 파괴적 결말 선공개(결과 먼저 보여주기)** (멀쩡하고 풍성한 작물을 트랙터로 부수는 극단적 행동).
*   **문장 3 (0:14~0:25):** "불과 몇 년 전까지만 해도 한 알에 천 원을 호가하던 과일 사과대추, 귀농인들이 앞다투어 뛰어들었던 황금 작물이 지금은 팔면 팔수록 손해를 보는 독이 되어버렸습니다."
    *   **사용 장치:** **숫자 대비(한 알 1,000원) 및 극단적 대비/반전** ('황금 작물' → '팔수록 손해 보는 독').
*   **문장 4 (0:26~0:33):** "수확을 하면 할수록 적자가 커지니 차라리 안 따는 게 남는 장사라는 끔찍한 계산. 대체 이 작은 열매에 무슨 일이 벌어진 걸까요?"
    *   **사용 장치:** **모순적 논리(안 따는 게 이득) + 질문형 오픈 루프(Open Loop)** (원인에 대한 호기심 극대화).

### 4. 화면 레이어 구조

*   **바닥 레이어 (배경):**
    *   연한 회색/화이트톤의 미니멀 텍스처 배경(도안 느낌).
    *   또는 현장 실사 영상/뉴스 클립에 가우시안 블러(Blur) 및 밝기(Brightness)를 올려 그래픽 시인성을 확보한 베이스.
*   **중간 레이어 (시각 자료):**
    *   실사 스톡/보도자료 영상(트랙터 전복, 과수원, 농작 작업).
    *   원형 마스크 처리된 실물 사진(일반 대추 vs 사과대추 크기 비교).
    *   스티커 스타일(흰색 외곽선/드롭섀도우)의 2.5D 과일, 손, 사람, 농기계 일러스트.
*   **앞 레이어 (정보 및 텍스트):**

    *   하단 기본 자막 바 (검은 반투명 박스 + 고딕 볼드체 흰 텍스트).
    *   화면 중앙 임팩트 타이포그래피 (도장 찍히듯 등장하는 붉은색/노란색 타이틀).
    *   우상단 채널 시그니처 워터마크 로고.

### 5. 글자(타이포그래피) 연출

*   **크기:**
    *   기본 내레이션 자막: 화면 세로 높이 대비 약 **4~5%** (가독성 최우선).
    *   핵심 키워드/헤드카피: 화면 세로 높이 대비 약 **10~15%** (한눈에 각인).
*   **색상 체계:**
    *   기본: White (`#FFFFFF`).
    *   부정/경고/충격: Red (`#E53935`) 또는 Dark Red.
    *   숫자/가격/신뢰/강조: Blue (`#1E88E5`) 또는 Gold/Yellow.
*   **등장 및 강조 방식:**
    *   **스탬프(Stamp) 효과:** 빨간 모서리 둥근 직사각형 테두리 박스가 회전하며 쿵 찍히듯 스케일 다운.
    *   **뱃지 팝업:** 동그라미/말풍선 형태의 배경 박스에 숫자가 카운트업 또는 튀어나오며 등장.
    *   **볼드 하이라이트:** 문장 전체 중 특정 단어("안 따는 게 남는 장사", "통째로 갈아엎기")만 포인트 컬러와 큰 폰트로 처리.

### 6. 전환과 카메라 워크

*   **전환(Transition):**
    *   하드 컷(Cut)이 약 70%로 가장 지배적 (스토리 전개가 빠름).
    *   그래픽 전환 시 스무스한 페이드(Fade) 및 모션 블러를 동반한 좌우/상하 슬라이드.
*   **카메라 워크:**
    *   스틸 이미지(사진/일러스트)에는 반드시 **서서히 줌인(Ken Burns 효과)**을 주어 정적임을 탈피.
    *   비교 씬에서는 좌측에서 우측으로 자연스럽게 팬(Pan)되거나 스케일이 1.0에서 1.15로 확대되며 시선 유도.

### 7. 소리(사운드 디자인) 연출

*   **배경음악 (BGM):**
    *   0~30초: 묵직하고 긴장감을 주는 단조(Minor)의 앰비언트 베이스와 느린 펄스 비트.
    *   이후(성공 스토리 회상 구간): 경쾌하고 희망적인 피아노/어쿠스틱 톤으로 톤 체인지.
*   **효과음 (SFX):**
    *   **팝(Pop)/뿅:** 스티커형 일러스트나 데이터 아이콘이 튀어나올 때.
    *   **우시(Whoosh):** 화면 전환, 그래프 곡선이 빠르게 그려질 때.
    *   **도장 쾅(Thud/Impact):** '통째로 갈아엎기', '적자' 등 충격 텍스트가 꽂힐 때 저음 임팩트 사운드.
    *   **금속성 찰칵(Click/Coin):** 가격(천 원), 당도 수치(브릭스) 강조 시.

### 8. 우리 채널(40대+ 경제·심리) 적용 추천 기법 3가지

#### ① 직관적 크기·가치 비교 듀얼 팝업 (대추 vs 사과대추 연출 응용)
*   **무엇인가:** 일반 대상과 비교 대상을 한 화면 좌우에 놓고, 손톱/동전 등 친숙한 기준물을 매개로 시각적 차이를 극대화하는 기법.
*   **언제 쓰나:** 경제적 수치 비교(예: 국민연금 vs 개인연금 수령액, 일반 예금 금리 vs 물가상승률 체감 격차).
*   **HTML/CSS 구현법:**
    ```html
    <div class="compare-container">
      <div class="item left">
        <span class="label">일반 대추</span>
        <div class="circle small"></div>
      </div>
      <div class="vs">VS</div>
      <div class="item right">
        <span class="label highlight">사과대추 (2~3배)</span>
        <div class="circle large"></div>
      </div>
    </div>
    ```
    *CSS:* Flexbox로 좌우 배치 후, `.large` 요소에 `transform: scale(0);`에서 `animation: popUp 0.6s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;`를 적용하여 고무공처럼 튕기듯 등장.

#### ② 스탬프형 경고/충격 박스 (통째로 갈아엎기 연출)
*   **무엇인가:** 배경 영상이 어두워지며 모서리가 둥근 붉은색 테두리 박스가 화면 한가운데에 도장 찍히듯 회전하며 떨어지는 연출.
*   **언제 쓰나:** "원금 전액 손실", "노후 파산", "인지 왜곡" 등 핵심 위험 키워드 각인 시.
*   **HTML/CSS 구현법:**
    ```html
    <div class="stamp-box">원금 전액 손실</div>
    ```
    *CSS:*
    ```css
    .stamp-box {
      border: 4px solid #E53935;
      color: #E53935;
      font-weight: 900;
      padding: 10px 20px;
      display: inline-block;
      opacity: 0;
      animation: stampImpact 0.4s ease-out forwards;
    }
    @keyframes stampImpact {
      0% { opacity: 0; transform: scale(3) rotate(-15deg); }
      70% { opacity: 1; transform: scale(0.9) rotate(5deg); }
      100% { opacity: 1; transform: scale(1) rotate(-3deg); }
    }
    ```

#### ③ 게이지/당도계 스타일의 데이터 바 애니메이션 (당도 36브릭스 연출 응용)
*   **무엇인가:** 수치가 빠르게 카운트업되면서 프로그레스 바나 게이지가 특정 임계점(위험/최고치)을 돌파하며 번쩍이는 연출.
*   **언제 쓰나:** 고금리 부담률, 부채 비율, 스트레스 지수 등 단계별 심각도를 보여줄 때.
*   **HTML/CSS 구현법:**
    ```html
    <div class="meter-wrapper">
      <div class="meter-bar"></div>
      <div class="meter-badge"><span class="counter">36</span>%</div>
    </div>
    ```
    *CSS:* `.meter-bar`의 `width`를 `0%`에서 `100%`로 `transition: width 1s cubic-bezier(0.22, 1, 0.36, 1);`로 늘리고, 끝부분에 도달했을 때 뱃지에 `filter: drop-shadow(0 0 8px gold);`와 펄스(Pulse) 애니메이션을 주어 최종 정점을 강조.
