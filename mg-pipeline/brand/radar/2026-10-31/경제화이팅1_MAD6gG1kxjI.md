### 5. 자막 및 텍스트 연출

- **크기**: 화면 세로 높이 대비 약 **5~6%**로 설정해 모바일과 TV/태블릿 모두에서 높은 시인성 확보.
- **배치 및 스타일**: 화면 최하단에 둥근 모서리(border-radius)를 가진 짙은 반투명 검은색 배경 바를 깔아 배경 일러스트의 복잡한 디테일과 텍스트가 겹쳐도 완벽히 분리됨.
- **색상**: 본문은 순백색(`#FFFFFF`), 핵심 수치나 키워드는 볼드 처리.
- **호흡**: 한 줄에 15~20자 내외로 호흡 단위 끊어치기(대본 한 문장을 2~3회에 나누어 교체).

### 6. 화면 전환 및 카메라 워크

- **카메라 무빙 (Ken Burns Effect)**: 정지된 일러스트를 쓰되, 정적인 느낌을 없애기 위해 모든 컷에 **0.05~0.1배율 미세 줌인/줌아웃** 및 **대각선 슬로우 팬**을 적용.
- **전환 효과**: 대부분 하드 컷(Cut)과 부드러운 디졸브(Cross Dissolve)를 사용해 지식 다큐멘터리의 신뢰성을 유지. 빠른 채찍 트랜지션(Whip pan) 등 과도한 효과는 지양함.

---

### 7. 오디오 및 BGM 연출

- **배경음악(BGM)**: 저음부 첼로와 절제된 타악기, 신스 패드가 깔린 **다큐멘터리/서스펜스 스타일 BGM**. 목소리 주파수 대역을 침범하지 않도록 미드 레인지를 비워둠.
- **효과음(SFX) 타이밍**:
  - 충격적인 단어/수치 전환 시: 묵직한 서브우퍼 쿵(Whoosh Hit).
  - 지도가 펼쳐지거나 국기가 꽂힐 때: 종이 바스락거림, 핀 꽂히는 탁음.
  - 덫이 닫히거나 계약서 도장을 찍을 때: 철컥(Metallic Trap), 쿵(Stamp) 소리로 뇌리에 각인.

### 8. 우리 채널 모션그래픽 자동화에 적용할 핵심 기법 3가지

#### 기법 1. [스케일 체감형 군중 패럴랙스 (00:01)]
- **무엇인가**: '2억 명/전 국민 4회' 같은 방대한 수치를 설명할 때 전경의 소수 관찰자와 원경의 무한한 군중을 층(Layer)으로 분리해 깊이감을 주는 연출.
- **언제 쓰나**: 국가 단위 통계, 심리학적 집단 현상, 압도적 규모를 직관적으로 각인시킬 때.
- **HTML/CSS 구현 방법**:
  ```html
  <div class="scale-scene">
    <div class="crowd-layer background"></div>
    <div class="family-layer foreground"></div>
  </div>
  ```
  ```css
  .scale-scene {
    position: relative;
    width: 100vw; height: 100vh;
    overflow: hidden;
  }
  .crowd-layer {
    position: absolute; width: 110%; height: 110%;
    background: url('crowd.png') center/cover;
    animation: zoomOutSlow 6s ease-out forwards;
  }
  .family-layer {
    position: absolute; bottom: 0; left: 10%; width: 300px;
    transform-origin: bottom center;
    animation: parallaxForeground 6s ease-out forwards;
  }
  @keyframes zoomOutSlow {
    from { transform: scale(1.15); }
    to { transform: scale(1.0); }
  }
  @keyframes parallaxForeground {
    from { transform: scale(1.05) translateY(10px); }
    to { transform: scale(1.0) translateY(0); }
  }
  ```

#### 기법 2. [심리적 딜레마를 시각화한 '베어 트랩(Bear Trap) 로드' 메타포 (02:46)]
- **무엇인가**: "공사를 안 하면 교통지옥, 공사를 시작하면 도시 마비"라는 진퇴양난의 구조를 둥근 도로가 곰 덫(철제 톱니) 형태로 맞물려 차를 가두는 기계적 은유로 시각화.
- **언제 쓰나**: 경제적 딜레마(금리 인상 vs 경기 침체), 심리적 이중구속(Double bind) 상황을 설명할 때.
- **HTML/CSS 구현 방법**:
  - SVG로 양쪽 톱니 도로 호(Arc)를 만들고 CSS 애니메이션으로 닫히는 모션 구현.
  ```html
  <div class="dilemma-container">
    <svg viewBox="0 0 400 400" class="trap-svg">
      <path class="trap-left" d="...톱니 반원 경로..." />
      <path class="trap-right" d="...톱니 반원 경로..." />
    </svg>
    <div class="trapped-car">🚗</div>
  </div>
  ```
  ```css
  .trap-left {
    transform-origin: bottom center;
    animation: snapLeft 1.2s cubic-bezier(0.68, -0.55, 0.27, 1.55) forwards;
  }
  .trap-right {
    transform-origin: bottom center;
    animation: snapRight 1.2s cubic-bezier(0.68, -0.55, 0.27, 1.55) forwards;
  }
  @keyframes snapLeft {
    0% { transform: rotate(-35deg); }
    100% { transform: rotate(0deg); }
  }
  @keyframes snapRight {
    0% { transform: rotate(35deg); }
    100% { transform: rotate(0deg); }
  }
  ```

#### 기법 3. [인포그래픽 노선 파이 점유율 드로잉 (01:12 ~ 01:23)]
- **무엇인가**: 백지 지도 위에 각 경쟁국(미국/이탈리아) 노선이 순차적으로 선으로 그어지고, 마지막에 한국이 3개 노선을 휩쓸며 국기 깃발이 꽂히는 성과 점유 연출.
- **언제 쓰나**: 시장 점유율 독점, 경쟁 구도 정리, 심리 테스트 결과 비율 분석 시.
- **HTML/CSS 구현 방법**:
  - SVG `stroke-dasharray`와 `stroke-dashoffset` 속성을 활용해 선이 자동으로 연결되는 트랜짓 맵 드로잉 생성.
  ```html
  <svg class="metro-map" viewBox="0 0 800 500">
    <!-- 배경 노선망 옅은 회색 -->
    <path class="route-bg" d="M 100 250 L 400 250 L 700 100" />
    <!-- 한국 점유 노선 강조 컬러 -->
    <path class="route-active korea" d="M 100 250 L 400 250 L 700 100" />
  </svg>
  <div class="flag-pin">🇰🇷</div>
  ```
  ```css
  .route-active {
    fill: none;
    stroke: #0047A0; /* 한국 블루 */
    stroke-width: 8;
    stroke-linecap: round;
    stroke-dasharray: 800;
    stroke-dashoffset: 800;
    animation: drawRoute 2.5s ease-in-out forwards;
  }
  @keyframes drawRoute {
    to { stroke-dashoffset: 0; }
  }
  .flag-pin {
    position: absolute;
    top: 90px; left: 690px;
    opacity: 0;
    transform: scale(0.2) translateY(-20px);
    animation: dropPin 0.5s 2.3s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
  }
  @keyframes dropPin {
    to { opacity: 1; transform: scale(1) translateY(0); }
  }
  ```
