### 4. 화면 레이어 구조

1. **바닥 레이어 (배경)**

   * 다크톤 미세 파티클(먼지/빛가루) 애니메이션 배경 (단색 암전 구간).
2. **중간 레이어 (시각 자료 및 모션그래픽)**
   * 막대 차트(연도별 매출 폭증), 비교 카드(판매가 vs 원가), 스탬프 효과(도장), 1~7위 카드 UI.
   * 드라마 클립/사진, 기사/반응 캡처 형태의 인용 박스.
3. **전면 레이어 (텍스트/자막)**
   * 상단 중앙: 핵심 메시지/소제목 고정 배너 (화면 상단 15~20% 영역).
   * 하단 중앙: 흰색 기본 음성 동기화 나레이션 자막 (고딕 계열 폰트).
   * 좌/우측 구석: 출처 표기(워터마크) 및 랭킹 번호 뱃지.

### 5. 글자(타이포그래피) 연출

* **크기**:
  * 메인 키워드 배너/타이틀: 화면 높이(VH)의 약 **6~9%** (중장년층도 한눈에 읽기 쉬운 큰 폰트).
  * 본문/내레이션 자막: 화면 높이의 약 **4~5%**.
* **색상**:
  * 배경 대비가 높은 **화이트(기본), 옐로우(#FFD700 계열, 핵심 강조), 레드(위기/충격 강조)** 3색 원칙 유지.
* **등장 및 강조 방식**:
  * **도장 쾅(Stamp)**: 붉은색 테두리 박스가 회전하며 축소 낙하 (신뢰도 타격, 충격 뉴스 강조).
  * **블록 박스(Tag/Pill)**: 라운드 박스 배경(다크 반투명 또는 노란색)에 텍스트를 넣어 가독성 극대화.
  * **숫자 카운트업 & 화살표 점멸**: 가격 인상률, 매출 변화 등에서 볼드체와 화살표 활용.

### 6. 전환과 카메라 워크

* **카메라 워크 (Ken Burns)**:
  * 정적인 사진이라도 100% 미세한 **천천히 줌인(Slow Zoom-in)** 또는 **패닝(Pan)**을 적용하여 영상처럼 보이게 처리.
* **전환(Transition)**:
  * 기본적으로는 정보 전달에 집중하기 위해 **하드 컷(Hard Cut)** 위주.
  * 챕터나 주제가 반전될 때는 부드러운 **디졸브(Cross Dissolve)** 또는 **암전(Dip to Black)** 사용.
  * 인용구나 충격적 사실 등장 시 **줌 블러(Zoom Blur) 펀치** 효과로 시선 집중.

### 7. 소리(사운드 디자인)

* **효과음(SFX)**:
  * *타이틀/카드 등장 시*: 묵직한 '우웅(Whoosh)' 저음 브러시 사운드.
  * *도장/스탬프 찍힐 때*: 둔탁한 타격음(Thud/Hit).
  * *차트 상승/숫자 강조 시*: 맑은 디지털 '띵(Ping/Chime)' 사운드.
  * *의문/전환 시*: 심장박동음 또는 서스펜스 라이저(Riser).
  * 빈도: 문장마다 남발하지 않고 **5~7초당 1회**, 핵심 키워드가 바뀔 때만 정밀 타격.
* **배경음악(BGM)**:
  * 전반부: 경제 시사 다큐멘터리 특유의 차분하면서도 긴장감을 유지하는 미니멀 신디사이저 펄스(Minimal Pulse/Electronic).
  * 보이스오버(목소리) 주파수를 방해하지 않도록 중음역대가 비어있는 트랙 사용.

### 8. 벤치마킹할 핵심 기법 3가지 (HTML/CSS 구현법 포함)

#### 기법 1: 블라인드 카드 랭킹 UI (호기심 유지 오픈 루프)
* **언제 쓰나**: "무너진 브랜드 TOP 7"처럼 순위형 콘텐츠를 전개하며, 시청자가 영상을 끝까지 이탈하지 않고 보게 만들 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="ranking-container">
    <div class="card revealed">
      <span class="rank">7위</span>
      <span class="brand">디올</span>
    </div>
    <div class="card locked">
      <span class="rank">6위</span>
      <span class="question">?</span>
    </div>
    <!-- 1위까지 반복 -->
  </div>
  ```
  ```css
  .ranking-container { display: flex; gap: 12px; justify-content: center; }
  .card { width: 100px; height: 160px; border-radius: 8px; border: 2px solid #555; background: #111; display: flex; flex-direction: column; align-items: center; justify-content: center; }
  .card.revealed { border-color: #ffd700; box-shadow: 0 0 15px rgba(255, 215, 0, 0.4); animation: flipOpen 0.6s ease-out; }
  .locked .question { font-size: 2rem; color: #777; }
  @keyframes flipOpen {
    0% { transform: rotateY(90deg); opacity: 0; }
    100% { transform: rotateY(0deg); opacity: 1; }
  }
  ```

#### 기법 2: 붉은색 스탬프(도장 쾅) 낙하 효과
* **언제 쓰나**: '원가 8만 원', '전량 취소' 등 충격적이거나 불합리한 팩트를 폭로해 시청자에게 감정적 타격을 줄 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="image-wrapper">
    <img src="dior_store.jpg" alt="매장">
    <div class="stamp-badge">원가 8만 원</div>
  </div>
  ```
  ```css
  .stamp-badge {
    position: absolute; top: 40%; right: 15%;
    border: 5px solid #d32f2f; color: #d32f2f;
    font-size: 2.2rem; font-weight: 900; padding: 8px 18px;
    transform: rotate(-15deg);

  }
  @keyframes stampDrop {
    0% { transform: scale(3) rotate(0deg); opacity: 0; }
    100% { transform: scale(1) rotate(-15deg); opacity: 1; }
  }
  ```

#### 기법 3: 가격/매출 대비 비교 바(Bar) 차트 애니메이션
* **언제 쓰나**: 650만 원 → 760만 원, 637억 → 1조 원 등 경제 데이터의 비정상적 급등/급락을 직관적으로 보여줄 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="chart-box">
    <div class="bar-group">
      <span>2017년 (637억)</span>
      <div class="bar start-bar" style="--target-width: 15%;"></div>
    </div>
    <div class="bar-group">
      <span>2023년 (1조 456억)</span>
      <div class="bar end-bar" style="--target-width: 95%;"></div>
    </div>
  </div>
  ```
  ```css
  .chart-box { width: 80%; margin: auto; color: #fff; font-size: 1.2rem; }
  .bar { height: 28px; border-radius: 4px; animation: expandBar 1.2s cubic-bezier(0.22, 1, 0.36, 1) forwards; }
  .start-bar { background: #555; }
  .end-bar { background: #e53935; box-shadow: 0 0 10px rgba(229, 57, 53, 0.5); }
  @keyframes expandBar {
    from { width: 0%; }
    to { width: var(--target-width); }
  }
  ```
