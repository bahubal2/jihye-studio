### 3. 30초 이후 페이스 및 밀도 (추정)

* **바닥 (배경 레이어):**

* **중간 (콘텐츠/정보 레이어):**

* **앞 (글자/모션그래픽 레이어):** 
  * 둥근 모서리 플랫 카드(UI 팝업 형태), 픽토그램(쇼핑카트, 상점, 위치핀, 상자 트럭), 핵심 키워드 강조 텍스트, 하단 고정 나레이션 자막.

### 5. 글자 연출

* **크기:** 
  * 핵심 수치 및 헤드라인: 화면 높이의 약 12~15% (매우 큼)
  * 설명 배지/키워드 카드: 화면 높이의 약 5~7%
  * 하단 내레이션 기본 자막: 화면 높이의 약 4~5%
* **색상:** 
  * 주목도 높은 고대비 색상 활용. 위기/하락은 **붉은색(#D9383A)**, 브랜드/안정은 **청록/블루(#2C6ECB)**, 질문이나 주의는 **옐로우/오렌지**. 본문 폰트는 주로 깔끔한 화이트/블랙.
* **등장 및 강조 방식:**
  * 카운트업 롤링(숫자 상승), 아래에서 위로 살짝 튀어오르는 슬라이드 업(Slide Up & Bounce).
  * 텍스트 뒷배경에 둥근 사각 라운드 박스(Chip UI), 빨간색 밑줄(스트로크 애니메이션) 마킹.
* **자막 스타일:** 
  * 하단 중앙 고정, 가독성이 뛰어난 산세리프 고딕체(Pretendard/Noto Sans 계열)에 얇은 외곽선과 그림자(Drop-shadow) 적용.

---

### 6. 전환과 카메라 워크

* **전환(Transition):** 주로 디졸브/페이드(Dissolve/Crossfade) 및 매끄러운 컷 전환을 사용해 자극적이지 않게 연출.
* **카메라 워크:** 
  * 정적인 이미지에 지속적인 **서행 줌인(Slow Zoom-in)** 또는 **패닝(Pan)**을 걸어 멈춰있지 않은 영상 느낌 부여(켄 번스 효과).
* **화면 강조:** 
  * 대비를 보여줄 때 한쪽 화면을 흑백(Grayscale) 처리하여 쇠락/폐점을 암시하고, 경쟁사는 풀컬러로 유지하는 채도 대비 기법 적용.

### 7. 소리 연출 (SFX & BGM)

* **효과음(SFX):** 
  * 수치 증가 시 경쾌한 디지털 틱틱/롤링 사운드.
  * 정보 카드 및 아이콘 팝업 시 둔탁하지 않고 깔끔한 팝(Pop), 휙(Whoosh) 사운드.
  * 위기나 반전 키워드(화근, 폐점 등) 등장 시 낮은 쿵(Impact/Boom) 사운드.
  * 평균 3~5초당 1회씩 그래픽 모션에 정확히 싱크되어 시각 집중을 돕는 보조 역할.
* **배경음(BGM):** 
  * 차분하면서도 긴장감을 팽팽하게 유지하는 미니멀한 경제 다큐멘터리풍 신디사이저/피아노 BGM. 내레이션 음성을 해치지 않도록 중저음역대가 깎여 있음.

### 8. 채널에 적용할 핵심 기법 3가지 (HTML/CSS 모션그래픽 구현법)

#### ① 숫자 카운트업 & 위기 수치 전환 카드
* **무엇인가 / 언제 쓰나:** `3,068억`에서 `4,000억`으로 롤링되며 빨간 글씨로 경고하듯 바뀌는 연출. 충격적인 손실액, 부동산 매각가, 금리 급등 등 **금액의 심각성을 직관적으로 전달할 때** 최적.
* **HTML/CSS 구현법:**
  ```html
  <div class="stat-card">
    <span class="label"><i class="icon-calendar"></i> 일년</span>
    <div class="counter-container">
      <span class="number count-up" data-target="4000">4,000</span>
      <span class="unit">억원</span>
    </div>
  </div>
  ```
  ```css
  .stat-card {
    background: rgba(255, 255, 255, 0.95);
    padding: 16px 28px;
    border-radius: 12px;
    box-shadow: 0 8px 24px rgba(0,0,0,0.12);
  }
  .number {
    font-size: 3.5rem;
    font-weight: 900;
    color: #c92a2a;
    transition: transform 0.3s ease-out;
  }
  /* JS RequestAnimationFrame으로 숫자 보간(0 -> 4,000) 처리 */
  ```

#### ② 도로/경계 분할 대조 뷰 (Split Map/Street Compare)
* **무엇인가 / 언제 쓰나:** 도로를 가운데 두고 '패자(망한 마트)'와 '승자(수혜를 본 마트)'를 좌우로 배치해 극적인 반사이익을 설명하는 연출. **비교 분석, 양극화 현상, 정책의 수혜자와 피해자를 대조할 때** 매우 효과적.
* **HTML/CSS 구현법:**
  ```html
  <div class="split-viewport">
    <div class="side left loser">
      <div class="store-badge">홈플러스</div>
      <div class="status">문 닫음</div>
    </div>
    <div class="road-divider"><span>길 건너</span></div>
    <div class="side right winner">
      <div class="store-badge">롯데마트</div>
      <div class="status active">매출 20% 급등</div>
    </div>
  </div>
  ```
  ```css
  .split-viewport {
    display: flex;
    position: relative;
    width: 100%;
    height: 360px;
  }
  .side.left {
    flex: 1;
    filter: grayscale(80%) brightness(0.9); /* 패자 쪽은 채도 감소 */
  }
  .side.right {
    flex: 1;
    background: #ffffff;
  }
  .road-divider {
    width: 4px;
    background: repeating-linear-gradient(to bottom, #888, #888 10px, transparent 10px, transparent 20px);
    display: flex;
    align-items: center;
    justify-content: center;
  }
  ```

#### ③ 신문 헤드라인 + 형광펜/도장 마킹 오버레이
* **무엇인가 / 언제 쓰나:** 언론 보도 캡처를 보여주며 대중의 통념("마트가 망한다")을 보여준 뒤, "천만의 말씀" 도장을 찍거나 핵심 문장에 빨간 밑줄을 그어 **대중의 착각을 반박하고 팩트를 제시할 때** 사용.
* **HTML/CSS 구현법:**
  ```html
  <div class="paper-cutout">
    <h3 class="article-title">대형마트의 몰락</h3>
    <div class="stamp-reject">천만의 말씀</div>
  </div>
  ```
  ```css
  .paper-cutout {
    position: relative;
    background: #faf8f5;
    padding: 24px;
    border: 1px solid #ddd;
    box-shadow: 2px 4px 15px rgba(0,0,0,0.1);
  }
  .stamp-reject {
    position: absolute;
    top: 50%;
    right: 10%;
    transform: translate(-50%, -50%) rotate(-12deg) scale(2);
    opacity: 0;
    color: #c92a2a;
    border: 4px solid #c92a2a;
    padding: 6px 16px;
    font-size: 1.8rem;
    font-weight: 800;
    animation: stamp-slam 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards 0.8s;
  }
  @keyframes stamp-slam {
    to {
      transform: translate(-50%, -50%) rotate(-12deg) scale(1);
      opacity: 1;
    }
  }
  ```
