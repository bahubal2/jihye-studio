### 3. 컷 수 및 그래픽 등장 빈도 (30초 이후 분석)

* **1분당 컷(화면 전환) 수**: 약 **12~15회** (평균 4~5초당 1회 컷 전환) [추정]
* **1분당 그래픽 요소 등장 수**: 약 **18~24개** [추정]
  * 단순 컷 전환뿐 아니라 한 화면 안에서 `아이콘 등장 → 텍스트 라벨 추가 → 수치 차트 변환` 식의 2~3단계 서브 모션이 지속적으로 일어남.

---

### 4. 화면 레이어 구조

1. **바닥(배경 레이어)**: 
   * 현장 스톡 영상 또는 뉴스 현장 사진을 **약 15~30% 어둡게(Dimming)** 하거나 **가우시안 블러(약 10~20px)** 처리하여 피사체와의 분리감 확보.
2. **중간(자료·비주얼 레이어)**:
   * 증거 자료(영수증, 뉴스 캡처, 고기 불판 사진, 드론 항공 뷰).
   * 둥근 모서리(Border-radius)가 적용된 카드(Card UI) 박스에 그림자(Drop-shadow)를 주어 입체감 부여.
3. **앞(텍스트·인포그래픽 레이어)**:
   * 핵심 키워드 강조 뱃지(빨강/검정 대비).
   * 타임라인 흐름선, 원형/막대 그래프, 픽토그램 아이콘, 하단 내레이션 기본 자막.

---

### 5. 글자(타이포그래피) 연출

* **크기**: 핵심 키워드는 화면 세로 높이의 **약 8~12%**, 내레이션 기본 자막은 약 **4.5~5.5%** 로 40대 이상 모바일 시청자에게 최적화된 큰 폰트 유지.
* **색상 팔레트**: 흰색 바탕 + 검은색 폰트 기본, 강조 시 **경고용 레드(#E53935)**, **신뢰/팩트용 딥네이비/차콜**.
* **강조 방식**:
  * 둥근 모서리 배경 박스(Badge).
  * 도장 찍히듯 바운스되며 떨어지는 **스탬프(Stamp) 모션**.
  * 느낌표/경고 삼각형 아이콘을 타이틀 앞에 배치해 시선 강제 유도.

---

### 6. 전환과 카메라 워크

* **전환(Transition)**: 현란한 3D 전환을 배제하고 **빠른 하드컷**과 **모션 슬라이드(Slide-in)** 중심.
* **카메라 워크**: 스틸 사진 자료에 미세한 **서행 줌인(Slow Zoom-in)** 또는 **패닝(Pan)**을 걸어 정지 이미지의 지루함 제거.
* **충격 효과**: 황당하거나 부정적인 발언/수치가 나올 때 텍스트가 확대되며 순간 정지하는 시각적 멈춤(Impact Pause).

---

### 7. 사운드 디자인

* **BGM**: 
  * 사건의 진실을 파헤치는 다큐/탐사보도 느낌의 **미디엄 템포 신스 비트 + 텐션감 있는 베이스 라인**.
  * 보이스오버(내레이션) 주파수 영역(1~3kHz)을 비워두어 대사 명확성 유지.
* **효과음(SFX)**:
  * 텍스트/카드 등장: **경쾌한 팝(Pop), 휙(Whoosh)**.
  * 충격 키워드/도장 찍힘: **둔탁한 쿵(Thud), 스탬프 소리**.
  * 수치 계산/금액 제시: **캐시 레지스터(철컥-칭), 카운팅 틱(Tick) 사운드**.

### 8. 우리 채널이 즉시 흡수할 핵심 기법 3가지 (HTML/CSS 구현법 포함)

#### 기법 1: 영수증/메뉴판 검증 UI + 비상식적 수치 경고 라벨
* **용도**: 경제 폭리, 물가 급등, 호구 잡힌 소비 심리를 설명할 때 직관적 팩트 체크용.
* **HTML/CSS 구현법**:
```html
<div class="receipt-card">
  <div class="item">
    <span class="label">갈치조림</span>
    <span class="price">100,000원</span>
  </div>
  <div class="warning-badge">⚠️ 폭리 논란</div>
</div>
```
```css
.receipt-card {
  width: 320px; padding: 16px; background: #fff;
  border-radius: 12px; box-shadow: 0 10px 25px rgba(0,0,0,0.15);
  display: flex; flex-direction: column; gap: 10px;
}
.warning-badge {
  background: #ff4757; color: #fff; font-weight: bold;
  padding: 6px 12px; border-radius: 6px; width: fit-content;
  animation: stampPop 0.3s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
}
@keyframes stampPop {
  0% { transform: scale(1.8) rotate(-5deg); opacity: 0; }
  100% { transform: scale(1) rotate(0deg); opacity: 1; }
}
```

#### 기법 2: 3단계 인과관계 흐름도 (욕망 → 패착 → 파국)
* **용도**: "탐욕에 눈이 멀어(1) → 집토끼를 내쫓았더니(2) → 안방까지 털렸다(3)" 식의 40대 타깃 경제·심리 서사를 한눈에 요약할 때.
* **HTML/CSS 구현법**:
```html
<div class="flow-container">
  <div class="step step-1"><span>1</span> 탐욕</div>
  <div class="arrow">➔</div>
  <div class="step step-2"><span>2</span> 내국인 이탈</div>
  <div class="arrow">➔</div>
  <div class="step step-3 danger"><span>3</span> 상권 붕괴</div>
</div>
```
```css
.flow-container {
  display: flex; align-items: center; gap: 12px;
}
.step {
  background: #f1f2f6; border: 2px solid #ced6e0; padding: 10px 18px;
  border-radius: 10px; font-weight: bold; font-size: 18px;
  animation: slideFadeIn 0.5s ease forwards;
}
.step.danger { background: #ffeaa7; border-color: #d63031; color: #d63031; }
.arrow { font-size: 20px; color: #747d8c; }
@keyframes slideFadeIn {
  from { opacity: 0; transform: translateX(-15px); }
  to { opacity: 1; transform: translateX(0); }
}
```

#### 기법 3: 카운트업 점유율 도넛 게이지 (70% 중국인 급증)
* **용도**: "70% 외국인이 장악" 등 특정 수치의 편중을 보여주어 위기감을 극대화할 때.
* **HTML/CSS 구현법**:
```html
<div class="gauge-box">
  <svg viewBox="0 0 36 36" class="circular-chart">
    <path class="circle-bg" d="M18 2.0845 a 15.9155 15.9155 0 0 1 0 31.831 a 15.9155 15.9155 0 0 1 0 -31.831"/>
    <path class="circle" stroke-dasharray="70, 100" d="M18 2.0845 a 15.9155 15.9155 0 0 1 0 31.831 a 15.9155 15.9155 0 0 1 0 -31.831"/>
    <text x="18" y="20.35" class="percentage">70%</text>
  </svg>
</div>
```
```css
.circular-chart { width: 120px; height: 120px; }
.circle-bg { fill: none; stroke: #eee; stroke-width: 3.8; }
.circle {
  fill: none; stroke-width: 3.8; stroke-linecap: round; stroke: #e74c3c;
  animation: progress 1.2s cubic-bezier(0.4, 0, 0.2, 1) forwards;
}
.percentage { fill: #c0392b; font-weight: bold; font-size: 8px; text-anchor: middle; }
@keyframes progress {
  0% { stroke-dasharray: 0 100; }
}
```
