### 3. 30초 이후 컷 전환 빈도 및 그래픽 (추정)

* **1분당 평균 컷 수**: 약 **14~18컷** (컷당 평균 3.5~4.5초 유지).
  * 40대 이상 시청자가 인포그래픽 수치와 기사 내용을 충분히 인지할 수 있도록 숏폼(1~2초)보다 긴 호흡을 유지합니다.
* **1분당 모션그래픽/자료 등장 수**: 약 **6~9회**.
  * 뉴스 기사 발췌문 하이라이트 박스, 위성/지도 선 긋기 모션, 인포그래픽 수치 증감 표시, 로고/기업 누끼 이미지 등이 6~8초 간격으로 꾸준히 갱신됩니다.

### 5. 글자 및 텍스트 연출

* **크기**:
  * 하단 내레이션 기본 자막: 화면 세로 높이 기준 약 **4.5~5.5%**.
  * 좌측 정보 박스 타이틀: 세로 높이 약 **6~7%**.
  * 핵심 수치 비교(500m, 170km, 2.4km 등): 세로 높이 약 **8~10%**로 대형 배치.
* **색상 팔레트**:
  * 배경 어두움 대비 **고대비 화이트(#FFFFFF)** 기본.
  * 포인트 강조 컬러: **비비드 옐로우(#FFE600)** 또는 **오렌지/골드(#FFA500)** 계열을 사용하여 숫자와 핵심 단어 착색.
* **등장 및 강조 방식**:
  * **외신 기사 인용구**: 배경을 어둡게 처리(딤드 처리)한 후 기사 헤드라인 텍스트가 좌측에서 타이핑되거나 서서히 페이드인.
  * **수치 변경 강조**: 원래 계획 수치(16km, 150만 명)에 **빨간색 취소선** 또는 즉각적인 축소 수치(2.4km, 30만 명)를 옆에 붉은색/노란색 볼드로 대치하여 실패감을 시각화.

### 8. 우리 채널(40대 대상 자동 모션그래픽)에 적용할 핵심 기법 3가지

#### 기법 1. [스케일 체감형] 절대 수치-친숙 랜드마크 1:1 비교 카드
* **무엇인가**: 500m 높이, 170km 거리 같은 비현실적 숫자가 나올 때, 타깃 층(한국인/40대 이상)에게 가장 익숙한 랜드마크(롯데월드타워 555m, 서울-대전 거리)를 나란히 배치해 체감시키는 방식.
* **언제 쓰나**: 경제 지표(GDP 규모, 부채 총액, 환율 급등폭)나 대형 인프라 규모를 다룰 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="compare-container">
    <div class="item standard">
      <img src="lotte_tower.png" class="cutout">
      <span class="label">롯데타워 555m</span>
    </div>
    <div class="item target">
      <div class="bar"></div>
      <span class="label">더 라인 500m</span>
    </div>
  </div>
  ```
  ```css
  .compare-container { display: flex; align-items: flex-end; gap: 40px; }
  .item.standard { transform: translateY(50px); opacity: 0; animation: slideUp 0.6s cubic-bezier(0.16, 1, 0.3, 1) forwards; }
  .item.target { animation: growHeight 0.8s 0.3s ease-out forwards; }
  @keyframes slideUp { to { transform: translateY(0); opacity: 1; } }
  ```

#### 기법 2. [현실 직시형] 목표치 하향 '레드 슬래시(취소선) & 스왑' 모션
* **무엇인가**: 당초 계획된 장밋빛 목표 수치에 빨간색 사선(Strikethrough)이 그어지며 즉시 쪼그라든 현실 수치가 붉은색으로 쿵 내려앉는 연출(예: 16km ➔ ~~16km~~ 2.4km / 150만 명 ➔ ~~150만 명~~ 30만 명).
* **언제 쓰나**: 기업의 어닝 쇼크, 정부 경제성장률 전망치 하향, 공약 파기, 부동산 가격 폭락 등을 시각화할 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="stat-box">
    <span class="plan">당초 목표: 150만 명</span>
    <span class="slash"></span>
    <span class="reality">수정: 30만 명</span>
  </div>
  ```
  ```css
  .slash {
    position: absolute; width: 0%; height: 4px; background: #FF3B30;
    top: 50%; left: 0; transform: rotate(-5deg);
    animation: strike 0.4s 1s ease-in-out forwards;
  }
  .reality {
    opacity: 0; transform: scale(1.5); color: #FF3B30; font-weight: 800;
    animation: dropIn 0.3s 1.4s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
  }
  @keyframes strike { to { width: 100%; } }
  @keyframes dropIn { to { opacity: 1; transform: scale(1); } }
  ```

#### 기법 3. [공신력 확보형] 외신/공시 원문 '블랙 딤드 하이라이트' 카드
* **무엇인가**: 화면 전체를 70% 어둡게 깔고(Dim), 신뢰할 수 있는 언론사(블룸버그, WSJ 등)의 영문/국문 텍스트 헤드라인에 형광펜을 긋듯 밝은 박스가 쳐지며 내레이션과 싱크를 맞추는 연출.
* **언제 쓰나**: 40대 이상 시청자에게 "유튜버의 뇌피셜이 아니라 정론지 팩트"임을 입증하여 논리적 신뢰도를 급상승시킬 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="news-overlay">
    <div class="news-card">
      <div class="source-badge">블룸버그 통신</div>
      <p class="headline">"사우디 네옴 2030년 목표 대폭 축소..."</p>
      <div class="highlighter"></div>
    </div>
  </div>
  ```
  ```css
  .news-overlay { background: rgba(0,0,0,0.75); backdrop-filter: blur(4px); }
  .news-card { background: #1E1E1E; border-left: 6px solid #FFE600; padding: 24px; }
  .highlighter {
    position: absolute; bottom: 0; left: 0; height: 35%; background: rgba(255, 230, 0, 0.3);
    width: 0%; animation: highlight 0.7s 0.4s ease-out forwards;
  }
  @keyframes highlight { to { width: 100%; } }
  ```
