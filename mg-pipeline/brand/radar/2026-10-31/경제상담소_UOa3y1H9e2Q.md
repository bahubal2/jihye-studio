### 3. 30초 이후 1분당 컷 수와 그래픽 등장 수 (추정)

* **1분당 컷 전환 수**: **약 10~13회** (평균 4.5~6초당 1컷)
  * 정보 전달 중심의 지식 영상 특성상 쇼츠처럼 1~2초마다 자르지 않고, 시청자가 문장과 데이터를 인지할 수 있는 호흡(4~5초)을 안정적으로 유지합니다.
* **1분당 모션 그래픽/텍스트 카드 등장 수**: **약 8~11회**
  * 거의 모든 컷마다 독립적인 정보 그래픽(랭킹 박스, 인용문 카드, 물가 증거 박스, 신문 기사 돋보기 연출 등)이 1개 이상 활성화됩니다.

### 4. 화면 레이어 구조

1. **바닥(배경) 레이어**:
   * 고화질 스톡 푸티지(비치, 도심 타임랩스, 현지 수상시장 영상).
   * 실사 항공/도시 영상 위에 은은한 비네팅(Vignette) 및 약한 암전(Dark Dim, 투명도 20~30% 블랙 오버레이)을 주어 텍스트 시인성 확보.
   * 영상 전체에 미세한 필름 노이즈/더스트 텍스처를 얹어 레트로하고 신뢰감 있는 톤 연출.
2. **중간(미들) 레이어**:
   * **자료 인서트 카드**: 오른쪽 상단에 배치되는 둥근 모서리(border-radius) 형태의 실사 사진 썸네일(출처 표기 포함).
   * **신문/문서 캡처**: 과거 신문 지면 위에 돋보기가 올라가 특정 텍스트를 확대하는 연출.
   * **랭킹/인포그래픽 카드**: 1위~5위까지 배치된 반투명 네이비 박스와 물음표(?) 카드.
3. **앞(포그라운드) 레이어**:
   * **핵심 키워드 볼드 자막**: 굵은 산세리프 텍스트 + 검은색 캡슐 박스 / 붉은 네온 박스.
   * **출처 표시**: 상단 중앙/우측에 작고 얇은 폰트로 "AI 음성으로 제작된 콘텐츠입니다", 사진 라이선스(CC BY-SA 등)를 표기하여 다큐멘터리적 공신력 부여.

### 5. 글자(타이포그래피) 연출

* **크기**:
  * 메인 키워드(숫자, 핵심 단어): 화면 높이(VH) 대비 **약 7~10%**로 매우 큼.
  * 서브 설명 텍스트: 화면 높이 대비 **약 3.5~4.5%**.
* **색상 팔레트**:
  * **기본/안정**: 화이트(`#FFFFFF`), 연한 그레이(`#E0E0E0`).
  * **포인트/수치**: 골드 옐로(`#FFD026`, 숫자 및 순위 강조).
  * **경고/반전/부정**: 쨍한 레드/오렌지(`#FF3B30`, "한국인이 없다", "천만에요", "물가").
  * **신뢰/배경 카드**: 딥 네이비 반투명(`rgba(15, 23, 42, 0.85)`).
* **등장 및 강조 방식**:
  * **박스 하이라이트**: 텍스트 뒤에 둥근 모서리 검은색/어두운 회색 박스를 씌워 배경 영상과 완벽히 분리.
  * **카운팅/전환 모션**: `39%`에서 `40%`로 숫자가 드럼 롤처럼 부드럽게 튀며 전환.
  * **도장형 임팩트(Impact Pop)**: "천만에요" 같은 단어는 1.3배 크기에서 1.0배 크기로 빠르게 축소되며 안착(스탬프 효과).

### 6. 전환과 카메라 워크

* **전환(Transition)**:
  * 컷과 컷 사이는 화려한 3D 트랜지션 대신 **하드 컷(Hard Cut)**과 빠른 **디졸브(Cross Dissolve, 약 0.2~0.3초)** 위주로 사용하여 지식 전달의 진중함을 유지.
* **카메라 무빙 (Ken Burns)**:
  * 정적인 사진이나 스톡 영상에 끊임없이 **느린 줌인(Slow Zoom-in)** 또는 **느린 줌아웃**을 적용하여 화면이 멈춰 있는 느낌을 철저히 배제.
* **오버레이**:
  * 미세한 파티클/필름 그레인이 화면 전반에 잔잔하게 흘러 아날로그 다큐멘터리의 질감을 연출.

### 7. 사운드 디자인

* **BGM (배경음)**:
  * 도입부(0~24초): 저음의 패드(Pad)와 은은한 비트가 깔리며 미스터리하고 긴장감 있는 다큐멘터리 앰비언스 유지.
  * "천만에요"(0:24) 직전: BGM이 순간적으로 먹먹해지거나 작아졌다가 전환을 알리는 묵직한 베이스 붐(Boom)과 함께 분위기 반전.
* **효과음(SFX)**:
  * **우웅(Whoosh/Swoosh)**: 텍스트 박스나 사진 카드가 밀려 들어올 때 (컷당 1회 꼴).
  * **쿵/쾅(Dull Hit/Impact)**: "천만에요", "한국인이 없다" 등 핵심 충격 문구가 뜰 때 서브우퍼를 울리는 타격음.
  * **짤깍/딸깍(Click/Pop)**: 돋보기 등장, 카드 팝업 시 미세한 클릭음으로 촉각적 인지 자극.

### 8. 벤치마킹할 강력한 연출 기법 3가지 & HTML/CSS 구현법

#### 기법 1. [통념 파괴 스탬프 팝업 (The Counter-Punch Stamp)]
* **무엇인가**: 시청자가 믿고 있는 가설("물가가 비싸서?")을 화면 양쪽에 띄운 뒤, 정중앙에 강렬한 붉은 박스로 **"천만에요"**를 도장 찍듯 때려 박는 연출.
* **언제 쓰나**: 40대 이상 타깃의 경제/심리 영상에서 대중의 잘못된 편견을 바로잡고, 시청자의 주의를 100% 환기해야 하는 인트로 20~25초 지점.
* **HTML/CSS 구현 방법**:
```html
<div class="stamp-container">
  <div class="stamp-box">천만에요</div>
</div>

<style>
.stamp-container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}
.stamp-box {
  font-family: 'Pretendard', sans-serif;
  font-size: 4rem;
  font-weight: 900;
  color: #ff3333;
  border: 5px solid #ff3333;
  padding: 12px 36px;
  border-radius: 12px;
  background: rgba(0, 0, 0, 0.75);
  box-shadow: 0 0 25px rgba(255, 51, 51, 0.5);
  
  /* 등장 애니메이션: 큰 스케일에서 빠르게 떨어져 쿵 찍히는 효과 */
  animation: stampDown 0.35s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
}

@keyframes stampDown {
  0% {
    opacity: 0;
    transform: scale(2.2) rotate(-5deg);
  }
  70% {
    opacity: 1;
    transform: scale(0.95) rotate(2deg);
  }
  100% {
    opacity: 1;
    transform: scale(1) rotate(0deg);
  }
}
</style>
```

* **언제 쓰나**: 과거 경제 사건, 과거 언론 보도, 통계청 고시 문서 등 팩트 데이터를 증명하여 신뢰도를 극대화할 때.
