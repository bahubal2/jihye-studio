### 4. 화면 레이어 구성

1. **바닥 레이어 (배경)**:

2. **중간 레이어 (모션그래픽/인포그래픽)**:
   * **좌상단 메타데이터 배너**: 국기 + 지명, 주제 태그(`[실패의 역사 40년]`, `[도시화 울란바토르]`).

   * **지도 오버레이**: 몽골 전도 위에 3D 핀포인트가 '툭' 꽂히는 모션.
3. **앞 레이어 (자막 및 UI)**:
   * **하단 메인 자막바**: 라운드 블랙 반투명 필 박스 + 굵은 고딕 텍스트.
   * **중앙 거대 타이포**: 충격적인 수치("460억 원", "19개")가 화면 중앙에 대형 크기로 바운스 등장.
   * **우상단 워터마크**: 채널 로고("이상하TV").

### 5. 글자 연출

* **크기**:
  * 일반 내레이션 자막: 화면 세로 높이 대비 **약 6~7%**. 40대 이상 모바일 시청 환경을 고려해 일반 유튜브 평균보다 약 15~20% 큼.
  * 충격 수치/키워드: 화면 높이 대비 **12~16%**의 초대형 볼드 폰트 적용.
* **색상**:
  * 자막 기본: 순백색(`White`).
  * 강조/숫자: 고채도 옐로우(`Yellow`) 및 민트 블루(통계 수치).
* **등장 및 강조 스타일**:
  * 단어 단위 컬러 전환: 내레이션과 정확히 일치하여 핵심 어휘('말도 안 되는 풍경', '식량안보')만 노란색으로 강조.
  * 숫자 롤링/카운트업: 숫자가 빠르게 스크롤되며 멈추는 애니메이션.
  * 불투명도 70~80%의 라운드 박스를 텍스트 뒤에 깔아 복잡한 실사 배경에서도 100% 가독성 보장.

---

### 6. 전환과 카메라

* **전환 기법**: 
  * 기본은 빠른 **하드 컷(Hard Cut)**.
  * 분위기 반전 구간(예: 00:54 40년 실패사 소개)에서 **수평 블라인드(Horizontal Blind Split)** 전환을 사용하여 과거/심층 분석으로 들어감을 시각화.
* **카메라 연출**:
  * 정지된 스톡 이미지/영상에도 105%~115% 수준의 **느린 디지털 줌인(Slow Zoom-in)**을 강제 적용해 화면이 멈춰있는 느낌을 완전히 배제.

### 7. 소리 (사운드 연출)

* **효과음(SFX)**:
  * 텍스트 팝업 시: 가벼운 '착(Snap)', '뽁(Pop)' 계열.
  * 숫자/핵심 단어 임팩트: 둔탁한 저음 타격음(Sub-bass Thud / Braam).
  * 종이 자료 등장 시: 실감 나는 페이퍼 넘김 사운드(Foley).
  * *빈도: 10~15초당 1회 수준으로 남발하지 않고 정확히 '숫자'와 '화면 전환'에만 동기화.*
* **배경음(BGM)**:
  * 인트로에는 미스터리하고 호기심을 끄는 신스 패드 사운드.
  * 460억 원이라는 경제 수치가 공개된 직후부터 일정한 템포의 묵직한 탐사 다큐 비트가 깔리며 지적인 몰입감 강화.

### 8. 우리 채널 자동화에 도입할 강력한 기법 3가지 (HTML/CSS 코드 포함)

#### ① 수평 스트립 슬라이스 전환 효과 (Horizontal Strip Transition)
* **언제 쓰나**: "이면에는 40년의 실패가 있었습니다"처럼 상식에서 숨겨진 반전/진실로 국면이 전환될 때.
* **HTML/CSS 구현**:
```html
<div class="split-container">
  <div class="slice" style="--i:0;"></div>
  <div class="slice" style="--i:1;"></div>
  <div class="slice" style="--i:2;"></div>
  <div class="slice" style="--i:3;"></div>
</div>

<style>
.split-container {
  position: absolute; width: 100%; height: 100%;
  display: flex; flex-direction: column; overflow: hidden;
}
.slice {
  flex: 1; width: 100%;
  background: url('next-scene.jpg') center/cover;
  transform: translateX(calc((var(--i) % 2 == 0 ? -1 : 1) * 100%));
  animation: sliceIn 0.5s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
@keyframes sliceIn {
  to { transform: translateX(0); }
}
</style>
```

#### ② 카운트업 수치 충격 카드 (Impact Number Banner)
* **언제 쓰나**: 40대 타깃에게 경제적 임팩트(돈, 통계 수치)를 각인시킬 때.
* **HTML/CSS 구현**:

#### ③ 좌상단 메타 뱃지 (Metadata Category Tag)
