### 3. 30초 이후 컷 및 그래픽 빈도 (분당 추정)

* **1분당 컷 전환 수:** 약 **14~18회** (컷당 3~4.5초 유지, 지루함을 방지하는 빠른 템포)
* **1분당 그래픽/인포그래픽 등장 수:** 약 **7~10회** (실사 화면 위 텍스트 배지, 도표, 픽토그램 애니메이션이 5~8초 간격으로 연속 발생)

### 4. 화면 레이어 구조

* **바닥 (배경):**
  * 은은한 밝은 회색 테크니컬 그리드(모눈 패턴) 애니메이션 배경
  * 또는 흑백/채도 감쇄 처리 및 가우시안 블러가 들어간 실제 보도 영상/스톡 영상
* **중간 (콘텐츠/정보):**
  * 라운드 코너(Border-radius)가 적용된 윈도우 카드 형태의 실사 사진/스톡 영상
  * 3D 렌더링 스타일의 직관적 오브젝트(전기밥솥, 경찰차, 경찰모자, 헤드셋 등)
  * 캐릭터 일러스트 및 간결한 픽토그램(인간 실루엣, 화살표 점선 경로)
* **앞 (텍스트/강조):**
  * 핵심 수치와 키워드가 적힌 알약형 배지(Pill badge)
  * 강조 도장(감소 판정, 불합격 등)
  * 하단 표준 내레이션 자막 및 상단 우측 고정 채널 워터마크

### 5. 글자(타이포그래피) 연출

* **크기:** 
  * 하단 일반 내레이션 자막: 화면 높이의 약 **5~6%**
  * 핵심 키워드/데이터 숫자: 화면 높이의 **12~25%**에 달하는 초대형 빅 타이포(Big Typo)
* **색상 팔레트:**
  * 기본 텍스트: 다크 차콜(`#1A1A1A`), 화이트(`#FFFFFF`)
  * 신뢰/강조: 딥 코발트 블루(`#1E50FF`)
  * 경고/수치 감소: 비비드 레드/코랄(`#FF3B30`)
  * 합격/보장: 에메랄드 그린
* **등장 및 강조 방식:**
  * 스프링 바운스(`cubic-bezier`) 느낌의 팝업 등장
  * 텍스트 뒤에 둥근 배경 박스(배지)를 씌워 가독성 100% 확보
  * 텍스트에 도장이 찍히듯 회전하며 축소되는 스탬프 애니메이션

### 6. 전환과 카메라 모션

* **전환(Transition):** 인위적인 3D 전환보다는 깔끔한 하드 컷(Hard Cut)과 좌우 슬라이드(Push/Slide)를 주로 사용하여 정갈하고 지적인 느낌 유지.
* **카메라 워크:** 정적인 이미지나 영상도 102%~108%로 서서히 줌인(Slow Ken Burns effect)하여 시선 고정 유도.
* **화면 강조:** 충격적인 수치나 경고 등장 시 미세한 흔들림(Camera Shake)과 소프트 화이트 플래시를 짧게 적용.

---

### 7. 음향(사운드 디자인) 연출

* **효과음(SFX):**
  * 핵심 텍스트/숫자 팝업 시: 가벼운 "툭(Pop)", "슉(Whoosh)"
  * 스탬프/도장/경고 배지 등장 시: 묵직한 타격음 "쿵(Heavy Thud/Impact)"
  * 전환 시: 가벼운 페이퍼 넘김(Paper Slide) 또는 스위시 사운드
  * 평균 3~5초당 1회씩 그래픽 등장과 밀리초 단위로 정확히 동기화.
* **배경음악(BGM):**
  * 차분하면서도 속도감이 있는 미니멀 앰비언트 비트(Lo-fi/Tech Ambient).
  * 내레이션 중저음 음역대와 충돌하지 않도록 보컬 없는 중저역 중심의 트랙을 일정한 볼륨으로 믹싱.

### 8. 우리 채널을 위한 강력한 기법 3가지 (HTML/CSS 모션그래픽 구현안)

#### ① 카드형 분할 레이아웃 & 빅 넘버 팝업 (Split Card & Big Number Pop)
* **언제 쓰나:** 경제 통계, 경쟁률, 노후 자산 등 40대 이상에게 숫자 충격을 직관적으로 줄 때.
* **HTML/CSS 구현 방법:**
```html
<div class="split-container">
  <div class="video-card"><img src="person.jpg" alt="case" /></div>
  <div class="info-card">
    <span class="label">경쟁률</span>
    <h1 class="counter">100대 1</h1>
    <div class="badge">사라지는 일터</div>
  </div>
</div>
```
```css
.split-container { display: flex; gap: 20px; align-items: center; justify-content: center; }
.video-card { border-radius: 16px; overflow: hidden; width: 45%; }
.counter { 
  font-size: 4rem; color: #1E50FF; font-weight: 900; 
  animation: popBounce 0.6s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
}
@keyframes popBounce {
  0% { transform: scale(0.5); opacity: 0; }
  100% { transform: scale(1); opacity: 1; }
}
```

#### ② '판정' 스탬프 모션 (Stamp Impact Effect)
* **언제 쓰나:** "위험 판정", "원금 손실", "퇴직 위기" 등 심리적 충격 문구를 각인시킬 때.
* **HTML/CSS 구현 방법:**
```html
<div class="stamp-box">감소 판정</div>
```
```css
.stamp-box {
  display: inline-block; padding: 8px 16px; font-weight: bold;
  color: #FF3B30; border: 3px solid #FF3B30; border-radius: 8px;
  transform: rotate(-10deg) scale(2); opacity: 0;
  animation: stampDrop 0.35s ease-in forwards;
}
@keyframes stampDrop {
  0% { transform: rotate(-10deg) scale(2.5); opacity: 0; }
  80% { transform: rotate(-8deg) scale(0.95); opacity: 1; }
  100% { transform: rotate(-10deg) scale(1); opacity: 1; }
}
```

#### ③ 인원/자금 이동 파이프라인 애니메이션 (Resource Flow Path)
* **언제 쓰나:** 직무 축소, 인력의 재배치, 자금의 유출/이동 경로를 단계별로 설명할 때(영상 01:15~01:25 구간).
* **HTML/CSS 구현 방법:**
  * SVG의 `stroke-dasharray`와 `stroke-dashoffset` 키프레임을 사용하여 점선 화살표가 흐르듯 이동하고, 끝점에 있는 대상(예: 순찰차/신규 직무)이 차례대로 `opacity: 1`과 `transform: translateY(0)`으로 켜지도록 CSS `animation-delay`를 순차적으로 부여합니다.
