### 1. 후킹 대본 구조 (0~30초)
* **문장 1 (0:00~0:02):** "아메리카노 나오셨습니다...?"
  * **장치:** **일상 속 위화감/의문 제시 (상황 재현)**. 누구나 카페에서 한 번쯤 들어봤을 법한 어색한 표현으로 시작해 공감대를 즉각 형성.
* **문장 2 (0:02~0:06):** "2010년대 이후, 국어 파괴의 예시로다가 흔히 거론되는 예문입니다."
  * **장치:** **배경 규정 및 문제 정의**. 해당 문장이 사회적으로 어떤 이슈였는지 명확히 짚어줌.
* **문장 3 (0:06~0:15):** "높여야 될 대상은 손님인데, 뜬금없이 사물을 높여버린 경우로 문법상 말이 안 되는 문장이죠."
  * **장치:** **상식적 비판 (직관적 설명)**. 시청자가 고개를 끄덕일 수 있는 당연한 설명을 제공하여 다음 반전을 준비.
* **문장 4 (0:16~0:21):** "어허, 높임말 하나 제대로 쓰질 못하다니! 우리 동방예의지국이 어쩌다 이렇게 됐냐?"
  * **장치:** **세대별 전형적 반응(꼰대 클리셰) 극화**. 4050 세대나 기성세대가 흔히 할 법한 한탄을 캐릭터 입을 빌려 대변.
* **문장 5 (0:22~0:27):** "사실 이게 예의가 없어져서 그런 게 아니라, 외려 예의를 너무 차리려다 보니 일어나는 현상입니다."
  * **장치:** **충격적 반전 (통념 깨기)**. "무식해서/버릇없어서"가 아니라 "예의가 과해서"라는 역발상 원인을 던져 강력한 몰입 유도.
* **문장 6 (0:28~0:30):** "언어란 시간이 지나며 변하기 마련이고... '존칭 인플레이션'."
  * **장치:** **개념 명명 및 오픈 루프**. 언어학적 현상을 경제학 용어인 '인플레이션'에 빗댄 핵심 키워드를 제시하여 호기심 극대화.

### 3. 30초 이후 컷 및 그래픽 등장 빈도 (추정)
* **1분당 컷 전환 수:** 약 **12~16회** (3~5초당 1회 컷 전환). 대본 호흡에 맞춰 배경 전환이나 장면 전환이 끊임없이 일어남.
* **1분당 그래픽 요소(텍스트/오브젝트/캐릭터) 등장 수:** 약 **20~25회** (거의 2~3초마다 단어 팝업, 화살표, 캐릭터 모션이 추가됨). 시청자가 지루할 틈을 주지 않는 고밀도 모션그래픽 구조.

### 4. 화면 레이어 구성
* **바닥 (배경):** 
  * 질감이 살아있는 한지/양장피 느낌의 베이지 톤 텍스처 종이 배경을 기본 베이스로 사용.
  * 필요 시 2D 카페 내부, 마트 계산대/콜센터 등 실사 스톡 사진·영상을 블러(Blur) 및 감색 처리하여 배경으로 배치.
* **중간 (메인 비주얼):**
  * 두꺼운 외곽선의 2D 플랫 일러스트 캐릭터 (자체 마스코트 캐릭터).
  * 상황 극화를 위한 소품 일러스트(군복, 커피, 칼, 도장 등).
* **앞 (텍스트 및 강조 그래픽):**
  * 볼드한 헤드라인용 타이포그래피.
  * 말풍선, 강조용 빨간 화살표, 경고 라벨, 빗금, 관계도 다이어그램 화살표.

### 5. 글자 연출
* **크기:**
  * 상단/중앙 키워드 텍스트: 화면 높이 대비 **약 10~15%** (큼직하고 명확함).
  * 하단 전체 내레이션 자막: 화면 높이 대비 **약 4~5%**.
* **색상:**
  * 기본 본문/대사: 블랙(#222), 화이트(#FFF).
  * 강조/경고: 굵은 레드(#D32F2F), 옐로우(#FFD54F) 포인트.
* **등장 및 강조 방식:**
  * **Scale Pop-up:** 0%에서 110%로 커졌다가 100%로 안착하는 탄성 모션.
  * **Stamp:** 화면 위에서 아래로 빠르게 떨어지며 쿵 찍히는 형태 (주제어용).
  * **대비 박스:** 검은색 배경 박스에 흰 글자, 혹은 말풍선 테두리 강조.
* **자막 스타일:**
  * 하단 고정 바 자막은 가독성 좋은 고딕 계열(노토산스 등)을 사용하며, 중앙 강조 단어는 무게감 있는 굵은 샌스세리프/헤드라인 폰트 사용.

### 6. 전환과 카메라 워크
* **전환 (Transition):**
  * 단순 하드컷(Cut)이 기본이지만, 챕터 전환 시 **스핀(회전) 왜곡 줌**, 종이가 찢어지거나 넘어가는 모션, 블랙 페이드 인/아웃 활용.
* **카메라 워크:**
  * 정적인 컷에서도 인물이나 사물이 미세하게 줌인(Slow Zoom-in)되거나, 화자의 대화 흐름에 따라 좌우로 살짝 패닝(Pan)하며 리듬감 유지.
* **화면 효과:**
  * 특정 단어나 스탬프가 떨어질 때 **미세한 화면 흔들림(Camera Shake)**을 주어 타격감 부여.

### 7. 소리 연출 (사운드 디자인)
* **효과음 (SFX):**
  * **빈도:** 2~3초당 1회 꼴로 매우 빈번함.
  * **종류:** 텍스트 팝업 시 '뽁/뾱', 강조 시 '쿵/쾅(타격음/우퍼)', 의문 시 '만화풍 띠용/피리 소리', 전환 시 '쉬익(Whoosh/스위시)'.
* **배경음악 (BGM):**
  * 템포감이 있으면서도 내레이션을 방해하지 않는 경쾌하고 어쿠스틱/재즈풍의 베이스·드럼 중심 BGM.
  * 심각한 주제를 너무 무겁지 않게, '흥미로운 지식 탐구' 톤으로 유지해 주는 역할.

### 8. 벤치마킹할 강력한 모션그래픽 기법 3가지 (HTML/CSS 구현법)

#### ① 탄성 팝업 키워드 (Elastic Pop-up)
* **언제 쓰나:** 새로운 핵심 단어("고맙습니다", "죄송합니다")나 반전 키워드가 중앙에 튀어나올 때.
* **CSS 구현법:**
```css
@keyframes elasticPop {
  0% { transform: scale(0); opacity: 0; }
  70% { transform: scale(1.15); opacity: 1; }
  100% { transform: scale(1); opacity: 1; }
}

.keyword {
  display: inline-block;
  font-size: 3rem;
  font-weight: 900;
  animation: elasticPop 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
}
```

#### ② '쾅' 찍히는 스탬프 임팩트 (Stamp Drop & Shake)
* **언제 쓰나:** "존칭 인플레이션", "틀린 문장입니다" 등 최종 판정이나 핵심 개념을 못 박을 때.
* **CSS 구현법:**
```css
@keyframes stampDrop {
  0% { transform: scale(3) rotate(-5deg); opacity: 0; }
  80% { transform: scale(0.95) rotate(-5deg); opacity: 1; }
  100% { transform: scale(1) rotate(-5deg); opacity: 1; }
}

/* 화면 전체 또는 부모 컨테이너에 주는 쉐이크 */
@keyframes screenShake {
  0%, 100% { transform: translate(0, 0); }
  25% { transform: translate(-3px, 3px); }
  50% { transform: translate(3px, -2px); }
  75% { transform: translate(-2px, -2px); }
}

.stamp-box {
  border: 4px solid #D32F2F;
  color: #D32F2F;
  animation: stampDrop 0.25s ease-in forwards;
}
.shake-trigger {
  animation: screenShake 0.15s ease-out 0.2s; /* 스탬프 도달 시점에 진동 */
}
```

#### ③ 겹쳐서 누적되는 다층 폴딩/스태킹 (Accordion Bow Stack)
* **언제 쓰나:** 1:16~1:30 구간처럼 "미안해 → 죄송해요 → 진심으로 사과드립니다..." 하며 예의 표현이 과도하게 겹치고 굽신거리는 모습을 시각화할 때 (인플레이션/과열 표현에 최적).
* **CSS 구현법:**
```css
/* 부모 기준 여러 자식 레이어가 순차적으로 각도를 꺾으며 누적 */
.stack-layer {
  position: absolute;
  transform-origin: bottom center;
  opacity: 0;
  animation: stackUp 0.3s forwards;
}

@keyframes stackUp {
  0% { transform: translateY(20px) rotate(0deg); opacity: 0; }
  100% { transform: translateY(0px) rotate(var(--angle, 5deg)); opacity: 0.85; }
}
/* 각 레이어마다 transition-delay와 --angle(각도)을 다르게 주어 
   부채꼴이나 허리를 깊이 숙이는 형태로 겹치게 연출 */
```
