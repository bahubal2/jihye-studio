### 3. 30초 이후 컷 및 그래픽 빈도 (추정)
* **분당 컷(장면) 전환 수**: 약 **10~14회/분** (평균 4~6초마다 시각적 배경 또는 핵심 프레임 전환).
* **그래픽(오브젝트/텍스트 모션) 등장 수**: 약 **22~28개/분** (2~3초마다 화살표, 키워드 배너, 말풍선, 아이콘 등이 쉼 없이 나타나 시각적 지루함을 차단).

---

### 4. 화면 레이어 구조

* **바닥 (배경 레이어)**: 
  * 미색의 크라프트 종이 텍스처(Parchment Paper), 교실 칠판 텍스처, 낡은 문서 종이.
  * *특징*: 단색 단조로움을 피하고 잡지/보고서 느낌을 주기 위해 미세한 종이 질감 노이즈를 일관되게 유지.
* **중간 (콘텐츠 레이어)**:
  * 펜 드로잉/빈티지 판화 느낌의 2D 일러스트 (담배, 액상, 파이프, 시가 등).
  * 굵은 외곽선(Ink Outline)과 손그림 느낌의 해칭(Hatching) 음영 처리.
  * 자체 마스코트 캐릭터(오리) 및 밈 요소 삽입.
* **앞 (글자/강조 레이어)**:
  * 텍스트 라벨(블록형 명찰 디자인), 굵은 화살표, 화학식 구조도 아이콘, 경고 딱지(온라인판매 X 등).

---

### 5. 글자 연출 기법

* **크기**: 
  * 키워드/핵심 숫자: 화면 높이의 약 **8~12%** (매우 크고 두꺼움).
  * 보조 설명 라벨: 화면 높이의 약 **4~5%**.
  * 하단 내레이션 자막: 화면 높이의 약 **3.5~4%**.
* **색상 팔레트**:
  * 강조: 고채도 **레드(#E02020)**, **블루(#1050A0)**, **옐로우/오렌지**.
  * 텍스트: 블랙(#222222)에 가까운 진회색.
* **등장 및 강조 방식**:
  * **스탬프 쾅 찍기**: 중요한 단어는 위에서 쿵 떨어지듯 약간의 스케일 오버슈트(1.2배 → 1.0배)와 함께 등장.
  * **라벨 배너**: 색상 박스 위에 흰색/검은색 볼드 폰트를 얹어 시선 고정.
  * **자막**: 하단 반투명 둥근 박스 안에 고딕 계열(Pretendard/Sandoll 계열 추정)로 가독성 확보.

### 6. 전환과 카메라 워크

* **전환(Transitions)**:
  * 하드 컷(Hard cut) 대신 **지우개 닦아내기(Eraser wipe)**, **종이 넘김**, **카메라 스와이프(좌우 밀기)**를 주로 사용.
  * 0:59초 칠판 지우개로 화면을 쓸어버리며 로고 인트로로 전환되는 기법이 대표적.
* **카메라 워크**:
  * 고정 앵글보다는 끊임없이 **1.05배~1.15배 미세 줌인(Slow Zoom-in)**을 유지.
  * 비교 대상이 늘어날 때 좌에서 우로 자연스럽게 팬(Pan) 이동.

### 7. 소리(사운드 디자인)

* **효과음(SFX)**:
  * 빈도: 분당 약 20~25회 (거의 모든 텍스트/아이콘 등장마다 매칭).
  * 유형: '쿵' (숫자 스탬프), '휘익' (슬라이드 인), '뽁/통' (말풍선/아이콘 팝업), '지익/슥' (칠판 지우개, 종이 넘김).
* **배경음(BGM)**:
  * 가볍고 호기심을 유발하는 어쿠스틱/재즈풍 피치카토(현악기를 튕기는 소리)와 가벼운 타악기 리듬.
  * 내레이션을 방해하지 않는 중저음역대 볼륨 유지, 분위기가 전환(법 개정, 반전 등)될 때 멈칫(BGM Stop) 후 재개.

### 8. 우리 채널(40대 대상 경제·심리 자동화)을 위한 핵심 기법 3가지

#### ① 실감 비교 물가 트래커 (Multi-Line Benchmark Chart)
* **무엇인가**: 단일 수치(담뱃값)만 보여주지 않고, 대중이 매일 체감하는 앵커 지표(짜장면값, 최저임금, 라면값)를 선 그래프 끝에 아이콘과 함께 달고 동시에 상승시키는 모션.
* **언제 쓰나**: 40대에게 국민연금, 부동산 가격, 물가상승률, 세금 인상 등 **'내 월급만 안 오른다'는 심리적 괴리**를 설명할 때.
* **HTML/CSS 구현법**:
  ```html
  <!-- SVG Path 드로잉 + 끝점에 아이콘 부착 -->
  <svg viewBox="0 0 800 400">
    <path class="chart-line" d="M 50 350 Q 400 300 750 80" />
  </svg>
  <div class="line-tracker">
    <img src="jjajang.png" />
    <span>1.7배</span>
  </div>
  ```
  ```css
  /* stroke-dashoffset 애니메이션으로 선을 긋고, 
     아이콘은 offset-path(CSS Motion Path)를 통해 선을 따라 이동 */
  .chart-line {
    stroke-dasharray: 1000;
    stroke-dashoffset: 1000;
    animation: drawLine 2s forwards ease-out;
  }
  .line-tracker {
    offset-path: path("M 50 350 Q 400 300 750 80");
    animation: moveTracker 2s forwards ease-out;
  }
  @keyframes drawLine { to { stroke-dashoffset: 0; } }
  @keyframes moveTracker { to { offset-distance: 100%; } }
  ```

#### ② 의인화 대립 말풍선 배틀 ("엥? 나 아닌데" vs "어 형이야")
* **무엇인가**: 복잡한 정책이나 법 개정 대상을 딱딱한 조문 대신 두 사물/개념(연초 vs 전자담배, 예금 vs 주식, 이성 vs 감정)에 말풍선을 달아 대화형으로 제시하는 방식.
* **언제 쓰나**: "부동산 규제, 아파트만 잡는 줄 알았더니 오피스텔이 얻어맞았다"처럼 **예상 밖의 규제/심리적 편향**을 풍자적으로 짚을 때.
* **HTML/CSS 구현법**:
  ```css
  /* 스프링 바운스(Bounce) 팝업 키프레임 */
  @keyframes popSpeechBubble {
    0% { transform: scale(0) rotate(-5deg); opacity: 0; }
    70% { transform: scale(1.15) rotate(2deg); opacity: 1; }
    100% { transform: scale(1) rotate(0deg); opacity: 1; }
  }
  .speech-bubble {
    animation: popSpeechBubble 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
    transform-origin: bottom center;
  }
  ```

#### ③ 칠판 지우개 화면 와이프 전환 (Blackboard Eraser Wipe)
* **무엇인가**: 칠판/종이 위에 글씨가 써 있다가 칠판지우개가 대각선으로 지나가면서 이전 내용이 지워지고 다음 챕터 타이틀이 나타나는 전환.
* **언제 쓰나**: 인트로 질문(문제 제기)을 끝내고 **본론(법적 배경, 이론 해설, 심리학적 원인)으로 넘어가는 챕터 전환부**.
* **HTML/CSS 구현법**:
  ```html
  <div class="screen-wrapper">
    <div class="board-layer" id="oldChapter">...</div>
    <div class="eraser-mask" id="newChapter">...</div>
    <img src="eraser.png" class="eraser-actor" />
  </div>
  ```
  ```css
  /* clip-path: polygon()을 시간에 따라 이동시켜 지워지는 효과 연출 */
  .eraser-mask {
    clip-path: polygon(0 0, 0 0, 0 100%, 0 100%);
    animation: wipeClean 1s ease-in-out forwards;
  }
  .eraser-actor {
    position: absolute;
    animation: moveEraser 1s ease-in-out forwards;
  }
  @keyframes wipeClean {
    to { clip-path: polygon(0 0, 100% 0, 100% 100%, 0 100%); }
  }
  @keyframes moveEraser {
    0% { left: 0%; top: 10%; }
    100% { left: 100%; top: 80%; }
  }
  ```
