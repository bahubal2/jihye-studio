### 1. 후킹 대본 구조 (0~30초 분석)

* **[0:00~0:06] "부모님 생신에 수십만 원짜리 등산 점퍼 한 벌 사 드렸거나, 자식들한테 받아 보신 분 꽤 계실 거예요."**
  * **장치:** **시청자 지목(공감대 형성) + 과거 추억 소환**. 40~60대 시청자의 일상적 경험(자식/부모로서의 경험)을 직격하여 몰입감을 유도합니다.
* **[0:06~0:11] "그 점퍼를 입고 오르던 산은 지금도 주말마다 붐빕니다."**
  * **장치:** **상태 유지(전제 설정)**. "등산 인구는 여전히 많다"는 팩트를 짚어 뒤에 올 반전을 극대화합니다.
* **[0:11~0:19] "그런데 그 시절 산에서 흔히 보던 등산복 브랜드 넷의 지난해 매출을 다 더해도, 노스페이스 한 곳에 못 미칩니다."**
  * **장치:** **반전 + 숫자/비교 충격**. "시장은 여전한데 대표 4대 브랜드 합산 < 노스페이스 1개"라는 명확한 대조를 제시합니다.
* **[0:20~0:23] "다섯 번째 브랜드는 아예 한국에서 사업을 접었습니다."**
  * **장치:** **위기감 고조 (극단적 사례)**. 사업 철수라는 파격적인 사실로 호기심 증폭.
* **[0:24~0:28] "등산복 유행이 지나서라고 생각하기 쉬워요."**
  * **장치:** **일반적 통념(상식) 제시**. 시청자의 예상 답변을 먼저 선점하여 깨뜨릴 준비를 합니다.
* **[0:28~0:33] "하지만 12년 전과 견주면, 노스페이스는 오히려 매출이 두 배가 됐습니다."**
  * **장치:** **통념 파괴(반전) + 수치 검증**. '유행 탓이 아니다'라는 점을 단번에 증명.
* **[0:34~0:40] "진짜 이유는 다른 데 있습니다. 도대체 그 브랜드들에 무슨 일이 있었던 걸까요?"**
  * **장치:** **오픈 루프 (Open Loop) + 질문 던지기**. 진짜 원인은 뒤에서 밝혀진다는 긴장감을 주어 이탈을 방지합니다.

   * 정적인 배경 위에 빛 번짐(블룸 효과)이나 거리 불빛 등 은은한 앰비언트 효과 가미.

   * 립싱크나 전신 애니메이션 대신, 눈 깜빡임, 입 모양 살짝 교체, 미세한 숨쉬기/바운스(2D Puppet) 효과 적용.
   * 의류 박스, 옷걸이 행거, 서류철 등 주제와 직접 관련된 소품 배치.
3. **앞 레이어 (정보 그래픽 및 자막):**
   * **상단/중앙 정보 박스:** '5위 K2', '2014년 4,200억 원 → 지난해 3,700억 원' 등 라운드 사각 박스 그래픽.

### 5. 글자(타이포그래피) 연출

* **크기:**
  * 기본 나레이션 자막: 화면 높이 대비 **약 5~6%** (화면 하단 중앙).
  * 핵심 키워드/순위 타이틀: 화면 높이 대비 **약 7~9%** (상단 좌/우측).
  * 숫자/매출 강조: 화면 높이 대비 **약 8~10%**.
* **색상:**
  * 바탕 텍스트: 주로 흰색(#FFFFFF) 또는 짙은 네이비.
  * 강조 텍스트/배경: 노란색(#FFD200 계열), 주황색, 진한 남색 박스 대비.
* **등장 및 강조 방식:**
  * 단어 단위로 쪼개기보다 **문장/수치 단위로 '통통' 튀어나오는 스케일 업(Scale Pop-up, 90% → 105% → 100%)** 효과.
  * 박스 형태로 감싸서 시선 분산을 막고, 숫자에는 굵기(Extra Bold)와 노란색 배경을 적용해 데이터 인지를 도움.

### 6. 전환과 카메라 워크

* **전환(Transition):**
  * 주로 **소프트 컷(Hard Cut)**과 부드러운 **디졸브(Cross Dissolve, 0.3~0.5초)** 혼용.
  * 화려한 3D 트랜지션 대신 내용에 집중할 수 있는 차분한 전환 위주.
* **카메라 워크:**
  * **미세한 켄 번스(Ken Burns) 효과:** 정지 일러스트가 지루하지 않도록 2~3% 천천히 줌인(Push-in)하거나 줌아웃(Pull-out).
  * **수평 패닝(Pan):** 캐릭터가 이동하거나 여러 매장을 보여줄 때 부드럽게 좌→우 패닝.

### 7. 소리(사운드) 연출

* **효과음(SFX):**
  * 빈도: 컷 전환 및 그래픽 팝업마다 발생 (분당 약 10~15회).
  * 종류:
    * 텍스트 박스/수치 등장: 가벼운 **'뽁(Pop)'**, **'착(Snap)'**, 부드러운 **'우웅(Whoosh)'**.
    * 충격적 수치/반전: 짧고 묵직한 저음 덤(Thud) 또는 차임벨.
* **배경음악(BGM):**
  * 템포가 빠르지 않고 차분하면서도 약간의 호기심을 유발하는 어쿠스틱/로파이 계열의 인스트루멘탈.
  * 나레이션 음성 대역(1kHz~3kHz)을 방해하지 않도록 볼륨을 -18dB~-22dB 수준으로 낮게 유지.

### 8. 추천 기법 3가지 및 웹(HTML/CSS) 구현 가이드

#### ① 수치 대조 비교 뱃지 (Number Contrast Badge)
* **무엇인가:** '12년 전 [매출 X억]'과 '현재 [매출 Y억 / 두 배]'를 양옆 또는 상하로 배치해 직관적으로 비교하는 듀얼 라운드 카드.
* **언제 쓰나:** 기업의 실적 급감/급증, 과거와 현재의 물가·소득 차이를 단번에 각인시킬 때.
* **HTML/CSS 구현:**
  ```html
  <div class="stat-compare">
    <div class="stat-pill past">12년 전 <span>4,200억</span></div>
    <div class="arrow">→</div>
    <div class="stat-pill current">지난해 <span>3,700억</span></div>
  </div>
  <style>
    .stat-compare {
      display: flex; align-items: center; gap: 12px;
      animation: popIn 0.5s cubic-bezier(0.175, 0.885, 0.32, 1.275);
    }
    .stat-pill {
      background: #ffffff; border: 2px solid #333; border-radius: 12px;
      padding: 8px 16px; font-weight: bold; box-shadow: 0 4px 10px rgba(0,0,0,0.15);
    }
    .stat-pill.current { background: #FFD200; border-color: #000; }
    @keyframes popIn {
      0% { transform: scale(0.8); opacity: 0; }
      100% { transform: scale(1); opacity: 1; }
    }
  </style>
  ```

#### ② 캐릭터 숨쉬기/미세 바운스 (Subtle Idle Animation)
* **무엇인가:** 정지된 일러스트 캐릭터에 부드러운 상하 호흡 리듬을 주어 살아있는 영상 느낌을 주는 기법.
* **언제 쓰나:** AI 일러스트나 2D 컷을 활용해 제작 단가를 낮추면서도 영상이 멈춘 것처럼 보이지 않게 할 때.
* **HTML/CSS 구현:**
  ```html
  <div class="character-wrapper">
    <img src="character.png" alt="캐릭터" class="idle-bounce" />
  </div>
  <style>
    .idle-bounce {
      transform-origin: bottom center;
      animation: breathe 3s ease-in-out infinite;
    }
    @keyframes breathe {
      0%, 100% { transform: scaleY(1) translateY(0); }
      50% { transform: scaleY(1.025) translateY(-3px); }
    }
  </style>
  ```

#### ③ 상단 고정형 랭킹/상황 브리핑 바 (Sticky Top Indicator)
* **무엇인가:** 영상 상단에 '[5위] K2 · 회사를 나눠 둔 곳'처럼 현재 설명 중인 챕터와 핵심 요약을 뱃지 형태로 고정 노출하는 기법.
* **언제 쓰나:** 40대 이상 시청자가 영상 중간에 진입하거나 집중력이 흐려졌을 때도 "지금 무슨 이야기를 하는 중인지" 즉각 인지시키고자 할 때.
* **HTML/CSS 구현:**
  ```html
  <div class="chapter-badge">
    <span class="rank">5위</span>
    <span class="topic">K2 · 회사를 나눠 둔 곳</span>
  </div>
  <style>
    .chapter-badge {
      display: inline-flex; align-items: center; border-radius: 8px;
      overflow: hidden; box-shadow: 0 3px 8px rgba(0,0,0,0.2);
      font-size: 18px; font-weight: bold;
    }
    .chapter-badge .rank { background: #FFD200; color: #000; padding: 6px 14px; }
    .chapter-badge .topic { background: #1F2937; color: #FFF; padding: 6px 16px; }
  </style>
  ```
