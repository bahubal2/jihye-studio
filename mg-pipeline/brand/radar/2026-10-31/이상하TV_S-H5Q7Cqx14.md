### 8. 자동 제작(HTML/CSS)에 적용할 핵심 기법 3가지

#### ① 수치 충격 데이터 카드 & 마커 오버레이 (0:11)
* **어디에 쓰나**: 경제 해설에서 손실액, 지원금, 투자 규모 등 시청자가 직관적으로 체감해야 할 숫자가 나올 때.
* **HTML/CSS 구현법**:
  ```html
  <div class="stat-card">
    <span class="badge">쏟아부은 돈</span>
    <h1 class="amount">6,200억 원</h1>
  </div>
  ```
  ```css
  .stat-card {
    background: rgba(20, 20, 25, 0.85);
    border: 1px solid #ffcc00;
    border-radius: 12px;
    padding: 16px 28px;
    animation: popUp 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
  }
  @keyframes popUp {
    0% { transform: scale(0.8) translateY(20px); opacity: 0; }
    100% { transform: scale(1) translateY(0); opacity: 1; }
  }
  ```
  * *사진 위 빨간 마킹*: SVG `<path>`에 `stroke-dasharray`, `stroke-dashoffset`을 주고 `transition`으로 0.6초간 테두리가 그려지는 애니메이션 구현.

#### ② 인터랙티브 지도 거리 진행선 (0:41, 1:40)
* **어디에 쓰나**: 지리적 거리, 사업 규모, 단계별 진행 과정을 시각적으로 비교 설명할 때.
* **HTML/CSS 구현법**:
  * 배경 지도 위에 점 두 개(`A 지점`, `B 지점`)를 두고, SVG 점선(Dashed Line)을 애니메이션 처리.
  ```html
  <svg class="map-track" viewBox="0 0 500 100">
    <line x1="50" y1="50" x2="450" y2="50" class="track-line" />
    <circle cx="50" cy="50" r="8" class="point-a" />
    <circle cx="450" cy="50" r="8" class="point-b" />
  </svg>
  ```
  ```css
  .track-line {
    stroke: #ffcc00;
    stroke-width: 4;
    stroke-dasharray: 8 4;
    animation: dashMove 1.5s linear infinite;
  }
  @keyframes dashMove {
    to { stroke-dashoffset: -24; }
  }
  ```

#### ③ 컨텍스트 메타 뱃지 (좌상단 정보창, 0:04, 0:41)
* **어디에 쓰나**: 과거 사건, 심리 실험 연도, 경제 지표 발표 시기 등 '시점과 공간'을 설명 내레이션과 분리해 깔끔하게 인지시킬 때.
* **HTML/CSS 구현법**:

    <span class="indicator"></span>
    <span class="year">1998년 여름</span>
    <span class="divider">|</span>

  ```

    position: absolute;
    top: 40px;
    left: 40px;
    display: inline-flex;
    align-items: center;
    gap: 8px;
    background: rgba(10, 15, 30, 0.85);
    border-left: 4px solid #ffcc00;
    padding: 8px 16px;
    border-radius: 4px;
    font-family: 'Pretendard', sans-serif;
    color: #fff;
    font-size: 18px;
  }
  .indicator {
    width: 8px; height: 8px;
    background: #ffcc00;
    border-radius: 50%;
    animation: blink 1s infinite alternate;
  }
  ```
