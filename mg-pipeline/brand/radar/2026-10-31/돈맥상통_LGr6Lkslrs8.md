### 1. 후킹 대본 구조 (0~30초)

* **[0:00~0:06] "고기를 마음껏 먹는 명륜진사갈비 1인당 가격이 이제 고깃집 삼겹살 1인분보다 비쌉니다."**
  * **연출 장치**: **상식의 전복(반전) + 직관적 비교**. '무한리필=가성비'라는 대중적 통념을 깨며 시청자의 즉각적인 인지 부조화를 유발.
* **[0:07~0:15] "지난해 2만 1,900원까지 올랐는데, 올여름 서울 식당 삼겹살은 평균 2만 1,300원 남짓이었습니다."**
  * **연출 장치**: **구체적 숫자 충격(데이터 팩트 폭격)**. 앞선 주장을 실제 통계치(21,900원 vs 21,300원)로 즉시 입증해 신뢰도 확보.
* **[0:16~0:21] "한때는 비슷한 돈이면 실컷 먹는 무한리필로 가는 게 남는 장사였습니다."**
  * **연출 장치**: **공감대 형성(과거 회상)**. 과거 소비 경험을 환기하여 시청자가 고개를 끄덕이게 유도.
* **[0:22~0:27] "그렇게 퍼 주다 보니 가게는 남는 게 없어 가격을 올렸겠거니 싶으실 거예요."**
  * **연출 장치**: **시청자 마음 읽기(가설 제시/시청자 지목)**. "다들 이렇게 생각하시죠?"라며 시청자의 고정관념을 짚어줌.
* **[0:28~0:45 (연결)] "실제로 줄 서서 먹던 무한리필... 아홉 곳 넘게 사라졌습니다. 그런데 문을 닫은 건 많이 먹는 손님 때문이 아니었습니다. 진짜 이유는 따로 있었습니다."**
  * **연출 장치**: **오픈 루프(Open Loop, 지적 호기심 극대화)**. 흔한 폐업 이유를 부정하고 숨겨진 이면(본사 착취, 사채 등)을 예고하며 이탈 방지.

### 3. 30초 이후 컷 수 및 그래픽 빈도 (추정)

* **1분당 컷 수**: 약 **8~11회** (평균 컷 지속 시간 약 5.5~7.5초). 40대 이상 타깃에 맞춰 컷 전환이 어지럽지 않고 안정적인 호흡을 유지함.
* **1분당 정보성 그래픽(인포그래픽/텍스트 박스) 수**: 약 **4~6회** 등장.
  * 매장 감소율(-90%), 순위 배너(5위 명륜진사갈비), 20% 매출 급락, 18% 고금리 대부업 이자율 등 핵심 키워드/숫자마다 그래픽 카드가 즉각 반응함.

### 4. 화면 레이어 구조

1. **바닥 레이어 (Background)**:
   * 미드저니/Stable Diffusion 등 텍스처와 빛 표현이 섬세한 **고품질 웹툰/지브리풍 2D AI 일러스트**.
   * 실사 대신 따뜻한 감성의 일러스트를 사용해 경제/사건 해설 특유의 삭막함·피로감을 완화.
2. **중간 레이어 (Character & Object)**:
   * 레이어가 분리된 주요 인물(가족, 자영업자 사장, 회장 등) 및 핵심 오브젝트(연기, 영수증 더미, 고기 불판).
   * 고정 이미지가 아닌 스케일 변화(Ken Burns) 및 미세 위치 이동 적용.
3. **앞 레이어 (Foreground / UI & Data Graphics)**:
   * **상단 배너**: 라운드 사각 뱃지(노란색/하얀색 폰트)로 핵심 통계 수치 제시.
   * **하단 자막**: 가독성 높은 산세리프 볼드 폰트에 검은 외곽선 처리.
   * **구독 유도/순위 타이틀**: 좌측 상단 넘버링 타이틀 바(`5위 | 명륜진사갈비`).

### 5. 글자(타이포그래피) 연출

* **크기**:
  * 내레이션 기본 자막: 화면 세로 높이 기준 약 **4~5%**.
  * 핵심 강조 숫자/키워드(예: `2만 1,900원`, `연 최고 18%`): 화면 세로 높이 기준 **7~10%**.
* **색상 팔레트**:
  * 배경 박스: 짙은 네이비/차콜 (`#1F2937`) 또는 반투명 블랙.
  * 강조 폰트: **형광 노랑(`Yellow/Gold`)**, **경고 빨강/주황**, 화이트.
* **등장 및 강조 방식**:
  * 핵심 숫자는 `Scale(0.8 -> 1.0)`의 **바운스 팝업(Pop-up)**으로 등장.
  * 텍스트 전체를 한 번에 띄우기보다 "문맥 박스"가 먼저 뜨고 그 안의 숫자가 반 박자 늦게 강조색으로 튀어나와 시선을 집중시킴.
* **스타일**:
  * 40대 이상 시청자를 배려해 장식 요소(세리프)가 없는 두꺼운 고딕 계열(프리텐다드, 에스코어드림 등 추정) 채택, 획 대비와 외곽선 명암비를 극대화함.

### 6. 전환 및 카메라 연출

* **전환(Transition)**:
  * 인위적인 3D 전환이나 왜곡 효과는 배제하고, 주로 **하드 컷(Hard Cut)**과 부드러운 **디졸브(Cross Dissolve / 0.3~0.5초)** 사용.
* **카메라 워크 (Ken Burns Effect)**:
  * 모든 스틸 컷에 멈춤 없이 1.05~1.15배 수준의 **서서히 밀기(Slow Zoom-in)** 또는 **좌우 팬(Slow Pan)**을 적용해 정지 이미지의 지루함 탈피.
  * 사장의 영수증 씬에서는 아래로 천천히 내려다보는 틸트(Tilt) 다운으로 침울함 전달.
* **화면 효과**:
  * 고기 굽는 씬의 반투명 연기 파티클 루프, 실내 창문의 반사광 등 자연스러운 2D 앰비언트 효과 가미.

### 7. 오디오 및 사운드 디자인

* **효과음(SFX)**:
  * **팝업음(Pop/Blop)**: 수치 및 그래픽 카드 등장 시 과하지 않은 둔탁하고 깔끔한 팝 사운드.
  * **임팩트 붐(Whoosh/Dull Thud)**: 반전 문장("많이 먹는 손님 때문이 아니었다") 등장 시 낮은 저음 충격음으로 집중 환기.
  * 빈도: 10~15초당 1회 정도로 절제하여 나레이션 전달력 방해 금지.
* **배경음악(BGM)**:
  * 도입부는 잔잔하면서도 살짝 서정적인 어쿠스틱/로파이 계열로 시작하여, 폐업/의혹 해설 구간에서는 신비롭고 긴장감 있는 다큐멘터리 앰비언트 톤으로 자연스럽게 전환.

### 8. 우리 채널에 즉시 도입할 핵심 연출 3가지 (HTML/CSS 모션그래픽 구현법)

#### ① [수치 대비 팝업 카드 (Comparison Stat Card)]
* **무엇인가**: 0:07처럼 화면 좌/우 상단에 대립되는 두 가격(무한리필 vs 삼겹살 1인분)을 뱃지 형태로 띄워 시각적 격차를 단번에 보여주는 기법.
* **언제 쓰나**: "A vs B" 물가 비교, 수익률 비교, 과거 vs 현재 지표를 대조할 때.
* **HTML/CSS 구현법**:
  ```html
  <div class="stat-badge">
    <span class="sub-label">지난해 · 명륜진사갈비 1인당</span>
    <span class="main-val">2만 1,900원</span>
  </div>
  ```
  ```css
  .stat-badge {
    background: rgba(30, 30, 30, 0.85);
    border-radius: 12px;
    padding: 10px 18px;
    box-shadow: 0 8px 24px rgba(0,0,0,0.3);
    animation: popBounce 0.5s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
  }
  .main-val {
    color: #FFD13B; /* 선명한 옐로우 */
    font-size: 28px;
    font-weight: 800;
  }
  @keyframes popBounce {
    0% { transform: scale(0.6); opacity: 0; }
    100% { transform: scale(1); opacity: 1; }
  }
  ```

#### ② [상식 파괴 반전 텍스트 박스 (Myth-Busting Text Banner)]
* **무엇인가**: 0:40의 "그 가게들이 문을 닫은 건 / 많이 먹는 손님 때문이 / 아니었다"처럼 상단에는 상식, 중앙에는 볼드 강조, 하단에는 부정/반전을 배치하는 계층형 텍스트 박스.
* **언제 쓰나**: 시청자가 잘못 알고 있는 통념을 깨뜨리며 영상 본론으로 진입하는 브릿지 구간.
* **HTML/CSS 구현법**:
  ```html
  <div class="myth-box">
    <div class="context">그 가게들이 문을 닫은 건</div>
    <div class="highlight-target">많이 먹는 손님 때문이</div>
    <div class="punchline">아니었다</div>
  </div>
  ```
  ```css
  .myth-box {
    display: inline-flex;
    flex-direction: column;
    align-items: center;
    background: rgba(15, 23, 42, 0.9);
    border: 1px solid rgba(255,255,255,0.15);
    padding: 14px 24px;
    border-radius: 8px;
  }
  .highlight-target {
    color: #F87171; /* 경고 레드 */
    font-size: 32px;
    font-weight: 900;
    margin: 4px 0;
  }
  .punchline {
    color: #FFF;
    font-size: 24px;
    font-weight: 700;
  }
  ```

#### ③ [자동화 최적화 켄 번스(Ken Burns) 배경 래퍼]
* **무엇인가**: 정적 2D 일러스트 이미지에 미세한 확대·이동을 부여해 자연스러운 영상미를 연출하는 카메라 기법.
* **언제 쓰나**: 모든 정지 이미지 기반 장면 전환 시 기본 래퍼로 상시 적용.
* **HTML/CSS 구현법**:
  ```css
  .scene-container {
    width: 100vw;
    height: 100vh;
    overflow: hidden;
    position: relative;
  }
  .ai-bg {
    width: 100%;
    height: 100%;
    object-fit: cover;
    animation: kenBurnsZoom 7s ease-out forwards;
  }
  @keyframes kenBurnsZoom {
    0% {
      transform: scale(1.0) translate(0, 0);
    }
    100% {
      transform: scale(1.08) translate(-1%, -1%);
    }
  }
  ```
