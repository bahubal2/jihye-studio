### 7. 55세 이상 남성 경제 채널(HTML/CSS 자동화)에 즉시 적용할 기법 5가지

#### ① '결실을 못 볼 것을 알면서도'형 시니어 공감형 인물 서사 삽입
* **대본**: 은퇴 자산가나 전설적 투자자의 일대기를 다룰 때, *"여든의 나이에 본인이 결과를 못 볼 것을 알면서도 10년 뒤 대한민국 산업을 위해 투자한 사람이 있습니다"* 식의 장기적 헌신 서사 부여.
* **화면(HTML/CSS)**: 흑백 인물 스케치 위에 은은한 골드/세피아 톤 비네팅 오버레이와 천천히 줌인되는 켄 번스(Ken Burns) 효과.
```css
.portrait-container {
  overflow: hidden;
  position: relative;
  filter: sepia(30%) contrast(110%);
}
.portrait-img {
  animation: kenBurns 12s ease-out forwards;
}
@keyframes kenBurns {
  from { transform: scale(1.0); }
  to { transform: scale(1.12) translate(-2%, -1%); }
}
```

#### ② '뜻밖의 반전(Plot Twist)' 브레이크 프레임
* **대본**: 경제 지표나 폭락장을 설명하다가 3~4분 시점에 *"하지만 여기서 대다수 투자자가 놓친 결정적 반전이 나타납니다"* 멘트 후 0.5초 침묵.
* **화면(HTML/CSS)**: 화면 전체에 순간적인 암전/블러가 걸린 뒤 텍스트 카드가 임팩트 있게 슬라이드업.
```html
<div class="twist-alert">
  <span class="badge">반전</span>
  <h2>통계가 숨기고 있는 진짜 숫자</h2>
</div>
```
```css
.twist-alert {
  background: rgba(15, 23, 42, 0.95);
  border-left: 6px solid #e11d48;
  padding: 24px;
  animation: slideUp 0.6s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
@keyframes slideUp {
  from { opacity: 0; transform: translateY(30px); }
  to { opacity: 1; transform: translateY(0); }
}
```

#### ③ '대체 어디서 왔을까?' 호기심 유발 질문 분기점
* **대본**: 원인과 주동자를 밝히기 직전 *"그렇다면 이 막대한 부(돈)는 대체 어디로 흘러들어갔을까요?"*라는 질문을 명시적으로 던져 뇌의 답변 대기 상태(오픈 루프) 유도.
* **화면(HTML/CSS)**: 큼직한 질문 타이포그래피에 부드러운 그라데이션 광택 애니메이션 적용.
```css
.question-text {
  font-size: 38px;
  font-weight: 800;
  background: linear-gradient(90deg, #ffffff 0%, #38bdf8 50%, #ffffff 100%);
  background-size: 200% auto;
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  animation: shine 4s linear infinite;
}
@keyframes shine {
  to { background-position: 200% center; }
}
```

#### ④ 내부 메커니즘 X-Ray 분해도 (내부 자금 흐름 시각화)
* **대본**: 기업의 분식회계나 부동산 프로젝트 파이낸싱(PF) 부실 과정을 설명할 때 *"껍질 아래에서 돈줄이 어떻게 막혔는지 살펴보면..."*과 같은 해부학적 비유 사용.
* **화면(HTML/CSS)**: SVG 마스크와 `stroke-dasharray`를 이용해 자금 파이프라인이 붉은색으로 막히는 흐름 모션 자동 생성.
```html
<svg width="400" height="200" viewBox="0 0 400 200">
  <path class="flow-line" d="M 20 100 H 380" />
</svg>
```
```css
.flow-line {
  stroke: #ef4444;
  stroke-width: 8;
  stroke-dasharray: 20, 10;
  animation: flowAnim 1.5s linear infinite;
}
@keyframes flowAnim {
  from { stroke-dashoffset: 60; }
  to { stroke-dashoffset: 0; }
}
```

#### ⑤ 실생활 오인 상식 바로잡기 (클릭 미끼가 아닌 '실질적 손실 예방')
* **대본**: 후반부에 *"여러분의 통장에 찍힌 이 상품, 사실 안전자산이 아닙니다(서양칠엽수 먹으면 탈나듯)"*처럼 일상에서 흔히 착각하는 금융 상품/세금 오해를 경고.
* **화면(HTML/CSS)**: '진짜 vs 가짜' 대비 분할 카드 컴포넌트(좌: 오해, 우: 진실)를 CSS 그리드로 자동 레이아웃.
```html
<div class="compare-grid">
  <div class="card false-card">흔히 하는 착각: 확정 고금리</div>
  <div class="card true-card">숨겨진 실체: 원금 손실 위험</div>
</div>
```
```css
.compare-grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 20px;
}

.true-card { background: #1e293b; border-top: 4px solid #ef4444; font-weight: bold; }
```
