### 8. 우리 채널(경제·심리 자동화)에 적용할 핵심 기법 3가지

#### 기법 1: [과거의 번영 vs 현재의 결핍] 대비 앵커링 (Contrast Anchoring)
*   **무엇인가:** 사건의 심각성을 알리기 전, "원래 얼마나 대단했는지"를 먼저 극단적으로 보여주고 한순간에 바닥으로 떨어뜨리는 시각/내러티브 공식.
*   **언제 쓰나:** 경제 위기(예: '1990년대 일본 버블의 화려함 vs 잃어버린 30년', '잘나가던 우량 기업의 파산')를 설명하는 도입부 30초.
*   **HTML/CSS 모션그래픽 구현법:**
    *   따뜻한 웜톤(풍요) 배경에서 차가운 쿨톤/흑백(위기)으로 `filter`와 CSS 애니메이션을 이용해 1.5초 만에 전환.
    ```css
    .scene-contrast {
      animation: prosperityToCrisis 1.5s ease-in-out forwards;
      animation-delay: 2.5s;
    }
    @keyframes prosperityToCrisis {
      0% { filter: sepia(0.2) saturate(1.3) brightness(1.05); }
      100% { filter: grayscale(0.8) contrast(1.2) brightness(0.7); }
    }
    ```

#### 기법 2: AI 일러스트의 '켄 번스(Ken Burns) + 깊이감(Depth)' 레이어 분리
*   **무엇인가:** 평면 AI 일러스트를 한 덩어리로 움직이지 않고, 전경(주제)과 배경을 분리하여 다른 속도로 스케일링/이동시킴으로써 실사 다큐멘터리 같은 2.5D 깊이감 연출.
*   **언제 쓰나:** 인포그래픽 데이터가 나오기 전, 역사적 배경이나 경제적 사건의 인물/배경을 소개할 때.
*   **HTML/CSS 모션그래픽 구현법:**
    *   배경과 전경을 `position: absolute`로 겹치고, CSS `transform`의 속도를 다르게 주어 시차(Parallax) 효과를 줌.
    ```html
    <div class="viewport">
      <div class="layer-bg"></div>
      <div class="layer-fg"></div>
    </div>
    ```
    ```css
    .viewport { width: 1920px; height: 1080px; overflow: hidden; position: relative; }
    .layer-bg {
      position: absolute; width: 110%; height: 110%;
      background: url('bg-forest.webp') center/cover;
      animation: panZoomBg 10s ease-out forwards;
    }
    .layer-fg {
      position: absolute; width: 105%; height: 105%;
      background: url('fg-character.webp') bottom/contain no-repeat;
      animation: zoomFg 10s ease-out forwards;
    }
    @keyframes panZoomBg {
      0% { transform: scale(1.0) translate(0, 0); }
      100% { transform: scale(1.12) translate(-2%, -1%); }
    }
    @keyframes zoomFg {
      0% { transform: scale(1.0); }
      100% { transform: scale(1.04); }
    }
    ```

#### 기법 3: AI 일러스트와 '실사 마크로(접사) 스톡'의 교차 검증 연출
*   **무엇인가:** AI 이미지만 연속되면 영상이 가짜/환상처럼 느껴져 신뢰도가 하락합니다. 핵심 증거물(병든 수피 2:46, 실제 열매 1:11, 가공된 제품 2:29)이 언급되는 순간에 **고화질 실사 클로즈업 사진/영상**을 번갈아 배치해 '실제 현실의 이야기'임을 뇌에 각인시키는 기법입니다.
*   **언제 쓰나:** 심리 실험의 실제 논문 표지, 경제 지표의 실제 영수증/지폐, 역사적 사건의 실제 신문 기사 1면을 보여줄 때.
*   **HTML/CSS 모션그래픽 구현법:**
    *   부드러운 크로스페이드와 함께 실사 이미지 테두리에 미세한 비네팅(Vignette)을 주어 AI 화면과의 이질감을 줄이고 몰입도를 높임.
    ```css
    .evidence-overlay {
      position: absolute;
      width: 100%; height: 100%;
      background: radial-gradient(circle, transparent 60%, rgba(0,0,0,0.6) 100%),
                  url('real-stock-macro.webp') center/cover;
      opacity: 0;
      animation: fadeInRealProof 0.8s ease forwards;
    }
    @keyframes fadeInRealProof {
      to { opacity: 1; }
    }
    ```
