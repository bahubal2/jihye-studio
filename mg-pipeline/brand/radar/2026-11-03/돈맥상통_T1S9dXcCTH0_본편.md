### 7. 55세 이상 경제 채널을 위한 '이탈 방지 CSS/HTML 기법' 5선

55세 이상 남성 시청층은 **"글씨가 작거나, 전환이 난잡하거나, 전문 금융 용어만 나열될 때"** 즉시 이탈합니다. 웹 렌더링 기반(Remotion/Puppeteer 등) 모션그래픽 파이프라인에 즉시 적용 가능한 5가지 솔루션입니다.

#### 기법 1. [통념 파괴 대비 박스] "아재 옷이라 망했다? 아닙니다"
*   **대본 공식**: 시청자가 당연하게 믿는 상식을 먼저 언급하고 1초 만에 뒤집는다.
    *   *예시: "다들 부동산 거품 때문이라고 하죠? 아닙니다. 진짜 원인은 따로 있었습니다."*
*   **화면 구현 (HTML/CSS)**:
    *   좌측엔 '대중의 오해(회색 텍스트+취소선)', 우측엔 '진짜 원인(선명한 빨강/노랑)'을 큼직한 폰트(32px 이상)로 스탠딩.
```html
<div class="fact-check-box">
  <div class="myth">기존 생각: 아저씨 옷 이미지 때문?</div>
  <div class="arrow">➔</div>
  <div class="truth">팩트: 그때도 아재 옷으로 1위 했다!</div>
</div>

<style>
.fact-check-box {
  display: flex; align-items: center; justify-content: center;
  background: #1e232d; border-radius: 12px; padding: 24px; gap: 20px;
}
.myth { font-size: 28px; color: #8a94a6; text-decoration: line-through; }
.arrow { font-size: 32px; color: #fff; }
.truth { font-size: 34px; font-weight: 800; color: #ffcc00; }
</style>
```

#### 기법 2. [50% 반토막 쇼크 게이지] 복잡한 재무제표 대신 단일 지표 극대화
*   **대본 공식**: 수치를 두 개 이상 연속해 부르지 않고, '줄어든 폭'을 일상 비유로 못 박는다.
    *   *예시: "2013년 5,800억이던 매출이 지난해 2,900억. 딱 절반만 남았습니다."*
*   **화면 구현 (HTML/CSS)**:
    *   화면 전체를 가로지르는 두꺼운 바(Bar) 차트가 순식간에 반으로 줄어들며 텍스트 카운트다운.
```html
<div class="bar-container">
  <div class="bar-label">매출 폭락: 5,800억 ➔ 2,900억 (-50%)</div>
  <div class="bar-track">
    <div class="bar-fill"></div>
  </div>
</div>

<style>
.bar-container { width: 80%; margin: auto; }
.bar-label { font-size: 32px; font-weight: bold; color: #ffffff; margin-bottom: 12px; }
.bar-track { width: 100%; height: 50px; background: #333d4b; border-radius: 25px; overflow: hidden; }
.bar-fill {
  width: 100%; height: 100%; background: #e54b4b;
  animation: shrinkHalf 1.5s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
@keyframes shrinkHalf {
  0% { width: 100%; }
  100% { width: 50%; }
}
</style>
```

#### 기법 3. [1인칭 고백형 몰입 자막] 감정적 쐐기 박기
*   **대본 공식**: 객관적 사실 전달 중간에 화자의 주관적 평가를 툭 던져 주의를 환기한다.
    *   *예시: "통계보다 더 놀라운 건 바로 이 다음 대목입니다." / "저는 이게 가장 위험하다고 봅니다."*
*   **화면 구현 (HTML/CSS)**:
    *   화면 하단 일반 자막과 분리하여, 화면 정중앙에 만년필로 밑줄을 긋는 듯한 하이라이트 애니메이션 표출.

```html
</div>

<style>
.confession-text {
  font-size: 40px; font-weight: 900; color: #ffffff; text-align: center;
```


#### 기법 5. [순위 브릿지 줌인] "다음 순위는 더 심합니다" 루프 생성
*   **대본 공식**: 한 사례를 끝낼 때 결론을 내지 않고, 다음 사례의 강도가 더 세다는 점을 예고하며 연결.
    *   *예시: "네파도 충격적이지만, 3위 브랜드 상황은 훨씬 더 심각합니다."*
*   **화면 구현 (HTML/CSS)**:
    *   텍스트가 화면 밖에서 시청자 눈앞으로 돌진해 오듯 스케일업(Scale-up)되며 셔터음 SFX와 결합.
```html
<div class="next-rank-card">
  <div class="rank-num">3위는 더합니다</div>
</div>

<style>
.next-rank-card {
  display: flex; justify-content: center; align-items: center;
  height: 100vh; background: rgba(10, 12, 16, 0.9);
}
.rank-num {
  font-size: 64px; font-weight: 900; color: #ff3b30;
  animation: slamZoom 0.5s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
}
@keyframes slamZoom {
  0% { transform: scale(0.3); opacity: 0; }
  100% { transform: scale(1); opacity: 1; }
}
</style>
```
