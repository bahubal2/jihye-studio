### 3. 숫자 전달 방식

* **1분당 소리(내레이션)로 언급되는 숫자:** 약 3~5개 수준 (예: "71만 2천 명", "6만 명", "329만 원", "51.4%", "7,500개", "14.1%", "6,000명"). 과도한 숫자 나열을 피하고 핵심 지표만 발음합니다.
* **화면으로만 보강하는 숫자:**
  * 그래프 상의 연도 표기(1997년, 2000년대, 현재), 세부 하락 비율, 통계청/금융감독원 출처 마크 등 텍스트 배지는 화면에 잔잔히 노출하여 신뢰성만 보강.
* **숫자를 생활·감정으로 체감시키는 화법:**
  * 단순 "정착률 51.4%"로 끝내지 않고 **"두 명 중 한 명은 1년도 못 버티고 튕겨 나간다"**로 환산.

### 7. 55세 이상 타깃 경제 채널을 위한 'HTML/CSS 자동화 접목 5대 기법'

중장년층 타깃은 **큰 글씨, 명확한 대조, 과거 회상과 노후 현실의 직결**이 핵심입니다.

#### 기법 1. [도발형 질문 후 반전 카드 노출]
* **대본:** "인원은 늘었는데 왜 망해갈까요? 여기가 충격적인 반전입니다."
* **화면(CSS):** 화면 중앙 카드 컴포넌트가 3D Flip 되며 뒷면의 빨간색 경고 텍스트 노출.
```html
<div class="flip-card">
  <div class="flip-inner">
    <div class="flip-front">총 종사자 71만 명 (증가?)</div>
    <div class="flip-back">월급 0원 부업자 80% (착시!)</div>
  </div>
</div>
<style>
.flip-card { perspective: 1000px; width: 400px; height: 120px; }
.flip-inner { transition: transform 0.6s ease; transform-style: preserve-3d; }
.flip-card.active .flip-inner { transform: rotateY(180deg); }
.flip-front, .flip-back { position: absolute; width: 100%; height: 100%; backface-visibility: hidden; font-size: 28px; font-weight: bold; display: flex; align-items: center; justify-content: center; border-radius: 12px; }
.flip-front { background: #f1f3f5; color: #333; }
.flip-back { background: #e03131; color: #fff; transform: rotateY(180deg); }
</style>
```

#### 기법 2. [체감형 1/N 픽토그램 소멸 연출]
* **대본:** "정착률 50%라는 건, 둘 중 한 명은 1년 안에 쫓겨난다는 뜻입니다."
* **화면(CSS):** 2개의 사람 아이콘 중 우측 아이콘이 흑백으로 변하며 아래로 페이드아웃.
```html
<div class="ratio-box">
  <span class="person stay">👤 생존</span>
  <span class="person drop">👤 탈락</span>
</div>
<style>
.ratio-box { font-size: 36px; display: flex; gap: 20px; }
.person.drop {
  animation: dropOut 1.5s ease forwards 1s;
}
@keyframes dropOut {
  to { opacity: 0.2; transform: translateY(30px) scale(0.9); filter: grayscale(1); }
}
</style>
```

#### 기법 3. [인정받던 과거 vs 냉혹한 현재 '스플릿 비교선']
* **대본:** "불과 몇 년 전까지 대우받던 기술이, 지금은 버튼 하나로 끝납니다."
* **화면(CSS):** 중앙의 경계선(Line)이 그어지며 좌측(과거/골드)과 우측(현재/블루그레이)의 가치 대조.
```html
<div class="contrast-container">
  <div class="side past">과거: 집안의 자랑 (1순위 신랑감)</div>
  <div class="divider"></div>
  <div class="side now">현재: 점포 폐쇄 (희망퇴직 1순위)</div>
</div>
<style>
.contrast-container { display: flex; align-items: center; width: 800px; height: 100px; background: #212529; border-radius: 8px; overflow: hidden; }
.side { flex: 1; text-align: center; font-size: 24px; font-weight: bold; }
.past { color: #fcc419; }
.now { color: #ff6b6b; }
.divider { width: 3px; height: 70%; background: #495057; animation: growLine 0.5s ease-in; }
@keyframes growLine { from { height: 0; } to { height: 70%; } }
</style>
```

#### 기법 4. [시청자 지목 핀포인트 강조 박스]
* **대본:** "남의 일이 아닙니다. 지금 이 영상을 보시는 바로 여러분 이야기입니다."
* **화면(CSS):** 시청자 범주 텍스트 박스 주위로 굵은 경고 테두리가 펄스(Pulse) 형태로 강조.
```html
<div class="target-alert">
  ⚠️ 5060 사무직·관리자 은퇴 준비생
</div>
<style>
.target-alert {
  font-size: 32px; font-weight: 800; color: #fff; background: #1864ab;
  padding: 15px 30px; border-radius: 10px;
  box-shadow: 0 0 0 0 rgba(24, 100, 171, 0.7);
  animation: pulse 1.5s infinite;
}
@keyframes pulse {
  0% { transform: scale(0.98); box-shadow: 0 0 0 0 rgba(224, 49, 49, 0.7); }
  70% { transform: scale(1.02); box-shadow: 0 0 0 20px rgba(224, 49, 49, 0); }
  100% { transform: scale(0.98); box-shadow: 0 0 0 0 rgba(224, 49, 49, 0); }
}
</style>
```

#### 기법 5. [다음 순위 유인용 '티저 블러(Teaser Blur)' 바]
* **대본:** "은행원보다 더 빠르게 사라지는 2위, 과연 내 일자리는 안전할까요?"
* **화면(CSS):** 2위 텍스트는 보이지만 직업명은 블러(흐림) 처리되어 있다가 다음 챕터로 넘어갈 때 해제.
```html
<div class="rank-teaser">
  <span class="rank-badge">다음 2위</span>
  <span class="job-title blurred">대기업 단순 사무직</span>
</div>
<style>
.rank-teaser { display: flex; align-items: center; gap: 15px; font-size: 30px; }
.rank-badge { background: #e03131; color: white; padding: 5px 15px; border-radius: 6px; }
.job-title.blurred {
  filter: blur(8px);
  user-select: none;
  transition: filter 0.8s ease;
}
/* 다음 순위 진입 시 active 클래스 추가 */
.job-title.blurred.active { filter: blur(0); }
</style>
```
