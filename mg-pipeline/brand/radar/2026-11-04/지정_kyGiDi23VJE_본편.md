### 7. 55세 이상 남성 경제 채널(HTML/CSS 자동화) 즉시 도입 5가지 기법

시니어 남성은 **'내 돈을 지키는 팩트'**, **'불합리한 손해에 대한 분노'**, **'직관적인 비교'**에 극도로 높은 반응을 보입니다.

#### ① '기준가 vs 폭리' 2분할 게이지 바 (대비 분노 유발)
- **무엇을**: 정상 가격과 피해 가격을 한눈에 대조해 부당함을 직관적으로 전달.
- **대본**: "원래 5천 원이면 갈 길입니다. 그런데 청구된 돈은 11만 원, 무려 20배가 넘습니다."
- **화면 (HTML/CSS)**:
  ```html
  <div class="compare-box">
    <div class="bar normal" style="width: 15%;">정상가: 5,000원</div>
    <div class="bar rip-off" style="width: 100%;">바가지: 110,000원 (22배 폭리!)</div>
  </div>
  ```
  `rip-off` 바에 붉은색 그라디언트와 `keyframes`로 흔들림(shake) 애니메이션을 줘 시각적 충격을 줍니다.

#### ② '그것이 알고싶다'식 챕터 전환 슬라이드 (미시 → 거시 확장)
- **무엇을**: 단순 개인 피해에서 제도·국가적 위기로 주제를 격상시키는 전환 브릿지.
- **대본**: "그런데 말입니다. 이게 과연 몇몇 악덕 업자만의 문제일까요? 진짜 심각한 건 시스템 자체가 무너졌다는 데 있습니다."
- **화면 (HTML/CSS)**:
  화면 전체가 암전(`opacity: 0 -> 1`의 검은 비네팅)된 후 굵은 백색 명조체 자막이 타이핑되듯 나타나는 CSS 모션:
  ```css
  .bridge-text { font-size: 42px; font-weight: 800; color: #ff4747; border-left: 6px solid #ff4747; padding-left: 20px; }
  ```

#### ③ 체감 환산 뱃지 (생소한 숫자를 즉각 내 지갑 기준으로 치환)
- **무엇을**: 외화, 퍼센트, 거대 통계를 시니어의 생활 물가(국밥, 4인 가족 지출)로 자동 변환 팝업.
- **대본**: "100만 동이라고 하면 눈이 돌아가지만, 우리 돈으로 치면 딱 5만 원, 국밥 몇 그릇 값입니다."
- **화면 (HTML/CSS)**:
  텍스트 옆에 주황색 둥근 배지 태그를 CSS `transform: scale(0) -> scale(1)`로 띄우기:
  ```html
  <span class="raw-num">1,000,000 VND</span>
  <span class="krw-badge">≈ 한국 돈 50,000원 (국밥 5그릇)</span>
  ```

#### ④ 지도 위 '동적 점선 경로 드로잉' (공간 감각과 리얼리티 확보)
- **무엇을**: 텍스트 설명 대신 공항-호텔, 생산지-유통지 간 거리를 지도 위 SVG 라인으로 연결.
- **대본**: "공항에서 숙소까지 딱 4.5km. 걸어가도 금방인 이 짧은 거리에서 사건이 터집니다."
- **화면 (HTML/CSS)**:
  SVG의 `stroke-dasharray`와 `stroke-dashoffset` 속성을 이용해 선이 스르륵 그어지는 CSS 애니메이션:
  ```css
  @keyframes drawLine { to { stroke-dashoffset: 0; } }
  .route-path { stroke-dasharray: 500; stroke-dashoffset: 500; animation: drawLine 2s forwards ease-in-out; }
  ```

#### ⑤ '신뢰 붕괴 메타포' 균열/침식 애니메이션 (추상적 결론 시각화)
- **무엇을**: "신뢰를 잃었다"는 뜬구름 잡는 결론을 바닥 균열이나 무너지는 블록으로 강렬하게 각인.
- **대본**: "한 번 무너진 신뢰는 바닥을 칩니다. 손님은 발길을 끊고, 도시는 서서히 가라앉습니다."
- **화면 (HTML/CSS)**:
  CSS `clip-path`를 이용해 화면 중앙 카드가 깨진 유리처럼 지그재그로 갈라지며 아래로 떨어지는 효과:
  ```css
  @keyframes crumble {
    0% { transform: translateY(0); }
    100% { transform: translateY(80px) rotate(4deg); opacity: 0; }
  }
  .trust-card.broken { animation: crumble 1.2s forwards; }
  ```
