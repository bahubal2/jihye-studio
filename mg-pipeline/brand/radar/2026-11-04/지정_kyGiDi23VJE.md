### 5. 글자 연출 (타이포그래피)

* **크기**: 화면 높이 대비 약 **7~9%** 내외 (모바일에서도 시인성이 높은 적정 크기).
* **서체 및 색상**:
  * 단정한 고딕 계열(노토 산스 또는 프리텐다드 계열 추정).
  * 기본 텍스트는 **화이트(#FFFFFF)**, 핵심 강조 키워드는 작은따옴표(`'베트남 여행은 무조건 다낭'`, `'지갑'`, `'가성비'`)로 처리.
* **등장 및 자막 스타일**:
  * 팝업이나 과도한 모션 없이 문장 음절 호흡에 맞춰 **스무스하게 즉시 전환(Cut to Text)**.
  * 배경 일러스트가 밝은 수채화 톤이므로, 가독성을 위해 **약한 반투명 검은색 둥근 배경 박스(Rounded Box)** 또는 **선명한 블랙 드롭섀도우/외곽선**을 적용.

### 6. 전환과 카메라 워크

* **화면 전환**: 
  * 급격한 글리치나 트랜지션 그래픽을 배제하고, 차분한 **디졸브(Cross Dissolve)** 또는 **직접 컷(Hard Cut)** 위주 사용.
* **카메라 워크 (2.5D 모션)**:
  * 정지된 AI 일러스트에 **서서히 들어가는 슬로우 줌인(Slow Zoom-in)** 또는 **수평 패닝(Slow Pan)**을 100% 적용하여 정적인 지루함을 방지(켄 번스 효과).
* **특수 효과**: 
  * 모래성이 부서지는 장면 등 비유적 파트에서 잔잔한 화면 흔들림(Camera Shake)을 은은하게 활용(추정).

### 7. 소리 연출 (사운드 디자인)

* **배경음악 (BGM)**:
  * 비트가 강하지 않고 서정적이며 살짝 긴장감과 사색을 유도하는 **어쿠스틱/로파이 피아노 및 앰비언트 신스 계열** BGM 상시 재생.
  * 내레이터의 중저음 톤과 분리되도록 중고음 대역이 맑은 배경음 선택.
* **효과음 (SFX)**:
  * '쾅', '슉' 같은 자극적인 유튜브 기본 SFX를 최소화.
  * 장면 전환 시 작고 둔탁한 타격음(Dull Thud)이나 부드러운 바람/종이 넘김 소리 정도만 절제하여 배치(중장년층의 청각적 피로도 감소).

### 8. 우리 채널(모션그래픽 자동 제작)에 도입할 핵심 기법 3가지

#### ① '상징적 은유(Metaphor)' 비주얼 전환 기법
* **무엇인가**: 복잡한 경제적 배신감·신뢰 붕괴 현상을 '바닷물에 무너지는 모래성'처럼 한눈에 들어오는 상징적 이미지로 치환하는 연출.
* **언제 쓰나**: 복잡한 경제 위기, 버블 붕괴, 군중 심리의 이탈을 요약 설명할 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="metaphor-container">
    <img src="sandcastle_intact.png" class="layer base" />
    <img src="sandcastle_collapse.png" class="layer wave-overlay" />
  </div>
  <style>
    .metaphor-container { position: relative; overflow: hidden; width: 100vw; height: 100vh; }
    .layer { position: absolute; width: 100%; height: 100%; object-fit: cover; }
    .wave-overlay {
      animation: dissolveIn 4s cubic-bezier(0.4, 0, 0.2, 1) forwards;
      opacity: 0;
    }
    @keyframes dissolveIn {
      0% { opacity: 0; transform: scale(1); }
      100% { opacity: 1; transform: scale(1.04); }
    }
  </style>
  ```

#### ② AI 수채화 캔버스에 주는 '무한 켄 번스(Ken Burns) 패닝'
* **무엇인가**: 텍스트 생성형 AI 이미지를 완전한 비디오처럼 느껴지게 만드는 미세 스케일/위치 보간 모션.
* **언제 쓰나**: 40대 이상 시청자가 내레이션에 집중할 수 있도록 차분하고 고급스러운 배경 흐름을 만들 때.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="kenburns-wrapper">
    <img src="vietnam_street.png" class="zoom-pan-img" />
  </div>
  <style>
    .kenburns-wrapper { width: 100vw; height: 100vh; overflow: hidden; }
    .zoom-pan-img {
      width: 100%; height: 100%; object-fit: cover;
      animation: slowKenBurns 8s ease-out forwards;
    }
    @keyframes slowKenBurns {
      0% { transform: scale(1.0) translate(0, 0); }
      100% { transform: scale(1.08) translate(-1%, -1.5%); }
    }
  </style>
  ```

#### ③ 시인성 극대화 '반투명 캡슐 자막 바'
* **무엇인가**: 밝은 톤과 어두운 톤이 혼재된 일러스트 위에서도 텍스트가 묻히지 않도록 글자 뒤에 부드러운 다크 캡슐 패널을 동적 배치.
* **언제 쓰나**: 모바일 가독성이 필수적인 중장년층 대상 자막 출력 시.
* **HTML/CSS 구현 방법**:
  ```html
  <div class="caption-box">
    <span>"베트남 여행은 무조건 <strong class="highlight">다낭</strong>이라던 공식"</span>
  </div>
  <style>
    .caption-box {
      position: absolute; bottom: 8%; left: 50%;
      transform: translateX(-50%);
      background: rgba(18, 18, 18, 0.65);
      backdrop-filter: blur(4px);
      padding: 10px 24px;
      border-radius: 8px;
      color: #FFFFFF;
      font-size: 2.2rem;
      font-family: 'Pretendard', sans-serif;
      letter-spacing: -0.5px;
    }
    .highlight { color: #FFE866; font-weight: 700; }
  </style>
  ```
