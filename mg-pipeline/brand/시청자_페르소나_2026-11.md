# 시청자 페르소나 & 대본 작성 원칙 (2026-11-10 담당자 제공)
근거: 유튜브 스튜디오 시청자층 분석, 2026.10.12~11.08 (지난 28일). **대본 검수·다듬기 때 항상 이 기준으로 고친다.**

## 1. 실제 시청자 데이터
- 성별: 남성 80.6% / 여성 19.4%
- 연령: 65세 이상 34.6% / 55~64세 34.0% / 45~54세 21.3% / 35~44세 8.0% / 25~34세 2.1% → 55세 이상 68.6%, 45세 이상 89.9%
- 구독자 시청 비율 14.9% (조회의 약 85%가 비구독자 = 추천·탐색 유입)
- 한국어 자막 사용 37.1%
- 국내 시청이 대부분 (미국 1.9%)

## 2. 기준 시청자 (모든 대본은 이 한 사람에게 말한다)
"은퇴를 앞두었거나 이미 은퇴한 55~70대 남성 가장"
- 평생 일해서 모은 돈(퇴직금, 연금, 집 한 채)을 지키는 게 가장 큰 관심사
- 자녀 결혼·증여, 부모 부양, 노후 의료비 사이에서 고민 중
- 체면과 자존심이 중요하고, 남에게 돈 얘기를 쉽게 꺼내지 못함
- "나도 저렇게 될까" 하는 불안과 "나는 아직 괜찮다"는 자신감이 함께 있음
- 젊은 세대의 신조어, 영어 경제용어에 익숙하지 않음
- "40대 이상 일반"으로 넓게 쓰지 않는다. 35~44세(8%)는 따로 겨냥하지 않는다.

## 3. 주제 선정
- 우선: 노후자금·연금·퇴직금 지키기/노후 파산 · 부동산(집 한 채의 운명, 다운사이징, 주택연금) · 자녀 증여·상속의 심리 · 은퇴 후 소비 습관·체면 소비·남자들이 돈 앞에서 하는 실수 · 사기·투자 실패·보증
- 관점: 경제 현상을 "내 지갑, 내 노후에 무슨 일이 생기나"로 번역. 소비심리도 남성 가장의 시선으로 푼다.
- 보조(월 1~2편 이내): 부부가 함께 볼 주제(부부 노후자금, 아내가 모르는 남편의 돈 습관). 남성 중심 톤 유지.
- 몰락·관광시설 같은 사회 주제도 끝은 "그 적자·세금·집값이 내 노후에 어떻게 오나"로 연결한다.

## 4. 말투·문체
- 존중하는 존댓말, 가르치지 않고 "같이 짚어보자".
- 평생 열심히 산 사람으로 인정하고 시작 ("평생 가족 위해 일하신 분들일수록 이 함정에 더 쉽게 빠집니다.")
- 영어 경제용어는 쓰지 않거나, 쓰면 바로 쉬운 우리말로 풀이.
- 한 문장은 짧게, 한 문장에 정보 하나.
- 중요한 숫자는 한 번 더 반복. 숫자 표기는 한글 숫자 표기 규칙을 따른다.

## 5. 구독 전환 장치 (비구독자 85%)
- 도입부 1~2분 사이 구독 멘트 1회 (끝에 몰지 않는다) 예) "이런 노후 이야기, 놓치지 않으시려면 지금 구독 눌러두세요."
- 중반부 다음 편 예고 1회
- 마무리 참여 질문 1개 ("여러분은 이 중 몇 개나 해당되십니까? 댓글로 남겨주세요.")
- 시리즈·재생목록으로 이어지게 제목과 예고를 맞춘다.

## 6. 자막·화면 (자막 사용 37.1%)
- 대본을 그대로 SRT로 쓸 수 있게 맞춤법·띄어쓰기 정확히.
- 핵심 숫자·핵심 문장은 [화면 강조] 표시 → 큰 화면 자막(kin·swapnum 등)으로 띄운다. 자막을 안 켠 62.8%도 핵심을 놓치지 않게.
  - **주의(Claude Code 운영):** [화면 강조] 표시는 VREW 녹음용 대본에서는 빼고(읽으면 안 됨), 장면 메모 목록으로 따로 넘긴다.
- 한 화면 자막은 두 줄 이내로 끊어지게 문장을 짠다.
